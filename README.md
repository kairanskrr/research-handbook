# Research Handbook

**English** · [中文](README.zh.md)

From choosing a topic to getting results: how to do a piece of research properly.

Each chapter opens with a short box of the things you must do; read only that box if you are in a hurry.

Written for people starting out in research: how to choose a topic, read the literature, design a study, move a project forward, and what conventions each field has of its own. The content comes from the experience of senior researchers and from widely accepted methodological standards in each field, and every piece of advice can be traced back to its original source.

## Where to start

| Your situation | Start here |
|---|---|
| This is your first research project and you want to know how to read this handbook | [How to use this handbook](en/guide/00_start-here/how-to-use.md), then [The research journey at a glance](en/guide/00_start-here/research-journey.md) |
| You are already under way: you have just picked an area, you are looking for a problem, designing the study, running experiments, or your results look wrong | The routing table in [How to use this handbook](en/guide/00_start-here/how-to-use.md#where-you-are-which-page-to-read-first), or the matching chapter in the two Parts below |
| You have a specific problem: the experiment won't work, the paper was rejected, your advisor has no time… | [FAQ: quick answers](en/guide/faq.md) |
| You have written down the sentence you want to prove, and want to know what kind of research this is and what evidence it needs | [Research strategies](en/guide/05_research-strategies/README.md) |
| You need to do a particular kind of research: controlled experiment, interviews, questionnaire, review, benchmarking… | [Research types](en/guide/06_methods/README.md): find the page by the name you use for it |
| You are entering a new field and want to learn its conventions | Your field in [Fields](en/guide/07_fields/README.md) |

## How to check the sources

Every piece of advice has a footnote. Open the footnote to see which source it comes from, where in the original it appears, and what the original says. Anything without a footnote is our own synthesis and advice. Where sources disagree, the different views are set out side by side.

All original sources are listed in the [source list](en/sources/README.md), and the quoted excerpts from each source are in [`sources/notes/`](en/sources/notes/README.md).

## Repository layout

```
guide/                          the handbook text (Chinese; README.zh.md is its home page)
en/                             the English edition, mirroring the same layout
  00_start-here/                  Getting started: how to use it, the research journey, key concepts
  01_find-a-problem/              Part 1: Find a good problem (exploring)
  02_do-the-project/              Part 2: Do the project (testing)
  05_research-strategies/         Reference: why, the eight research strategies
  06_methods/                     Reference: the research types directory, and methods shared across fields
  07_fields/                      Reference: Fields, one folder per field
    computer-science/practices/     research practices specific to computer science
    <field>/practices/              research practices specific to other fields
  08_throughout/                  Throughout the project: planning, materials, advisors and collaboration, integrity, mindset
  faq.md                          FAQ: quick answers
sources/                        original sources
  README.md                       source list: papers, standards, blogs, repositories
  notes/                          evidence notes: the original text and its location for each source
papers/                         BibTeX for the papers (references.bib) and an index
repos/                          GitHub repositories included as reference material (git submodules)
templates/                      document templates
scripts/                        paper download script, web reader build script (preview locally with python scripts/build_site.py --full . --out _site)
site/                           web reader pages
```

To clone this repository:

```
git clone --recursive https://github.com/kairanskrr/research-handbook.git
```

If you have already cloned it, run `git submodule update --init` to fetch the submodules under `repos/`.
