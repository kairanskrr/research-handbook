# Research Handbook

从选题到发表，把一项研究做扎实。

写给刚开始做科研的人：怎样选题、读文献、设计研究、推进项目、写作投稿，以及各个学科有哪些自己的规矩。内容来自资深研究者的经验和各领域公认的方法规范，每条建议都能追溯到原文出处。

## 从哪里读

| 你的情况 | 从这里开始 |
|---|---|
| 第一次做研究，想先知道这本手册怎么读 | [怎么用这本手册](guide/00_start-here/how-to-use.md)，再看[全程地图](guide/00_start-here/research-journey.md) |
| 正处在某个阶段：刚有方向、在设计研究、在做实验、准备投稿 | 下面"四条主线"里对应的那一章 |
| 遇到了具体问题：实验做不出来、被拒稿、导师没空…… | [常见问题速查](guide/faq.md) |
| 写出了想证明的那句话，想知道这是哪一种研究、要什么证据 | [研究套路](guide/05_research-strategies/README.md) |
| 要用某种研究方法：对照实验、访谈、问卷、综述…… | [研究方法](guide/06_methods/README.md)，或学科篇里本学科独有的实践 |
| 进入一个新学科，想了解它的规矩 | [学科篇](guide/07_fields/README.md)里你的学科 |

## 怎么看出处

每条建议后面都有脚注。点开脚注，可以看到它出自哪份资料、原文在哪一页、原文怎么说。没有文献依据、属于我们自己的判断，标注 `[本项目分析]`。资料之间说法不一致时，会把各方观点并列写出来。

所有原始资料都列在[资料列表](sources/README.md)里，每份资料的原文摘录在 [`sources/notes/`](sources/notes/README.md)。

## 仓库结构

```
guide/                          手册正文
  00_start-here/                  开始：怎么用、全程地图、核心术语
  01_from-interest-to-project/    主线一：从兴趣到项目
  02_from-project-to-study/       主线二：从项目到研究设计
  03_conduct-and-analyze/         主线三：执行和分析
  04_write-and-publish/           主线四：写作和发表
  05_research-strategies/         参考层：八种研究套路
  06_methods/                     参考层：多个学科通用的研究方法
  07_fields/                      参考层：学科篇，每个学科一个文件夹
    computer-science/practices/     计算机特有的研究实践
    <学科>/practices/               其他学科独有的研究实践
  08_throughout/                  贯穿全程：计划、材料、导师与合作、诚信、心态、当审稿人
  faq.md                          常见问题速查
sources/                        原始资料
  README.md                       资料列表：论文、规范、博客、仓库
  notes/                          证据摘录：每份资料的原文和位置
papers/                         论文的 BibTeX（references.bib）和索引
repos/                          作为参考资料引入的 GitHub 仓库（git submodule）
templates/                      文档模板
scripts/                        论文下载脚本
docs/                           项目自身的规划文档
```

克隆本仓库：

```
git clone --recursive https://github.com/kairanskrr/research-handbook.git
```

已经克隆过的，运行 `git submodule update --init` 拉取 `repos/` 下的子模块。
