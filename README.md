# merevo-resources：科研知识库

本仓库为 Auto Research 项目整理科研相关的知识：各类研究应该怎么做、什么是好的研究、常见的问题有哪些。

## 现阶段的用途：评估，而不是能力

科研知识在项目中有两种用途，按不同节奏推进：

| 用途 | 内容 | 阶段 |
|---|---|---|
| **用于评估**：什么是好的研究 | 各类研究的阶段、产出物、质量标准、反面模式 | **现在**，服务于 S1（任务与评估） |
| **用于能力**：怎么做研究 | 把知识做成 agent 的 skills 或提示词 | **S2 之后**，针对 baseline 中观察到的失败再补充 |

因此本仓库**不包含** agent 的 skills、提示词或代码。是否以及如何把这里的知识做成 agent 能力，要等实验证据出来后再决定。

另外要注意：同一套知识不宜既当 agent 的操作指南，又当评估标准，否则 agent 可能学会"对着评分表打勾"。评估需要独立的人工评审来校准。

## 贡献规则

1. **每条内容都要注明出处**。没有出处的内容不要写。属于本项目自己的分析、不来自文献的内容，标注"本项目分析"。
2. **不复制受版权保护的全文或 PDF**。只放链接，用自己的话概括；必要时可以简短引用并注明出处。
3. **不确定就标"待确认"**，不要猜测。
4. **资料先进 `SOURCES.md`**，核实后再在整理中引用。
5. 用中文撰写；资料标题、术语和文件名保留英文。
