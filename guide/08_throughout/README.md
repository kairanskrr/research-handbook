# 贯穿全程

手册的主干按研究的先后顺序走：第一部分想到一个好题目，第二部分把它做出来。但有些事不属于哪一个阶段，而是从第一天一直跟到最后：怎么安排时间，怎么整理材料，怎么和导师、合作者相处，怎么守住诚信，以及怎么度过低谷。

这一层就放这些内容。**不用按顺序读**，遇到相关的事再翻到对应的那一页。

## 这一层有哪几页

| 页面 | 讲什么 | 什么时候读 |
|---|---|---|
| [计划与日常节奏](planning_and_routines.md) | 怎么把项目拆成每周能推进的事，安排日常的研究节奏 | 刚开始一个项目时；觉得每天很忙却没有进展时 |
| [整理科研材料](organizing_materials.md) | 怎么管理数据、代码、实验结果和笔记，让几个月后的自己还找得到、看得懂 | 项目开工、跑第一个实验之前；材料已经乱了的时候 |
| [合作与导师](collaboration_and_advisors.md) | 怎么和导师沟通、开会、要反馈，怎么和合作者分工、商量署名 | 刚进组时；和导师或合作者意见不合、沟通不顺时 |
| [科研诚信与伦理](integrity_and_ethics.md) | 数据、署名、引用和涉及人的研究中，哪些事不能做、该怎么做 | 设计研究、写论文、定作者顺序之前；拿不准某件事算不算越界时 |
| [心态与长期积累](mindset_and_growth.md) | 怎么面对卡住、失败和拒稿，怎么慢慢培养研究品味 | 卡住、没有进展、被拒稿后；想想自己长期往哪里走时 |

## 和两部分主干的关系

第一部分、第二部分各章讲到这些话题时，只点一句，再链接到这里。比如[收敛成项目](../01_find-a-problem/05_converge.md)要你写一页项目简介，并拿去和导师讨论；怎样开好这次讨论，见[合作与导师](collaboration_and_advisors.md)。

反过来，读这一层的某一页时，如果发现问题其实出在项目本身，比如总也推进不动，是因为结论想得不清楚，就回到两部分里相应的章节。全程地图见[全程地图](../00_start-here/research-journey.md)。
