# 贯穿全程

> **状态**：初稿，待审阅 · **最后更新**：2026-10-07

主线一到四按研究的先后顺序走：从兴趣到项目，从项目到研究设计，再到执行、分析和发表。但有些事不属于哪一个阶段，而是从第一天一直跟到最后：怎么安排时间，怎么整理材料，怎么和导师、合作者相处，怎么守住诚信，怎么度过低谷，以及别人请你审稿时该怎么做。

这一层就放这些内容。**不用按顺序读**，遇到相关的事再翻到对应的那一页。

## 这一层有哪几页

| 页面 | 讲什么 | 什么时候读 |
|---|---|---|
| [计划与日常节奏](planning_and_routines.md) | 怎么把项目拆成每周能推进的事，安排日常的研究节奏 | 刚开始一个项目时；觉得每天很忙却没有进展时 |
| [整理科研材料](organizing_materials.md) | 怎么管理数据、代码、实验结果和笔记，让几个月后的自己还找得到、看得懂 | 项目开工、跑第一个实验之前；材料已经乱了的时候 |
| [合作与导师](collaboration_and_advisors.md) | 怎么和导师沟通、开会、要反馈，怎么和合作者分工、商量署名 | 刚进组时；和导师或合作者意见不合、沟通不顺时 |
| [科研诚信与伦理](integrity_and_ethics.md) | 数据、署名、引用和涉及人的研究中，哪些事不能做、该怎么做 | 设计研究、写论文、定作者顺序之前；拿不准某件事算不算越界时 |
| [心态与长期积累](mindset_and_growth.md) | 怎么面对卡住、失败和拒稿，怎么慢慢培养研究品味 | 卡住、没有进展、被拒稿后；想想自己长期往哪里走时 |
| [当审稿人](being_a_reviewer.md) | 接不接审稿邀请、怎么保密和回避、怎么读稿和写出有用的审稿意见 | 收到审稿邀请，或导师让你帮忙审一篇稿子时 |

## 和主线的关系

主线章节讲到这些话题时，只点一句，再链接到这里。比如[收敛成项目](../01_from-interest-to-project/03_converge.md)要你写一页项目简介，并拿去和导师讨论；怎样开好这次讨论，见[合作与导师](collaboration_and_advisors.md)。

反过来，读这一层的某一页时，如果发现问题其实出在项目本身，比如总也推进不动，是因为结论想得不清楚，就回到主线的相应章节。全程地图见[研究历程](../00_start-here/research-journey.md)。
