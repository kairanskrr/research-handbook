# 档案研究

本文讲**档案研究**：到档案馆查阅没有出版过的原始记录（信件、日记、会议记录、机构文件等），或使用它们的数字化版本，用这些记录回答一个关于过去的问题。Ithaka S+R 2012 年访谈了 39 位美国历史学者和研究生，报告认为使用一手资料仍是历史研究方法的核心[^rutner2012supporting-e19]。文学、法学、政治学、社会学的研究者也会进档案馆；各学科对"什么算一手资料"看法不同[^saaacrl2018primary-e2]，但查档和审视资料的步骤是共通的。

一手和二手资料的区别、档案馆的基本规矩、上面那项 2012 年 39 人访谈研究的背景，已在[历史与考古学科概况](../07_fields/history-archaeology/README.md#在档案馆里工作)讲过，这里不重复。本文资料主要有三类：美国档案学界的两份公开文件，即美国档案工作者协会（Society of American Archivists，SAA）的查档指南（下称"SAA 查档指南"）和它与美国大学与研究图书馆协会（ACRL）合编的《一手资料素养指南》（下称"素养指南"）；英国国家档案馆和美国国家档案与记录管理局的官网页面，只代表这两家机构；以及历史与考古学科概况用过的几份资料。所以本文反映的是**英美的做法**，其他国家以当地档案馆和法律的规定为准。注意：历史与考古学科概况里的"SAA"指美国考古学会，是另一个组织。

**适用范围**：本篇原为历史与考古学科篇写，资料主要来自英美档案机构和档案学界的文件、美国历史学界的准则和方法文章（另有两条软件工程文献，只用来对比）。除[历史与考古](../07_fields/history-archaeology/README.md)外，[艺术](../07_fields/arts/README.md)、[语言与文学](../07_fields/languages-literature/README.md)、[社会学](../07_fields/sociology/README.md)的学科概况也链接到本篇。各学科对"什么算一手资料"、怎样引用档案有自己的习惯；用之前先看本学科的规范。

**常服务的套路**：[解读论证](../05_research-strategies/interpret_argue.md)（从零碎的记录搭起一个关于过去的论点）。依据是素养指南的要求：考察并综合多种资料，用来建立、支撑或反驳一个论点[^saaacrl2018primary-e16]，具体见下面第九步。

**读完本文，你应该能：**

- 把一个题目变成能用档案回答的问题，并找到可能收藏相关记录的地方；
- 做好查档前的准备：查规定、办手续、算时间和经费；
- 在阅览室里高效工作，并记下以后能让别人找回原件的出处；
- 审视一份档案：谁、何时、为何、为谁而写，以及档案里**没有**什么；
- 知道数字化档案、受限档案和版权各有什么坑。

## 1. 这是什么研究，什么时候用

**档案和图书馆不一样。** 档案馆里的材料常常独一无二[^schmidt2016using-e1]。英国国家档案馆的入门页面说，图书馆按主题和作者排书，档案却按**产生它的个人或机构**排列，所以你很可能要看好几个来源、好几个档案馆的记录[^tnastarthere-e1]。因此找档案不是搜"主题词"，而是先想"谁会留下记录"。

**什么时候用：** 你的问题要靠当时人留下的、没出版的记录才能回答，比如一个机构内部怎样做决定、一个人私下怎样想。如果已出版的材料就够用，或者研究的是正在发生的事，档案研究不一定是首选。

**和相近的研究方法怎么区分** （本手册根据下列资料的归纳）：

| | 档案研究 | 案例研究（见研究方法里的[案例研究与民族志](case_study.md)） | 口述历史（见[历史与考古学科概况](../07_fields/history-archaeology/README.md#口述历史受访者的同意和控制权)） |
|---|---|---|---|
| 研究对象 | 过去留下的记录 | 当下正在发生的现象[^ralph2020empirical-e414] | 亲历者对过去的讲述 |
| 能否产生新资料 | 不能，只能用留存下来的 | 能，可以访谈、观察 | 能，访谈本身就是新资料 |
| 主要难点 | 记录零碎、有缺口[^aha2023standards-e14] | 进入现场 | 受访者的同意和记忆的主观性 |

软件工程里只分析已有仓库数据的研究，Wohlin 认为应叫"档案分析"而非案例研究[^wohlin2021case-e3]；本文的档案研究更重视**记录是谁、为什么留下来的**。

## 2. 怎么做

### 第一步：把题目变成能用档案回答的问题

**怎么做：**
1. **先读二手文献，抓出人名、机构名和年代。** 档案馆按个人和机构的名字归档[^cronon2009learning-e29]。Cronon 等人的历史研究入门网站以研究"地球日"起源为例：先找出相关的人和机构，再想清楚哪几年和问题最相关[^cronon2009learning-e30]。
2. **问"谁会留下记录"。** 二手文献里出现的每个人、每个机构，都问一句：他们留下文字记录了吗？[^cronon2009learning-e40]
3. **列一张"理想资料清单"**，遇到真实文献后不断更新[^cronon2009learning-e41]。
4. **检查问题本身。** 素养指南说，好的研究问题可回答、可论证、不太宽也不太窄；问题决定你需要什么信息，也决定哪些资料算一手资料[^saaacrl2018primary-e22]。

**为什么：** 先界定题目、想清楚要找什么材料，才能判断该联系哪些收藏机构[^schmidt2016using-e2]。

**容易错在哪里：** 一是问题定得太死。素养指南提醒，研究是反复往返的过程，找到资料后问题可能会变[^saaacrl2018primary-e8]。二是看了第一份文件就改题。Cronon 等人建议：带着真正在意的问题进馆，不轻易放弃，但也让它在和文献的对话中改变；把思考过程写下来，放弃的问题也可能成为以后的课题[^cronon2009learning-e35]。

### 第二步：找到收藏，读懂检索指南

**怎么做：**
- **顺着别人的脚注找。** 查同主题著作的参考文献，看信息从哪里来[^schmidt2016using-e3]；问同领域的专家去过哪些档案馆[^schmidt2016using-e4]。那项 2012 年 39 人的美国访谈研究也说，追引用线索是发现资料的重要途径[^rutner2012supporting-e18]。
- **用国家档案馆的目录。** 英国国家档案馆的目录 Discovery 也能检索其他档案馆的记录[^tnastarthere-e7]。其他国家有什么联合目录，问本校图书馆员。
- **用常识推测。** 档案馆倾向于收藏和自身归属相关的材料[^cronon2009learning-e31]。
- **读检索指南**（finding aid，描述一个收藏里有什么的文本，像书的目录[^schmidt2016using-e5]）。它有时还写着收藏怎样形成、档案馆怎样得到它、材料怎样排列[^schmidt2016using-e6]。重点看：**主体年代**（bulk dates），即大部分材料所属的年代[^schmidt2016using-e33]，收藏标着"1921–2005"不代表每年都有材料；**查阅和使用**一节，写着限制、版权和建议的引用格式[^schmidt2016using-e34]。
- **联系档案工作人员。** 先看完目录、检索指南和网站，再打电话或发邮件确认[^schmidt2016using-e10]。邮件里写清项目、看过哪些检索指南、想看哪些材料，再问有没有其他相关材料[^schmidt2016using-e9]。网站上没列收藏的档案馆，只能靠联系工作人员才知道有什么[^schmidt2016using-e11]。亲手整理过这个收藏的人，是最好的帮手之一[^cronon2009learning-e33]。

**为什么：** 档案馆的目录不像 Google，简单的关键词检索不一定管用[^tnastarthere-e2]；检索指南和工作人员能帮你看到目录里看不到的东西。

**容易错在哪里：** 只用主题词搜，搜不到就以为没有。档案按创建者排列[^tnastarthere-e1]，而且检索指南本身也可能有错误或遗漏[^schmidt2016using-e32]。

### 第三步：准备查档：规定、手续、时间和经费

**怎么做（出发前逐项确认）：**
- **手续。** 有些档案馆要推荐信或特别许可才能进馆[^schmidt2016using-e20]。以英国国家档案馆为例，看原件要办读者证，要带规定的身份证件[^tnastarthere-e8]。
- **材料在不在，怎么调阅。** 把到访日期和想看的材料提前告诉工作人员。存放在馆外库房的材料，调取可能要几个小时甚至几天[^schmidt2016using-e15]。Cronon 等人到馆后才发现有一箱借给了别的机构，事先打个电话就能避免[^cronon2009learning-e32]。另外问清一次能调多少、什么时间能提交申请[^schmidt2016using-e16]；复印、扫描、拍照的规定和费用，各馆不同[^schmidt2016using-e17]。
- **未整理的收藏**（档案馆收到但还没整理编目的材料）：尽早联系，问清使用规定[^schmidt2016using-e28]。那项 2012 年访谈研究也说，用这类收藏需要不同的准备[^rutner2012supporting-e15]。
- **时间和经费。** 它们会限制项目范围[^cronon2009learning-e40]。给意外留出时间，考虑第二次去核对和补查[^schmidt2016using-e19]；问问档案馆有没有研究资助[^schmidt2016using-e18]。
- **先试试不出门的办法。** 问能否付费扫描[^schmidt2016using-e12]、能否请研究助理代查[^schmidt2016using-e13]；简单的问题，工作人员很可能直接答复[^schmidt2016using-e14]。那项 2012 年访谈研究的受访者说，去不了档案馆时，曾通过大量电话和邮件依靠档案工作人员[^rutner2012supporting-e12]。

**为什么：** 到了馆才发现缺手续、材料调不出来，一趟差旅就白费了。

**容易错在哪里：** 行程排得太满，没给"发现新线索"留时间。SAA 查档指南建议给意外留出时间[^schmidt2016using-e19]。

### 第四步：在阅览室里工作

**怎么做：**
- **守规矩，也懂原因。** 只用铅笔，是因为万一在档案上留下痕迹还能擦掉[^schmidt2016using-e21]。材料要保持拿到时的顺序，以后才能找到，也才能放在原来的上下文里看[^schmidt2016using-e22]。
- **先看最重要的。** 先申请对你最有用的材料，确保有时间看完[^schmidt2016using-e29]。
- **每条笔记、每张照片都带完整出处**：收藏名和档案馆给的编号[^schmidt2016using-e30]，以及箱号、文件夹号[^schmidt2016using-e34]。拍照的技巧和"只拍不想"的代价，见[历史与考古学科概况](../07_fields/history-archaeology/README.md#在档案馆里工作)。
- **看页边。** 很多信件因为页边批注而有了另一层意义[^cronon2009learning-e37]。一个问号证明不了论点，但能让你换个角度看其他证据[^cronon2009learning-e38]。
- **追线索，记缺口。** 文献会把你引向下一个去处[^cronon2009learning-e39]；缺口和不确定之处也记下来，以后的研究可能带来新线索[^cronon2009learning-e36]。

**为什么：** 完整出处让你自己回头能找到原件，也让读你成果的人能追查到原件[^schmidt2016using-e31]。

**容易错在哪里：** 跳过"无关"的文件。Cronon 等人发现自己三次因为"和问题无关"而跳过感兴趣的文件；其实这些文件引出了很多问题，只是他们没让自己去问[^cronon2009learning-e34]。

### 第五步：审视每一份资料

历史与考古学科概况已经列了几个基本问题：作者是谁、文献是否出自那个时期、写给谁看。素养指南把它们展开成更完整的做法：
1. **先说清它是什么**：怎样产生的、谁产生的、何时产生、是什么[^saaacrl2018primary-e11]。
2. **问视角和目的**：创作者的语气、主观性、偏见，和资料原本的目的、读者有什么关系[^saaacrl2018primary-e13]。
3. **看物质形态**：资料的物理和材料特征也要纳入解释[^saaacrl2018primary-e15]。
4. **分清版本**：你看到的可能是节选、转录或译本[^saaacrl2018primary-e12]。
5. **真不等于可靠**：一份记录是真的，不等于它的内容可靠[^saaacrl2018primary-e20]。
6. **想想谁替你挑过**：从资料产生到你手里，档案工作者、数据库设计者都做过"中介"[^saaacrl2018primary-e3]；检索指南、目录和材料的排列方式也是中介[^saaacrl2018primary-e27]。例如按主题分装的文件夹会掩盖一个人同一时期在做的其他事，Cronon 等人按日期把材料串起来，才看到更完整的图景[^cronon2009learning-e43][^cronon2009learning-e44]。

**档案里的"沉默"。** 档案不是过去的全部：
- 美国国家档案与记录管理局说，美国联邦政府工作中产生的全部文件和材料里，只有 1% 到 3% 因法律或历史价值被永久保存[^naragettingstarted-e1]。Cronon 等人也提醒，几乎所有写下来的东西都没有进入档案馆[^cronon2009learning-e36]。
- 素养指南说，文化遗产机构的收藏反映并强化社会的权力结构[^saaacrl2018primary-e5]。"沉默"指历史记录里的缺口，常常因为有些人无法留下记录，或他们的记录不被看重、被压制；这和"某个馆恰好没收这类材料"是两回事[^saaacrl2018primary-e21]。
- 所以要问：哪些资料从未被创造，哪些已不存在，哪些被收藏了[^saaacrl2018primary-e4]；缺口、矛盾和权力关系的痕迹，原因是什么[^saaacrl2018primary-e14]。

**为什么：** 美国历史学会（American Historical Association，AHA）的职业准则说，历史研究要讨论资料告诉了我们什么，**也要讨论它们照不亮什么**[^aha2023standards-e24]。

**容易错在哪里：** 把"档案里没有记载"当成"历史上没有发生"；用今天的标准评判当时的人（当下主义，见[历史与考古学科概况的常见错误](../07_fields/history-archaeology/README.md#常见错误)）。

### 第六步：整理和引用

**怎么做：**
- **按收藏机构的建议格式记出处。** SAA 查档指南的检索指南样例给的引用格式是"条目、文件夹、箱、收藏名、收藏机构"[^schmidt2016using-e34]。素养指南也说，可能时遵从收藏机构的引用惯例[^saaacrl2018primary-e17]。
- **选引用格式。** 《芝加哥格式手册》的注释—参考书目体系，能容纳放不进"作者—年份"体系的特殊资料[^chicago2024citation-e3]；用哪种体系，先问导师[^chicago2024citation-e5]。
- **注明你对原文做过的任何改动**，不管是数字版还是印刷版[^aha2023standards-e22]。数字化记录容易复制，这让准确引用更加重要[^aha2023standards-e23]。引的是原件、缩微胶片还是网上的数字版，也要写清。
- **不要转引装作亲见。** 从别人书里借来一手资料的出处、却不注明那本书，AHA 视为不当[^aha2023standards-e11]。
- **整理照片和笔记。** 素养指南把转录、拍照、下载都列为需要有办法管理的研究资料[^saaacrl2018primary-e7]。具体做法见贯穿全程的[整理科研材料](../08_throughout/organizing_materials.md#5-分清三种笔记)。

**为什么：** AHA 准则要求准备好公开所用的资料和证据[^aha2023standards-e15]；出处记不全，这一条就做不到。

### 第七步：用好数字化档案，也认清它的局限

**数字化档案省时间，但不等于全部。**
- SAA 查档指南说，数字化收藏往往只是馆藏的一小部分[^schmidt2016using-e7]。英国国家档案馆的官网写着，该馆上线的记录是馆藏的 5% 多一点（网页未注日期）[^tnastarthere-e4]；还有一部分由商业公司数字化，通常要付费才能看[^tnastarthere-e5]。在线浏览时，可能分不清看到的是完整收藏还是一部分，要找到最高一级的收藏看全貌[^schmidt2016using-e8]。
- 分清两类网站：只提供"资料信息"的目录，和提供"资料本身"的数字版[^saaacrl2018primary-e10]。数字化收藏也经过挑选，反映了许多人在挑选、复制和呈现上的决定[^saaacrl2018primary-e6]。

**关键词检索有盲区。** 那项 2012 年 39 人的美国访谈研究中，一些受访者担心能检索的材料并不全面[^rutner2012supporting-e16]；做国际题目的人指出，Google 图书里的外文材料有限[^rutner2012supporting-e17]。所以比较好的用法是： 用数字化档案和在线检索指南来**定位**，再有针对性地去档案馆。同一项研究里，多数受访者说有了数字化的检索指南和收藏，他们没有少出差，但出差更有针对性了[^rutner2012supporting-e13]。

### 第八步：处理受限档案、隐私和版权

**为什么会受限。** SAA 查档指南（讲美国的情况）举了两类原因：捐赠者设了期限或条件，通常出于隐私或材料敏感[^schmidt2016using-e25]；法律规定，例如美国人口普查记录封存 72 年才开放[^schmidt2016using-e26]。有时可以申请获准查阅[^schmidt2016using-e27]。素养指南还说，档案人员可能因为法律、捐赠协议或职业伦理，遮盖记录的部分内容[^saaacrl2018primary-e23]。

**怎么做：**
- **遵守你同意过的条件。** AHA 承认出于国家安全、商业产权和隐私的限制是正当的，也反对不必要的限制[^aha2023standards-e21]。历史学家有时会正当地同意某些资料的使用条件[^aha2023standards-e26]，做过的承诺就要遵守[^aha2023standards-e8]；也不做任何妨碍后来者查阅资料的事[^aha2023standards-e10]。
- **想想对当事人的影响。** 素养指南要求使用资料时尊重隐私和文化背景，遵守版权法和隐私法[^saaacrl2018primary-e18]，并考虑研究可能对资料的创作者、捐赠者、所有者产生什么影响[^saaacrl2018primary-e19]。即使资料已进入公有领域（不再受版权保护），隐私问题仍要权衡[^saaacrl2018primary-e26]。
- **区分"拥有原件"和"拥有版权"。** 档案馆拥有一份文件的实物，不等于拥有它的版权[^schmidt2016using-e23]。按 SAA 查档指南，在美国要发表或引用这些材料，由研究者自己负责找到版权人[^schmidt2016using-e24]；复印给你的未出版材料，发表前可能还要另取许可[^schmidt2016using-e35]。各国版权法不同[^saaacrl2018primary-e24]，你所在国家的规定，问学校版权办公室或图书馆。

### 第九步：从碎片搭起论证

**怎么做：**
- **综合多种资料。** 素养指南说，要考察并综合多种资料，用来建立、支撑或反驳一个论点[^saaacrl2018primary-e16]。证据有多强、怎样收集、怎样用来支撑主张，都影响结论的可信度[^saaacrl2018primary-e25]。
- **交叉印证**：一个关键说法，尽量找不同人、不同机构留下的记录相互核对，例如同一次会议，既看主办方的记录，也看与会者的信件。
- **按时间串起来**：仔细记日期，能看出意想不到的联系[^cronon2009learning-e43]。
- **不挑证据。** 不得歪曲资料，不略去与自己解释相反的证据[^aha2023standards-e25]。
- **写明局限。** 过去的记录是零碎的，不可能得到绝对的历史知识[^aha2023standards-e14]。把找过但没找到的、档案里的沉默，以及它们怎样限制了结论，写进正文或注释。

**为什么：** 让证据和研究问题对话，可能是研究过程中最重要的部分[^cronon2009learning-e45]。

**容易错在哪里：** 真实找到的证据常常不如想象中好[^cronon2009learning-e42]。这时缩小结论，比硬撑一个大论点更稳妥。

## 3. 检查清单

本文资料里没有档案研究专用的报告规范。下面依据 AHA 准则、SAA 查档指南和素养指南整理，分档为本项目归纳。

**必须做到**
- [ ] 每条引用的档案都记了完整出处（收藏机构、收藏名、箱号、文件夹号或编号），别人能据此找回原件[^schmidt2016using-e30][^schmidt2016using-e34][^schmidt2016using-e31]
- [ ] 对原文的改动都做了标注[^aha2023standards-e22]
- [ ] 没有略去与自己解释相反的证据[^aha2023standards-e25]
- [ ] 借用别人著作里的一手资料出处时，注明了那本著作[^aha2023standards-e11]
- [ ] 遵守了自己做过的承诺[^aha2023standards-e8]；发表前处理了版权和许可[^schmidt2016using-e24][^schmidt2016using-e35]
- [ ] 每份关键资料都问过：谁、何时、为什么、写给谁[^saaacrl2018primary-e11][^saaacrl2018primary-e13]

**做到更好**
- [ ] 讨论了档案的沉默和缺口，以及它们怎样限制结论[^saaacrl2018primary-e14][^aha2023standards-e24]
- [ ] 说明了用的是原件还是节选、转录、译本等其他版本[^saaacrl2018primary-e12]
- [ ] 关键说法综合了多种资料[^saaacrl2018primary-e16]
- [ ] 考虑了研究对资料当事人的影响[^saaacrl2018primary-e19]

**这些情况可以不做，不算缺陷**
- 没有亲自到馆，而是用档案馆的扫描件或请人代查：SAA 查档指南把这些列为可以向档案馆问的远程办法[^schmidt2016using-e12][^schmidt2016using-e13]。但要在注释里写清你看的是什么版本。

## 4. 常见错误

| 错误 | 为什么是问题 |
|---|---|
| 按主题词搜档案，搜不到就以为没有 | 档案按产生它的个人或机构排列[^tnastarthere-e1]，目录也不像 Google[^tnastarthere-e2] |
| 只看网上已数字化的部分 | 数字化往往只是馆藏的一小部分[^schmidt2016using-e7]；英国国家档案馆上线的是馆藏的 5% 多[^tnastarthere-e4] |
| 没联系档案馆就出发 | 材料可能在馆外库房要等几天[^schmidt2016using-e15]，甚至已借给别的机构[^cronon2009learning-e32] |
| 拍照或笔记不记出处 | 自己找不回，读者也追查不到原件[^schmidt2016using-e31] |
| 打乱材料顺序 | 别人以后找不到，也失去原来的上下文[^schmidt2016using-e22] |
| 把档案里的说法当事实 | 一份记录是真的，不等于内容可靠[^saaacrl2018primary-e20] |
| 把"档案里没有"当成"没发生" | 美国联邦政府的文件只有 1%–3% 被永久保存[^naragettingstarted-e1]，几乎所有写下来的东西都没进档案馆[^cronon2009learning-e36]，有些人的记录被忽视或压制[^saaacrl2018primary-e21] |
| 以为档案馆给了复印件，就能随便发表 | 拥有原件不等于拥有版权[^schmidt2016using-e23]；未出版材料发表前可能要另取许可[^schmidt2016using-e35] |
| 看了第一份文件就改题，或者死守原题 | 问题要在和文献的对话中调整，但不要轻易放弃[^cronon2009learning-e35] |

## 5. 延伸阅读

- **SAA，Using Archives: A Guide to Effective Research**（Laura Schmidt 撰写，免费网页，面向美国读者）：从找档案馆、远程申请、计划到访，到阅览室规则、版权和受限材料，附一份带注释的检索指南样例。第一次查档前通读一遍。
- **SAA 与 ACRL，Guidelines for Primary Source Literacy**（2018，免费 PDF）：怎样提问、查找、阅读、评估和使用一手资料，附词汇表（"沉默""中介""真实性"等）。适合自查资料批判做得够不够。
- **Cronon 等，Learning to Do Historical Research 的 Manuscripts 一页**：以一个真实收藏为例，演示怎样找收藏、在阅览室里看文件、追线索。
- **英国国家档案馆 Start here 栏目**、**美国国家档案与记录管理局 Getting Started 页面**：两家机构各自的入门说明，讲网上有什么、没有什么、怎样准备到访。
- **AHA，Statement on Standards of Professional Conduct**：美国历史学会关于引用、改动标注、查阅限制和承诺的职业准则。
- 文学研究者用档案的特点，见[语言与文学学科概况](../07_fields/languages-literature/README.md#文学研究档案和学术版本)。
