# 艺术：学科概况

本文讲艺术领域（艺术史、音乐学、表演艺术、设计，以及基于实践的艺术研究）的研究实际怎样运转。这个领域里有**两类很不一样的研究**：一类是**关于艺术的学术研究**，研究对象是作品、档案和艺术家；另一类是**以创作实践为方法的研究**，做作品本身就是研究的一部分。下文把两类分开讲。各学科共通的做法（选题、读文献、写作、科研诚信）见[全程地图](../../00_start-here/research-journey.md)里的主线各章和[贯穿全程](../../08_throughout/README.md)，这里不重复。艺术研究常用哪些研究套路、各看什么证据，见[常用套路与证据标准](#常用套路与证据标准)；具体做法见文末的[本学科常用的研究方法](#本学科常用的研究方法)。

本文资料主要来自英国、美国和欧洲：英国的科研评估文件和一份英格兰的调研报告、美国两个学会的准则、一份欧洲组织联合发表的宣言，以及澳大利亚一所大学里一个研究中心的报告。文中写到某个机构的要求时，指的是**那个机构、那个国家的做法**。各国的学位制度、科研评估和版权法都不同，**具体做法以你所在国家、学校和目标出版社的规定为准** `[本项目分析]`。

**读完本文，你应该能：**

- 分清"关于艺术的研究"和"以实践为方法的研究"，知道自己的项目属于哪一类；
- 说清一件作品要满足什么条件才算研究，以及怎样用文字说明它的贡献；
- 知道英国科研评估怎样评价展览、演出、作曲这类成果；
- 知道艺术研究常用哪几种研究套路，每种通常靠什么证据；
- 在论文里使用作品图像、录音前，知道要先查清哪些版权问题；
- 和参与者、社区合作时，知道有哪些额外的责任。

## 本领域研究怎样运转

### 先分清两类研究

经济合作与发展组织（OECD）的《Frascati 手册》是各国统计研发活动用的手册。它建议把三件事分开：为艺术的研究、关于艺术的研究、艺术表达本身[^oecd2015frascati-e11]。对新手最重要的是后两种的区别（表中没有脚注的格子是本项目的归纳 `[本项目分析]`）：

| | 关于艺术的研究 | 以实践为方法的研究 |
|---|---|---|
| 例子 | 艺术史、音乐学、戏剧研究[^oecd2015frascati-e12] | 创作作品，作品是知识贡献的基础[^candy2006practice-e1] |
| 证据 | 作品、文献、档案等资料 | 作品本身，加上过程记录和文字分析[^candy2006practice-e5] |
| 成果 | 主要是文字 | 作品加"研究叙述"（见下文）[^bulley2021practice-e5] |
| 最接近的已有学科篇 | [历史与考古](../history-archaeology/README.md) | 本文第二类；研究方法里的[行动研究](../../06_methods/action_research.md)有相通之处 |

### 第一类：关于艺术的学术研究

艺术史和音乐学研究过去的作品、文献和档案，**资料批判和档案工作的方法与历史学相通** `[本项目分析]`。一手和二手资料的区分、资料批判，见历史与考古篇的["证据"在这里指什么](../history-archaeology/README.md#证据在这里指什么)；怎样查档、做笔记，见同篇的[在档案馆里工作](../history-archaeology/README.md#在档案馆里工作)。下面只讲艺术史特有的几点，依据是美国大学艺术协会（College Art Association，CAA，美国艺术史学者和艺术家的专业学会）2014 年的《艺术史实践标准》。这是美国学会的职业规范，目前没有强制执行条款[^caa2014standards-e12]。

- **记录发现，公开证据。** 艺术史学者要仔细记录发现，向他人提供所用的资料、证据和数据，不歪曲证据、不抄袭[^caa2014standards-e1]。学术诚信还要求意识到个人和文化偏见[^caa2014standards-e2]。
- **照片和"边角里的意见"也要注明来源。** 不只是观点和文字，照片的来源也要注明[^caa2014standards-e3]。其他学者写在素描衬板上、照片背面、博物馆档案里的意见，甚至口头告诉你的意见，相关时都应引用[^caa2014standards-e4]。
- **发现的一手资料要分享。** CAA 说，发现一手资料的人有道德义务和同行分享，并应争取三年内发表[^caa2014standards-e7]。利用自己的影响让档案保管方为自己预留资料，是不当行为[^caa2014standards-e8]。
- **警惕利益冲突。** CAA 建议婉拒艺术家赠送的作品，认为这样能保证学术过程的公正[^caa2014standards-e9]。
- **和学生合作要给足认可。** 老师和学生合作发表时，学生做的部分要得到充分认可[^caa2014standards-e11]。

**出书。** CAA 的标准提到，要在"艺术史专著出版机会在减少"的情况下评价学术成果[^caa2014standards-e14]。CAA 还说明，书稿同时投给多家出版社并不违反职业伦理，只要告知各家[^caa2014standards-e13]。这是美国学会对书稿的说法；期刊论文另有规定，以目标期刊和出版社的要求为准 `[本项目分析]`。博士论文怎样改成书，可参考[历史与考古篇](../history-archaeology/README.md#专著和博士论文变成书)。

### 第二类：以实践为方法的研究

**几个名字。** 英文里 practice-based research（基于实践的研究）和 practice-led research（实践引导的研究）常被混用[^candy2006practice-e16]。澳大利亚悉尼科技大学的研究中心"创造力与认知工作室"2006 年发表了一份面向研究生的报告，作者 Linda Candy。她这样区分：创作成果是知识贡献的基础，叫"基于实践的研究"；研究主要带来对实践的新理解，叫"实践引导的研究"[^candy2006practice-e1]。后者的博士论文可以完全用文字写，不必附作品[^candy2006practice-e3]。英国还常说 practice research（实践研究）。英国实践研究顾问组（PRAG-UK）2021 年发表了一份报告，依据是对英格兰 62 位实践研究者、理论学者、科研支持人员和政策制定者的调研[^bulley2021practice-e8]。它的定义是：实践是研究成果所传达的主要方法[^bulley2021practice-e1]。欧洲则常说 artistic research（艺术研究）。欧洲音乐院校协会（AEC）等十个欧洲组织[^aec2020vienna-e9] 2020 年联合发表了《维也纳艺术研究宣言》，把艺术研究定义为艺术领域中基于实践、由实践引导的研究[^aec2020vienna-e1]。它覆盖建筑、设计、电影、摄影、美术、媒体与数字艺术、音乐和表演艺术等所有艺术门类[^aec2020vienna-e8]。

**做作品不等于做研究。** 这是新手最需要想清楚的一点：

- Candy 指出，从业者日常也会做一些"研究"，但那多是为了个人当下的目标，不是为大家共享的知识添加东西[^candy2006practice-e4]。
- PRAG-UK 的报告说，好的实践不一定是好的实践研究，反之亦然；实践要成为研究，**研究必须被说清楚**[^bulley2021practice-e2]。报告引用的一句话说得更直接：做好研究不在于做出成功的作品，而在于产生新的洞见[^bulley2021practice-e3]。
- Candy 认为，博士层次的新知识要能分享、能被核验或质疑[^candy2006practice-e8]。默会知识（只在你身上、没有分享出来的"手感"）不算这个意义上的知识[^candy2006practice-e9]。

**研究要有问题、背景和方法。** Candy 的报告列出了研究的三个条件：提出研究问题；说明研究背景；说明回答问题的方法[^candy2006practice-e7]。这和[核心术语](../../00_start-here/key-concepts.md)、主线章节[从研究问题到证据清单](../../02_from-project-to-study/01_question-to-evidence.md)讲的一致；不同的是，在这里"方法"本身可以是创作 `[本项目分析]`。

**边做边记录过程。** Candy 说，实践成果必须配上研究过程的记录，以及文字分析或说明，用来支撑立场、展示批判性反思[^candy2006practice-e5]。她给的具体做法：

1. 用在线日记、博客或手写笔记本持续记录[^candy2006practice-e10]；
2. 反思要排进日程，不要只是想起来才做[^candy2006practice-e10]；怎样给记录分类、留存，见[整理科研材料](../../08_throughout/organizing_materials.md#5-分清三种笔记)。

**用文字说清贡献。** 作品本身不是解释，需要文字把作品的发展和性质，与对创作过程的理解联系起来[^candy2006practice-e11]。Candy 说，主张的意义和背景用文字说明，但完整理解必须直接看作品[^candy2006practice-e2]。PRAG-UK 把这段文字叫作"研究叙述"（research narrative），发现多数情况下，把研究叙述和实践结合起来是分享认识的有效方式[^bulley2021practice-e5]。他们也说，不必觉得非得用非线性、跨媒介的复杂形式；有时期刊论文或书的一章就是写研究叙述最合适的地方[^bulley2021practice-e6]。

**博士论文要定位作品。** Candy 写道：基于实践的博士论文必须对作品做充分的背景定位[^candy2006practice-e6]；如果有作品参加答辩，她建议的论文结构里，介绍新研究的那一章至少要说明作品中什么是重要的、新的[^candy2006practice-e17]。她在回顾这类学位的由来时还提到一条规定：存到图书馆的论文要包含参加答辩的作品的永久记录[^candy2006practice-e15]。各校对作品、论文字数和答辩形式的规定不同，以你所在学校的规定为准 `[本项目分析]`。

### 怎样评价：以英国 REF 2021 为例

英国的"科研卓越框架"（Research Excellence Framework，REF）是英国高等教育资助机构定期评估各大学科研的制度 `[本项目分析]`。它的 2021 轮文件把怎样评价实践成果写得很具体，可以当作一份"怎样说明作品的研究成分"的清单 `[本项目分析]`。这是英国的制度，其他国家另有做法。

- **研究的定义。** REF 把研究定义为"一个带来新洞见、并被有效分享的探究过程"[^ref2019guidance-e1]；创造想法、图像、表演、作品（含设计），只要带来新的或显著改进的洞见，就算研究[^ref2019guidance-e2]。
- **成果形式很宽。** 艺术与设计评估单元预计会收到文本、编著、创作实践、作品、活动和策展成果[^ref2019panel-e6]；音乐、戏剧、舞蹈、电影等评估单元预计会收到作品、创作实践、策展、编著、录音和文字[^ref2019panel-e7]。一项成果可以同时是几种类型，例如已经演出或录音的作品，或研究体现在策展上的展览[^ref2019panel-e8]。
- **300 词说明。** 研究成分在作品里看不出来时，要附文字说明[^ref2019guidance-e3]。艺术与人文评审组（Main Panel D）强烈建议提交一份不超过 300 词的说明[^ref2019panel-e1]，讲清三件事：**研究过程**（问题、发现过程、方法、所依托的创作或学术背景）[^ref2019panel-e2]、**研究洞见**（发现或创作成果）[^ref2019panel-e3]、**传播**（在哪里、怎样被有效分享）[^ref2019panel-e4]。
- **评什么，不看什么。** 评审组评估原创性、重要性和严谨性，并会忽略自我评价质量的材料[^ref2019panel-e5]。所以说明里写"这是一场广受好评的演出"没有用，要写清问了什么、怎样做、发现了什么 `[本项目分析]`。
> **不同的看法：艺术创作本身算不算研究？**
>
> - **OECD《Frascati 手册》（2015，研发统计手册）**：艺术表演通常不算研发，因为它追求新的表达，而不是新知识[^oecd2015frascati-e13]。艺术有创造性，但其他标准（新颖、结果不确定、系统、可转移或可复现[^oecd2015frascati-e16]）也要满足才算[^oecd2015frascati-e15]。不过，高校如果凭艺术表演给艺术家授博士学位，要逐案判断[^oecd2015frascati-e14]。
> - **《维也纳宣言》（2020，欧洲组织的政策文件）**：优秀的艺术研究是通过高水平艺术实践和反思进行的认识探究[^aec2020vienna-e2]。它主张艺术研究通过同行评议来认定，评议者要覆盖作品涉及的各项学科能力[^aec2020vienna-e4]。宣言还呼吁把艺术研究列为 Frascati 手册中的独立类别[^aec2020vienna-e5]，并说艺术研究总体上拿不到和其他领域同等的研究资助，有时根本没资格申请[^aec2020vienna-e6]。注意它是写给政策制定者和资助机构的倡议文件[^aec2020vienna-e7]。
> - **英国 REF 2021**：见上一节的定义。
>
> **实际操作**：几方的共同点是，创作要带来能被分享、能被检验的新认识才算研究。所以不管你所在的制度怎样定义，都把研究问题、方法和洞见写清楚 `[本项目分析]`。

### 发表与传播

- **形式多样。** 除了论文和专著，还有展览、演出、录音、策展[^ref2019panel-e6][^ref2019panel-e7]。《维也纳宣言》说，艺术研究包含许多不是（或不只是）文字的东西，如作品、动作、声音[^aec2020vienna-e3]。例如《艺术研究期刊》（Journal for Artistic Research）有一个叫 Research Catalogue 的研究库，用"展陈"（exposition）的形式发表[^bulley2021practice-e14]。
- **记录是读者唯一能看到的东西。** 绝大多数实践研究成果，读者没法亲身体验实践本身，只能看"记录"[^bulley2021practice-e4]。演出、装置结束就没了，**记录要在创作时就计划好** `[本项目分析]`。
- **别让成果散落各处。** 这份英格兰 62 人的报告说，实践研究成果的各部分常分散在商业视频音频平台、机构知识库、博客、个人网页等多处[^bulley2021practice-e7]。尽量把作品记录和研究叙述一起存进学校的机构知识库 `[本项目分析]`。
- **照顾无障碍。** 同一份报告提醒，多媒体内容要配足够的描述文字，尽量提供文字稿[^bulley2021practice-e9]。

## 和其他学科不同的地方

下表只列本文资料能支持的几点，没有脚注的格子是本项目的归纳 `[本项目分析]`：

| | 艺术（以实践为方法的研究） | 艺术史 / 音乐学 | 计算机（对照） |
|---|---|---|---|
| 主要成果 | 作品加研究叙述[^bulley2021practice-e5]；展览、演出、录音、策展[^ref2019panel-e7] | 文字，包括专著[^caa2014standards-e14] | 会议论文（见[计算机篇](../computer-science/README.md)） |
| 证据 | 作品本身，加过程记录[^candy2006practice-e5] | 作品、文献、档案等资料 | 新方法要用评估证明更好（见计算机篇） |
| 读者怎样看到研究 | 多数只能看记录[^bulley2021practice-e4] | 读文字和图版 | 读论文，部分方向还看代码和数据（见计算机篇） |
| 是否算"研究" | 各方定义不同（见上文"不同的看法"） | 大多属于基础或应用研究（OECD）[^oecd2015frascati-e12] | — |
| 版权 | 作品里用他人素材要产生新意义（美国 CAA）[^caa2015fairuse-e10] | 论文里用图像要有分析目的（美国 CAA）[^caa2015fairuse-e3] | — |

## 本领域的规范和伦理

通用的伦理原则见贯穿全程的[科研诚信与伦理](../../08_throughout/integrity_and_ethics.md)。下面只讲本领域特有的部分。

### 在论文里用作品图像和录音：先查版权

艺术研究常要用到别人的作品：论文里的图版、讲座里的录音片段、创作里引用的素材。**能不能用、要不要付费，取决于你在哪个国家发表、素材受什么法律和合同约束** `[本项目分析]`。下面是 CAA 2015 年《视觉艺术合理使用最佳实践准则》的要点。合理使用（fair use）是美国版权法的一部分，这份准则只适用于在美国的使用[^caa2015fairuse-e1]。其他国家的版权例外规则不同，下面只补中国。

**中国**：《中华人民共和国著作权法》（2020 年修正）[^npc2020copyright-e1]第 24 条逐项列出可以不经许可、不付报酬使用作品的情形。和写论文、上课最直接相关的是两项：为介绍、评论某一作品或说明某一问题，在自己的作品里适当引用他人已发表的作品[^npc2020copyright-e3]；教学或科研人员为课堂教学或科学研究，翻译、改编、汇编、播放或少量复制已发表的作品，但不得出版发行[^npc2020copyright-e4]。不管用哪一项，都要指明作者姓名或名称、作品名称，不得影响作品的正常使用，也不得不合理地损害著作权人的合法权益[^npc2020copyright-e2]。上面依据的是全国人大网站的英文译本，以中文官方文本为准；法条没有说引用多少才算"适当"，你的用法算不算其中一项，要问学校版权部门或出版社 `[本项目分析]`。

**写论文时**，学者（及其出版社）可以援引合理使用来引用、节选或复制作品[^caa2015fairuse-e2]，但要满足：

- 使用由分析目的支撑，并准备好说明理由[^caa2015fairuse-e3]；
- 分析目的要压过"单纯展示作品"[^caa2015fairuse-e4]；
- 图像的尺寸和分辨率不超过分析所需[^caa2015fairuse-e5]；
- 按本领域惯例注明原作信息[^caa2015fairuse-e6]。

**合理使用管不到的情况**：

- 有许可协议或其他合同约束复制和使用的[^caa2015fairuse-e9]；
- 藏品方收取的图像费用，不能用合理使用来免除[^caa2015fairuse-e8]；
- 公有领域的作品本来就不需要它[^caa2015fairuse-e14]。CAA 还提醒，美国的 Bridgeman 判例（它处理的是平面作品的翻拍照片 `[本项目分析]`）不当然适用于雕塑、建筑、表演艺术这类立体作品的照片[^caa2015fairuse-e13]。

**创作时**，用他人作品要产生新的艺术意义，只是换个媒介可能不够[^caa2015fairuse-e10]；要注明来源，除非有说得出的美学理由[^caa2015fairuse-e11]。

**别过度自我审查。** 制定这份准则前，CAA 调查了近 12,000 名会员，并做了 100 次访谈[^caa2015fairuse-e12]。调研发现，很多美国视觉艺术从业者以为一定要取得许可，即使本可以放心地使用合理使用[^caa2015fairuse-e7]。CAA 2014 年的标准也提醒，人们对合理使用和知识产权的理解变化很快，要找最新的资料[^caa2014standards-e10]。

**音乐和录音。** 本文资料没有找到音乐学界关于乐谱、录音引用的专门指南。美国民族音乐学会（Society for Ethnomusicology，SEM）认为，成员需要了解版权以及有关知识产权和文化财产的法律[^sem1998ethics-e5]；PRAG-UK 的报告也指出，实践研究常用多媒体记录，版权和授权问题特别复杂[^bulley2021practice-e10]。具体以目标出版社和学校版权办公室的意见为准。

### 和参与者、社区合作

演出、参与式艺术、社区项目、田野录音都会涉及人 `[本项目分析]`。Candy 的报告说，研究涉及人时，开始前必须取得知情同意[^candy2006practice-e13]。PRAG-UK 的报告指出，实践研究者有时没有考虑人类参与者的伦理问题[^bulley2021practice-e11]；出于伦理考虑，有些项目（例如护理、丧亲主题的）很难公开分享[^bulley2021practice-e13]；参与制作的人，都要被列出、被提到[^bulley2021practice-e12]。

研究在世的音乐和艺术传统时，下面是美国两个学会（SEM 和 CAA）的要求。SEM 自己也承认，这些伦理价值不一定代表各地所有从业者[^sem1998ethics-e7]：

- **关系建立在知情同意和尊重上。** SEM 1998 年的伦理声明要求田野研究建立在知情同意、隐私和保密权、相互尊重的基础上[^sem1998ethics-e1]，对录音、照片的所有权问题保持敏感[^sem1998ethics-e2]。
- **责任是长期的。** 田野研究的责任超出田野现场，往往是对合作者及其社区的长期承诺[^sem1998ethics-e3]。田野研究可能为日后意想不到的、甚至剥削性的录音使用创造条件[^sem1998ethics-e4]。
- **把成果和资料还给社区。** CAA 说，艺术史学者常常没有考虑东道社区，没有把成果或田野资料留给社区[^caa2014standards-e6]。它要求研究在世艺术传统的学者，存放与发表相关的全部田野资料的原件或副本，并在社区里留一份发表的成果[^caa2014standards-e5]。
- **署名和致谢。** 发表时要给合作者、同事、学生应有的认可[^sem1998ethics-e6]。

**和一般访谈研究的区别。** SEM 2008 年的立场声明认为，美国大学伦理审查委员会（Institutional Review Board，IRB）强调匿名、要求项目结束后销毁记录，这与民族音乐学的工作方式格格不入[^sem2008irb-e1]。它主张研究记录对历史记录也很重要，应当归档保存[^sem2008irb-e3]；取得许可的方式要看当地文化[^sem2008irb-e2]。这份声明针对的是 2018 年修订前的美国规则 `[本项目分析]`。是否需要伦理审批、能否公开受访者身份，以你所在机构的伦理审查委员会为准。这一点和口述历史相近，见[历史与考古篇](../history-archaeology/README.md#口述历史受访者的同意和控制权)。

## 常用套路与证据标准

**研究套路**指一个项目主要靠什么逻辑产生新知识，按核心主张来定，见[核心术语](../../00_start-here/key-concepts.md#研究套路)和[研究套路](../../05_research-strategies/README.md)。下表只列本文资料能支持的五种。

表的分组和"在艺术里的样子"一栏是本项目的归纳；每条标准只代表脚注里那个机构、那个国家或那篇文章的做法 `[本项目分析]`。表里的测量一行属于音乐认知（也叫音乐心理学），它和心理学交叉，通用规矩见[心理学篇](../psychology/README.md) `[本项目分析]`。其他套路本文资料未涉及。

| 套路 | 在艺术里的样子 | 常用证据和评判标准 | 具体做法 |
|---|---|---|---|
| [构建改进](../../05_research-strategies/build_improve.md) | 基于实践的研究：创作出的作品是知识贡献的基础[^candy2006practice-e1] | 作品加过程记录和文字分析，用来展示批判性反思[^candy2006practice-e5]；新知识要能分享、能被核验或质疑[^candy2006practice-e8]；英国 REF 2021 评原创性、重要性和严谨性，忽略自我评价质量的材料[^ref2019panel-e5]；《维也纳宣言》主张由覆盖作品所涉各项学科能力的同行评议来认定[^aec2020vienna-e4] | [基于实践的研究](practices/practice_based_research.md) |
| [解读论证](../../05_research-strategies/interpret_argue.md) | 艺术史、音乐学、戏剧研究等关于艺术的研究[^oecd2015frascati-e12]，研究作品、文献和档案 | 仔细记录发现，向他人公开所用的资料、证据和数据，不歪曲证据（美国 CAA）[^caa2014standards-e1]；照片来源、他人口头或手写的意见，相关时都要注明[^caa2014standards-e3][^caa2014standards-e4] | [档案研究](../../06_methods/archival_research.md)；资料批判见[历史与考古篇](../history-archaeology/README.md#证据在这里指什么) |
| [测量](../../05_research-strategies/measure.md) | 音乐认知的实验：用行为任务测听者怎样感知节奏、音高、情绪等，也做跨文化比较；实证美学和音乐科学期刊的投稿要求见表后 | 本行出自 2020 年一篇 20 位作者的立场文章，源于德国马克斯·普朗克实证美学研究所 2018 年的研讨，作者说明它不是完整清单[^jacoby2020crosscultural-e3]。文章指出，音乐心理学的被试几乎都来自 WEIRD 社会（Western, Educated, Industrialized, Rich, Democratic，即西方、受过教育、工业化、富裕、民主），材料也多取自西方音乐[^jacoby2020crosscultural-e1]，结论不一定代表全人类[^jacoby2020crosscultural-e2]。建议：外来的概念、记谱法或量表，别不经确认就用在另一种音乐文化的被试身上[^jacoby2020crosscultural-e5]；跨文化用评分量表，要做控制实验确认被试看懂了，材料要和熟悉该文化的专家一起预试[^jacoby2020crosscultural-e6]；也可改用打拍、唱旋律这类不靠语言的任务[^jacoby2020crosscultural-e7]；想更贴近真实的音乐生活（生态效度），就用更多样的音乐和表演场景，但要和实验控制取舍[^jacoby2020crosscultural-e8] | [对照实验](../../06_methods/controlled_experiment.md)；被试和量表的通用要求见心理学篇的[被试：学生样本和 WEIRD 样本](../psychology/README.md#被试学生样本和-weird-样本)、[测量：用有效度证据的量表](../psychology/README.md#测量用有效度证据的量表) |
| [观察描述](../../05_research-strategies/observe_describe.md) | 民族音乐学和在世艺术传统的田野研究：观察、参与、访谈、录音 | 田野笔记、录音、照片等记录对历史记录也重要，应当归档保存（美国 SEM）[^sem2008irb-e3]；相关田野资料要存放，并在社区里留一份发表的成果（美国 CAA）[^caa2014standards-e5]；怎样判断描述够不够，本文资料未涉及 | [案例研究与民族志](../../06_methods/case_study.md)、[访谈研究](../../06_methods/interview_study.md) |
| [综合](../../05_research-strategies/synthesize.md) | 艺术与健康研究的综述：汇总来自不同学科、用不同方法的研究 | 本行只出自一篇报告：世卫组织欧洲区域办事处 2019 年发布的 Fancourt 和 Finn 的范围综述（先摸清有哪些证据，见[综合](../../05_research-strategies/synthesize.md)里的映射研究）。它的目标是尽量广地呈现已有证据，不按研究方法筛选[^fancourt2019evidence-e1]；作者说明没有做系统检索，选范围综述而不选系统综述，是为了不受研究设计和结局指标的限制，作者认为这对如此跨学科的领域很重要[^fancourt2019evidence-e2]；证据质量参差，报告对照优势不同的多项研究的发现（三角互证），来弥补单项研究的弱点和偏倚[^fancourt2019evidence-e3]；只检索了英文和俄文文献[^fancourt2019evidence-e4]。艺术史、音乐学等方向的综述标准，本文资料未涉及 | [综述研究](../../06_methods/review_study.md) |

怎么用这张表 `[本项目分析]`：

- **先分清是哪一类研究**（见[先分清两类研究](#先分清两类研究)），再按核心主张找套路。实践引导的研究主要带来对实践的新理解[^candy2006practice-e1]，常落在行动研究的大范围里[^candy2006practice-e3]；它归入哪种套路，套路页暂未讨论，按你的核心主张来定。
- **同一种套路，艺术里的"够不够"和别的学科很不同。** 基于实践的研究也是"做出新东西"，但一般不和基线比较（见[构建改进](../../05_research-strategies/build_improve.md#5-哪些学科常用)）；关键是把研究说清楚，好的实践不一定是好的实践研究[^bulley2021practice-e2]。

**实证美学和音乐科学期刊的投稿要求。** 下面是两本期刊投稿说明的要点（据 2024 年的网页存档），只代表这两本期刊：

- 《Psychology of Aesthetics, Creativity, and the Arts》（美国心理学会第 10 分会的期刊）刊发原创实证研究和对已有研究的综合评价，一般不鼓励质性研究、案例研究和文献综述[^apa2024aesthetics-e1]。它接收注册报告：先投引言和方法（含假设、用统计功效分析确定的样本量、分析流程），这一步通过，无论结果如何原则上都接收[^apa2024aesthetics-e2]（来龙去脉见心理学篇的[之后改了什么](../psychology/README.md#之后改了什么)）。投稿说明里写着，美国心理学会期望作者在审稿期间和发表后至少 5 年内能提供数据[^apa2024aesthetics-e3]；该刊还建议描述被试样本，并说明结论推广范围的限制[^apa2024aesthetics-e4]。
- 《Music & Science》（Sage 出版）要求随文提交原始数据（如统计数据文件、复现代码、音频、视频），或在文中详细说明怎样获取[^sage2024musicscience-e1]，并标注清楚，让审稿人或读者能重做你的分析[^sage2024musicscience-e2]。方法部分要说明被试是否知情同意、是书面还是口头同意[^sage2024musicscience-e4]。审稿是双盲的，至少两位审稿人[^sage2024musicscience-e3]。

## 给新手的建议

1. **先确定你做的是哪一类研究。** 关于艺术的研究和以实践为方法的研究，对证据和成果的要求不同。实践类的，再弄清学校用的是哪个名称和定义[^candy2006practice-e16]。
2. **用一句话写出研究问题。** 研究要有问题、背景和方法[^candy2006practice-e7]。"我想做一组作品"不是研究问题 `[本项目分析]`。
3. **从第一天起记录过程。** 用日记或笔记本持续记录，把反思排进日程[^candy2006practice-e10]；演出和装置的记录要提前计划 `[本项目分析]`。
4. **用 300 词练习说清贡献。** 按 REF 的三项（研究过程、研究洞见、传播）写一段说明[^ref2019panel-e2][^ref2019panel-e3][^ref2019panel-e4]。即使你不在英国，这也是检验"研究是否说清楚"的好办法 `[本项目分析]`。
5. **发表前先清点图像和录音的权利。** 列出每张图、每段录音的来源、权利人和你打算依据的理由（许可、合理使用或公有领域），并问出版社的要求 `[本项目分析]`。在美国，合理使用要有分析目的并能说明理由[^caa2015fairuse-e3]。
6. **涉及人或社区时，先过伦理审批，并想好资料的去向。** 开始前取得知情同意[^candy2006practice-e13]；田野资料考虑归档并还给社区[^caa2014standards-e5][^sem2008irb-e3]。
7. **研究在世艺术家时，避开利益冲突。** CAA 建议婉拒艺术家赠送的作品[^caa2014standards-e9]。

## 常见错误

| 错误 | 为什么是问题 |
|---|---|
| 把作品集当成研究 | 好的实践不一定是好的实践研究，研究必须被说清楚[^bulley2021practice-e2]；日常创作多为个人目标，不是为共享知识添加东西[^candy2006practice-e4] |
| 只交作品，不写文字说明 | 作品本身不是解释[^candy2006practice-e11]；英国 REF 在研究成分看不出来时要求附文字说明[^ref2019guidance-e3] |
| 说明里写作品多受欢迎，不写问了什么、发现了什么 | REF 评审组会忽略自我评价质量的材料[^ref2019panel-e5]，评的是原创性、重要性和严谨性 |
| 演出结束后才想起记录 | 绝大多数实践研究成果，读者只能通过记录了解[^bulley2021practice-e4] |
| 以为"学术用途"就可以随便用图 | 合理使用是美国法律，只适用于在美国的使用[^caa2015fairuse-e1]；有合同约束时它不适用[^caa2015fairuse-e9]，藏品方的收费也不能靠它免除[^caa2015fairuse-e8] |
| 反过来，每张图都觉得必须买授权 | CAA 的调研发现，很多美国从业者在本可以使用合理使用时也以为必须取得许可[^caa2015fairuse-e7] |
| 只注明作品，不注明照片来源和别人的口头提示 | CAA 要求照片来源、他人口头或手写的意见相关时都要注明[^caa2014standards-e3][^caa2014standards-e4] |
| 田野录音带走就不管了 | 责任是长期的[^sem1998ethics-e3]；CAA 要求把资料和成果留给东道社区[^caa2014standards-e5] |

## 本学科常用的研究方法

做法分两类：只在艺术里用的研究实践，放在艺术篇的 `practices/`；别的学科也用的研究方法，放在[研究方法](../../06_methods/README.md)目录。它们分别服务哪种套路，见上文[常用套路与证据标准](#常用套路与证据标准)。借用跨学科方法时要注意的差异，是本项目的归纳 `[本项目分析]`：

- **艺术特有：**[基于实践的研究](practices/practice_based_research.md)。创作作品，作品是知识贡献的基础[^candy2006practice-e1]；成果是作品、记录加研究叙述。
- [档案研究](../../06_methods/archival_research.md)：艺术史、音乐学研究作品、手稿、信件和机构档案。
- [综述研究](../../06_methods/review_study.md)：写文献综述时可参考它的检索和取舍思路，不必照搬系统综述的流程；不要转引，要回到原文[^candy2006practice-e12]。
- [对照实验](../../06_methods/controlled_experiment.md)：音乐认知的实验。差异见上文[常用套路与证据标准](#常用套路与证据标准)的测量一行：被试和材料不要只限于西方，跨文化用量表要先确认被试看懂了。
- [案例研究与民族志](../../06_methods/case_study.md)、[访谈研究](../../06_methods/interview_study.md)：民族音乐学和在世艺术传统的田野研究。差异见上文：往往不匿名、资料要归档并还给社区。
- [行动研究](../../06_methods/action_research.md)：实践引导的研究常落在它的大范围里[^candy2006practice-e3]，可参考它"计划—行动—反思"的循环；差异是，这里改进的常常是研究者自己的创作实践，而不是一个合作组织。
- 设计研究可参考教育学的[基于设计的研究](../education/practices/design_based_research.md)。Candy 指出，设计研究更多研究"设计实践怎样运转、怎样改进"，常由专门的研究者而不是设计师来做；视觉艺术更重创作过程和由此产生的作品[^candy2006practice-e14]。

## 延伸阅读

- **Candy 2006，Practice Based Research: A Guide**：澳大利亚一个研究中心的报告，讲基于实践和实践引导的区别、博士论文结构、怎样写反思记录。适合做创作类博士的人先读。
- **Bulley & Şahin 2021，Practice Research（PRAG-UK 报告）**：基于英格兰 62 人调研的两份报告，讲什么是实践研究、研究叙述、怎样分享和保存成果。开放获取。
- **REF 2021，Panel criteria and working methods（REF 2019/02）**：第 264–267 段讲艺术与人文评审组怎样看实践成果的说明，可当作写成果说明的清单；研究的定义见 REF 2019/01 附录 C。
- **The Vienna Declaration on Artistic Research（2020）**：两页的欧洲政策文件，了解艺术研究在欧洲的定位和诉求。
- **CAA，Code of Best Practices in Fair Use for the Visual Arts（2015）**：在美国发表艺术图像前必读；其他国家的读者可以借它理解"为什么要说明使用理由"。
- **CAA，Standards for the Practice of Art History（2014）**：美国艺术史学者的研究、发表、利益冲突和社区责任。
- **SEM，Position Statement on Ethical Considerations（1998）**：美国民族音乐学会对田野研究伦理的立场声明。
