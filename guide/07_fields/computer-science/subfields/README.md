# 计算机各方向

计算机内部各方向差别很大：发表在哪里、审稿看什么、证据要做到什么程度，都不一样。为什么要按方向看，见[计算机学科概况：各方向的惯例不一样](../README.md#各方向的惯例不一样)。

这一层只写**各方向特有的做法**。其他内容在别处：

- 各学科通用的做法（选题、计划、写作、审稿）见第一部分、第二部分、写作和发表各章；某类研究的一般逻辑和证据标准见[研究套路](../../../05_research-strategies/README.md)。
- 计算机共通的规矩（以会议为主、双盲与预印本、制品评估）见[计算机学科概况](../README.md)。
- 计算机特有的具体做法（工程研究、基准评测、仓库挖掘等）见[计算机特有的研究实践](../practices/README.md)。

## 怎样用这一层

- **先读计算机学科概况，再读你的方向页。** 方向页默认你已经知道会议、双盲、制品评估是怎么回事。
- **方向交叉时，两页都读。** 例如用机器学习做程序分析，要同时满足两边审稿人的期待；最后以你要投的会议所在方向为准。
- **方向页里的会议规定都是某个会议某一年的。** 它们是例子，不是整个方向的规矩；投稿前一定读目标会议当年的征稿启事。
