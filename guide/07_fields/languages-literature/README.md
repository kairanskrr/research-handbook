# 语言与文学：领域概况

> **状态**：初稿，待审阅 · **最后更新**：2026-10-06

本文讲语言与文学领域的研究实际怎样运转。这个领域里有两个差别很大的传统：**文学研究**（细读文本、提出阐释、做档案和版本工作）和**语言学**（到社区做田野调查、建语料库、做实验）。下文分开讲，不要把一边的做法直接套到另一边 `[本项目分析]`。各学科共通的做法（选题、读文献、写作、科研诚信）见[通用篇](../../general/README.md)，这里不重复。

本文的资料主要来自两个美国学会：语言学部分依据美国语言学会（Linguistic Society of America，LSA）的伦理声明和决议，以及语言学者联名的数据引用立场声明；文学部分依据美国现代语言协会（Modern Language Association，MLA，美国研究语言和文学的学会）的报告、指南和格式网站，以及美国北卡罗来纳大学写作中心、英国约克大学英语系的两份免费讲义。这两份讲义只是这两所学校给学生的教学材料，不是学科规范。所以文中写到某个学会或学校的要求时，指的是**那个学会、那所学校、那个国家的做法**。各国的伦理审查制度、学术评价和出版惯例不同，**具体做法以你所在国家、机构和目标期刊的规定为准** `[本项目分析]`。

按 OECD 学科分类，"6.5 其他人文学科"没有单独的领域篇，请根据你的研究内容参考本篇、[历史与考古](../history-archaeology/README.md)或[哲学、伦理与宗教](../philosophy-ethics-religion/README.md)。

**读完本文，你应该能：**

- 分清文学研究和语言学两个传统，知道自己的课题属于哪一边；
- 知道怎样从细读出发，围绕文本建立一个有证据的论证；
- 理解为什么美国的文学研究以专著为中心，以及 MLA 格式怎样引用；
- 知道做语言田野调查时，对发音人和社区各有哪些责任；
- 知道语言数据为什么要存档、要引用，以及怎样让语料库和实验研究经得起检查。

## 本领域研究怎样运转

### 先分清两个传统

下表是本项目的概括 `[本项目分析]`，有出处的格子另加了脚注。一些课题横跨两边，例如用语料库研究文学文本的风格：文本解读部分按文学研究的标准，数据部分按语言学和数据科学的标准 `[本项目分析]`。

| | 文学研究 | 语言学 |
|---|---|---|
| 研究对象 | 文学文本（小说、诗歌、戏剧等）及其历史和文化背景 | 语言本身：语音、语法、意义、使用和变化 |
| 证据 | 文本的语言、意象、句法、形式[^yorkclosereading-e1]，以及反复出现的模式[^uncwritinglit-e12] | 录音录像、语料[^berezkroeker2018reproducible-e7]，以及语感判断[^berezkroeker2018reproducible-e9] |
| 成果（本文资料所见） | 美国：专著、期刊论文[^mla2007evaluating-e3][^mla2007evaluating-e5]，以及学术版本[^mlacseguidelines-e1] | 美国语言学会主张，除论文外，语法书、词典、文本集、语料库等也算学术成果[^lsa2010documentation-e2][^lsa2010documentation-e3] |
| 主要规范来源（本文） | 美国现代语言协会（MLA）的报告和格式 | 美国语言学会（LSA）的伦理声明，语言学者的数据引用原则 |

### 文学研究：从细读到论证

**细读**（close reading）是文学研究常用的基本方法 `[本项目分析]`。英国约克大学英语系的写作讲义引用学者 Showalter 的话说，细读是慢读：有意摆脱讲故事的魔力，去注意语言、意象、典故、互文、句法和形式[^yorkclosereading-e1]。它不是读"言外之意"，而是往字句里越读越深[^yorkclosereading-e2]。具体做法：

- **准确抄录引文，记下页码。** 有人把准确抄录看作细读的头条规则[^yorkclosereading-e3]；北卡罗来纳大学教堂山分校写作中心的讲义建议做笔记时记下页码，之后引用时不用重新翻书[^uncwritinglit-e7]。
- **从原文出发。** 盯着眼前的文字，不要从脑子里的转述出发[^yorkclosereading-e8]。
- **找模式和问题。** 北卡讲义建议，从两类地方找题目：反复出现的意象、词汇、形式或事件（模式）[^uncwritinglit-e12]；让你困惑、说不通的地方（问题）[^uncwritinglit-e5]。

**阐释要能论证。** 文学作品没有唯一答案，但这不等于怎么说都行；阐释有高下之分[^uncwritinglit-e2]。同一份讲义说，好的阐释要避开读者自己就能得出的显而易见的结论[^uncwritinglit-e4]，并用缜密的推理说明证据怎样支撑论点[^uncwritinglit-e3]。论点要能回答"那又怎样"（so what）[^uncwritinglit-e9]。两条实用规则：

- **只引不析不算论证。** 引了一段却不解释，就没有展示你的推理[^uncwritinglit-e8]。约克大学的讲义提出"二倍规则"：对引文的分析应是引文长度的两倍[^yorkclosereading-e7]。
- **工作论点会变。** 论点在变，说明你开始说出更有意思、更复杂的东西[^uncwritinglit-e6]。这和通用篇[写作](../../general/3_after/01_writing.md#6-尽早动笔把写作当作研究的一部分)说的"把写作当作研究的一部分"一致。

**使用理论和背景。** 文学研究者常把文本和更大的议题联系起来，例如经济、宗教、法律、政治、历史、环境等[^uncwritinglit-e10]。各种文学理论提供的是观察文本的角度，不是现成的结论 `[本项目分析]`。北卡讲义提醒，不要带着预设的结论进入题目[^uncwritinglit-e11]。反过来，细读也被批评过脱离语境、远离文本的历史和政治关联[^yorkclosereading-e4]。约克大学的讲义说：要的是细读（close reading），不是封闭的阅读（closed reading）[^yorkclosereading-e5]；发现的东西不要罗列，要组织成论证[^yorkclosereading-e6]。

### 文学研究：档案和学术版本

研究作家的手稿、书信、不同版本时，你会进档案馆。查档的基本做法（先读检索指南、记下箱号和文件夹号、笔记分清照抄和转述）见[历史与考古](../history-archaeology/README.md#在档案馆里工作)，这里不重复。两者的一个区别是：历史学者主要把档案当作了解过去的证据，而文学研究者常常关心文本本身怎样形成、怎样变化，例如手稿和印本之间的改动 `[本项目分析]`。

**学术版本**（scholarly edition，经过考订、附有说明的作品版本）是文学研究的一类成果。美国现代语言协会（MLA）学术版本委员会的编者指南说，学术版本的基本任务是给出可靠的文本：说清承诺了什么，并且做到[^mlacseguidelines-e1]。它通常附校勘记，记录文本的改动和异文（不同版本之间不一样的文字）[^mlacseguidelines-e2]；编者还要制定并执行校对计划[^mlacseguidelines-e3]。学术版本在评职称时算多少分，各单位不同；如果你的博士课题以编版本为主，先和导师商量它在你所在单位怎样被评价 `[本项目分析]`。

### 文学研究：专著、期刊和引用格式

下面的数字来自 MLA 的一个工作组。这个工作组专门研究美国高校在**终身教职**（tenure，长期聘用、不能随意解聘的职位）**和晋升评审**中怎样评价学术成果，报告 2007 年发表。它在 2005 年春做了一次在线调查，对象是美国 734 所院校的 1,339 个系[^mla2007evaluating-e1]。报告自己说明，作答的院系不是美国四年制高校的代表性样本[^mla2007evaluating-e2]。所以这些数字只反映约二十年前、这批美国院系在终身教职评审上的看法 `[本项目分析]`。

- **专著很重要。** 在博士授予院校中，88.9% 的作答院系把出版专著列为终身教职评审中"非常重要"或"重要"的条件；硕士授予院校和本科院校分别是 44.4% 和 48%[^mla2007evaluating-e3]。博士授予院校中，49.8% 的院系要求第二本书已有进展[^mla2007evaluating-e4]。
- **但这是比较晚近的事**，工作组认为专著成为"金标准"并不久[^mla2007evaluating-e9]；人们预期博士论文修改后出版，也让院系更容易要求候选人出专著[^mla2007evaluating-e11]。
- **期刊论文同样受重视。** 只有 1.6% 的作答院系认为同行评审期刊论文在终身教职和晋升评审中"不重要"[^mla2007evaluating-e5]。工作组认为，期刊出版周期比书短，便于及时交流观点[^mla2007evaluating-e6]；一组同行评审论文可以和同样篇幅的专著一样、有时甚至更好地体现学术质量[^mla2007evaluating-e8]。
- **会议论文地位低。** MLA 2012 年发布的数字人文评价指南说，会议论文集在计算机领域是最有声望的发表形式之一，在人文学科一般被看作次一等[^mla2012digital-e1]。
- **其他。** 审稿周期、署名顺序等，本文资料未涉及，以导师和目标期刊、出版社的要求为准。

**引用格式。** MLA 格式由美国现代语言协会制定，美国的文学研究常用它 `[本项目分析]`；投稿时以目标期刊的要求为准。MLA 格式官网的免费页面说明：正文里用简短的文中引注，指向文末的"引用文献"（Works Cited）列表[^mlastylecenter-e1]；引用或转述具体段落时，作品有页码、行号或时间码的，必须在括号里给出[^mlastylecenter-e2]。被引作品属于一个更大的整体时，那个整体叫"容器"（container）[^mlastylecenter-e3]，例如收进选集的一篇短篇小说，选集就是容器 `[本项目分析]`。历史学许多人用的脚注体系（芝加哥格式）见[历史与考古](../history-archaeology/README.md#写作论证加叙事)。

### 语言学：田野调查和濒危语言

**田野调查**指到说某种语言的社区，和发音人（提供语言材料的人）一起记录、分析这种语言 `[本项目分析]`。一份 2018 年的语言学立场声明提醒，珍贵的濒危语言数据可能消失[^berezkroeker2018reproducible-e14]。美国语言学会（LSA）1992 年的一份声明说，研究一种语言常常依赖和说这种语言的人保持长期关系[^lsa1992humansubjects-e2]。下面几点来自 LSA 的这份声明和它 2019 年的伦理声明，是这个美国学会的主张：

- **社区从一开始就参与。** 要从项目规划的最早阶段请社区参与[^lsa2019ethics-e8]。
- **个人同意可能不够。** 在许多社区，语言和文化知识被看作集体的，个人无权单独同意把材料分享给外人[^lsa2019ethics-e6]。资料的查阅、存档和结果的传播，要遵从社区的意愿[^lsa2019ethics-e7]。
- **想好给什么回报**：报酬，或正式承认对方的贡献等[^lsa2019ethics-e5]。
- **把数据交还社区。** 尽可能把数据和知识交还社区保管；语言学者参与收集的数据，不都属于语言学者[^lsa2019ethics-e9]。
- **想清楚发表的后果**，例如会不会影响社区的社会地位，或社区和政治体制的关系[^lsa2019ethics-e10]。
- **署名还是匿名，看对方意愿。** 参与者常以掌握自己的语言为荣，可能希望被署名；不公开名字反而对不起他们[^lsa1992humansubjects-e3]。LSA 2019 年的伦理声明则说，参与者有权决定记录能不能和本人身份联系起来[^lsa2019ethics-e4]。两条合起来：事先问清，按对方的选择做 `[本项目分析]`。

LSA 2010 年的一项决议说，语言田野工作正在转向以对言语社区的伦理责任为基础的合作[^lsa2010documentation-e1]，并支持在学位授予、招聘、终身教职和晋升中，把语法书、词典、语料库、给社区用的教学材料等算作学术贡献[^lsa2010documentation-e2][^lsa2010documentation-e3]。

田野访谈的技巧可参考[访谈研究](../../06_methods/interview_study.md)。区别在于：访谈研究多以归纳主题为目的，常默认匿名 `[本项目分析]`；语言田野调查要长期记录语言本身，材料要存档供后人使用，署名与否看发音人的意愿（见上）。

### 语言学：语料库和实验

**语料库研究**用大量真实的语言材料做分析，涉及数据处理的部分可参考[数据科学](../../06_methods/data_science.md)。不同在于：语言学要求写清数据从哪里来、让读者能找到和核对（见下节）`[本项目分析]`。

**实验研究**（例如语音实验、心理语言学实验）和心理学的实验方法相通 `[本项目分析]`，可参考[心理学篇讲可重复性危机的部分](../psychology/README.md#一场可重复性危机改变了这个领域)。下面是一位作者的观点，不是学会规范：语言学者 Roettger 在 2019 年的文章中主张，语音学研究因为研究对象的特点，分析时可做的选择很多，这叫"研究者自由度"[^roettger2019researcher-e1]。他的建议：

- **分清探索和验证。** 可以探索数据，但不要把探索说成在检验事先的假设[^roettger2019researcher-e2]。见通用篇[研究设计](../../general/1_before/04_research_design.md#4-分清探索性研究和验证性研究)。
- **考虑预注册。** 预注册是带时间戳的文件，事先写明怎样收集数据、怎样做验证性分析[^roettger2019researcher-e3]。但他也说，到 2019 年时采用注册报告（先审研究方案、再做研究的论文形式）的定量语言学期刊还很少[^roettger2019researcher-e6]。
- **如实报告所有分析。** 测了十个参数，就要说测了十个[^roettger2019researcher-e4]。他认为这类问题多数时候不是故意的[^roettger2019researcher-e5]，所以更要靠事先定好的规矩来防 `[本项目分析]`。

### 语言学：数据引用和可复现

2018 年，Berez-Kroeker 等人在期刊 *Linguistics* 上发表了一份关于语言数据引用的立场声明，代表约 41 位同行的共同看法[^berezkroeker2018reproducible-e1]。它区分了两个概念：**可重复**（replicable）是别人重新收集新数据再检验；**可复现**（reproducible）是别人拿到你的原始数据独立分析[^berezkroeker2018reproducible-e2]。语言学者没法指望同行重造当初的数据收集条件[^berezkroeker2018reproducible-e3]，所以对田野数据来说，可复现更现实 `[本项目分析]`。

声明引用的一项调查（Gawne 等 2017）发现，2003—2012 年的 100 部描写语法（全面描述一种语言的著作）中，很少有作者写明方法或数据来源[^berezkroeker2018reproducible-e4]。声明的说法是，语言学有变成"请读者相信我们说的话"的危险[^berezkroeker2018reproducible-e5]。它建议：

- **写清数据怎么来的**：在什么条件下收集[^berezkroeker2018reproducible-e6]；数据来自内省（研究者自己或他人的语感判断）时，要明确说明[^berezkroeker2018reproducible-e9]。
- **让读者能定位到具体数据**：页码、语料行号、录音的起止时间码[^berezkroeker2018reproducible-e7]；同时顾及被录音者的隐私[^berezkroeker2018reproducible-e8]。
- **存进数据档案馆**，最好是承诺长期保存和开放的机构[^berezkroeker2018reproducible-e10]；格式不依赖专有软件[^berezkroeker2018reproducible-e15]。声明建议每位语言学者主动和一家档案馆建立联系[^berezkroeker2018reproducible-e13]。

另一份文件《奥斯汀语言学数据引用原则》（Austin Principles，2018 年 1.0 版）专门列出了引用语言数据的原则。要点：主张依据了哪些数据，就引用哪些数据[^berezkroeker2018austin-e1]；写明数据版本[^berezkroeker2018austin-e6]；让读者能找到那一条具体数据[^berezkroeker2018austin-e7]；选能提供持久标识符（例如 DOI，数字对象唯一标识符）的数据库[^berezkroeker2018austin-e5]；列出贡献者和各自的角色[^berezkroeker2018austin-e4]。数据应尽可能开放，必要时才限制[^berezkroeker2018austin-e3]；受限数据也可以引用，但只有不受限的数据才能被别人再利用[^berezkroeker2018reproducible-e11]。整理数据的通用做法见通用篇[整理科研材料](../../general/2_during/03_organizing_materials.md)。

## 和其他学科不同的地方

下表和[计算机领域](../computer-science/README.md)对照，只列本文资料能支持的几点 `[本项目分析，依据上文资料]`：

|---|---|---|---|
| 证据 | 文本的词句和形式，靠推理阐释[^uncwritinglit-e3] | 语言数据，要能被定位和核对[^berezkroeker2018austin-e7] | 用评估证明新方法更好（见计算机篇） |

| 会议论文 | 在人文学科一般被看作次一等（MLA）[^mla2012digital-e1] | 本文资料未涉及 | 最有声望的形式之一[^mla2012digital-e1] |

## 本领域的规范和伦理

通用的伦理原则见通用篇[科研诚信与伦理](../../general/4_throughout/02_integrity_and_ethics.md)，下面只讲本领域特有的部分。**美国语言学会（LSA）2019 年的伦理声明**不取代正式的伦理审查[^lsa2019ethics-e1]。和新手关系最大的几条 `[本项目分析：条目为本项目挑选]`：

- **免审不等于不用管伦理。** 即使机构伦理委员会认为项目可以免审，语言学者也应尽力遵守尊重个人等核心原则[^lsa2019ethics-e2]。
- **知情同意，全程自愿**[^lsa2019ethics-e3]。匿名观察人们在公共场合的行为，也应经过伦理委员会的充分审查[^lsa2019ethics-e16]。
- **不捏造、不篡改数据，不做 p 值操纵**（反复换分析方法，直到结果"显著"）[^lsa2019ethics-e11]。
- **引用观点、描述和数据的原始来源**[^lsa2019ethics-e12]；承认学生和合作者的全部贡献[^lsa2019ethics-e14]。
- **在合适且可能时，推动数据共享和存档**[^lsa2019ethics-e13]。
- **做语言技术的，要想到后果**，包括技术在社会和政治决策中的作用[^lsa2019ethics-e15]。

LSA 1992 年那份声明的起因，是一些会员担心美国联邦的人类受试者保护政策不一定适用于语言研究[^lsa1992humansubjects-e1]；声明说，语言研究的情况很难机械地套用一般规则[^lsa1992humansubjects-e4]。这是美国的情况；其他国家的伦理审查要求各不相同，以你所在机构的规定为准 `[本项目分析]`。

**文学研究：小心自我抄袭。** MLA 格式网站说，发表时重用自己以前的观点或句子而不引用，也算抄袭[^mlastylecenter-e4]。

## 常见的研究类型

**本领域的研究类型文档**：[文本细读与文学论证](research-types/close_reading.md)、[语言记录与语言学田野调查](research-types/language_documentation.md)。

**相关学科的研究类型文档**：[档案研究](../history-archaeology/research-types/archival_research.md)、[口述历史](../history-archaeology/research-types/oral_history.md)。

本领域还没有专门的研究类型文档。下面的分类为本项目归纳 `[本项目分析]`，能借用计算机篇文档的，给出链接和差异：

- **文本细读与阐释**：围绕一个或几个文本建立论证。做法见上文。
- **档案与学术版本研究**：研究手稿和版本，编辑可靠的文本。查档基础见[历史与考古](../history-archaeology/README.md)。
- **文学史与研究综述**：梳理前人怎样阐释一个作家或问题。可参考[综述研究](../../06_methods/review_study.md)的"写清检索和取舍"思路，但文学研究的综述更重给自己的论点定位，不一定走系统综述的固定流程。
- **语言田野调查与语言记录**：在社区中记录和描写一种语言。访谈技巧可参考[访谈研究](../../06_methods/interview_study.md)，差异见上文。
- **语料库研究**：分析大量真实语言材料。数据处理可参考[数据科学](../../06_methods/data_science.md)，另加数据引用的要求。偏计算的方向（计算语言学）和计算机领域重叠很多，按[计算机领域](../computer-science/README.md)的惯例走。
- **语言实验**：语音、心理语言学等实验。可参考[对照实验](../../06_methods/controlled_experiment.md)和[心理学](../psychology/README.md)。

## 给新手的建议

1. **先确定你在哪个传统里。** 文学研究和语言学的证据、成果和规范都不同，导师和目标期刊的要求是最直接的依据 `[本项目分析]`。
2. **（文学）先细读，再立论。** 抄准引文，记下页码，从模式和问题里找题目[^yorkclosereading-e3][^uncwritinglit-e7][^uncwritinglit-e5]；每条引文都要分析[^uncwritinglit-e8]。
3. **（文学）用理论打开文本，不要套结论。** 不带预设结论进入题目[^uncwritinglit-e11]，把细读放回语境[^yorkclosereading-e5]。
4. **（文学）早点了解所在单位怎样评价专著、论文和学术版本。** MLA 2005 年对美国 1,339 个系的调查显示，博士、硕士、本科院校对专著的看重程度差别很大[^mla2007evaluating-e3]；其他国家的情况先问导师 `[本项目分析]`。
5. **（语言学）田野调查前，先和社区谈。** 从规划阶段就请社区参与[^lsa2019ethics-e8]，问清谁能代表社区同意、材料怎样存档和使用[^lsa2019ethics-e6][^lsa2019ethics-e7]。
6. **（语言学）项目一开始就联系数据档案馆**[^berezkroeker2018reproducible-e13]，录音和转写从第一天起就按能存档、能引用的方式整理 `[本项目分析]`。
7. **（语言学）做实验前写好分析计划。** 分清探索和验证，考虑预注册[^roettger2019researcher-e2][^roettger2019researcher-e3]。

## 常见错误

**文学研究**

| 错误 | 为什么是问题 |
|---|---|
| 复述情节，没有论点 | 好的阐释要避开显而易见的结论，并用推理把证据和论点连起来[^uncwritinglit-e4][^uncwritinglit-e3] |
| 大段引用，不做分析 | 只引不析，就没有展示推理[^uncwritinglit-e8]；分析应是引文长度的两倍[^yorkclosereading-e7] |
| 引文抄错，或凭记忆转述 | 准确抄录是细读的头条规则[^yorkclosereading-e3]；要从原文出发[^yorkclosereading-e8] |
| 先选好理论结论，再去文本里找例子 | 不要带着预设结论进入题目[^uncwritinglit-e11] |
| 只做细读，不管历史和语境 | 细读因脱离语境被批评过[^yorkclosereading-e4] |
| 引用不注页码或行号 | MLA 格式要求注明位置[^mlastylecenter-e2] |
| 重用自己以前的文字而不注明 | 也算抄袭[^mlastylecenter-e4] |

**语言学**

| 错误 | 为什么是问题 |
|---|---|
| 只取得个人同意，就把材料分享出去 | 在许多社区，语言知识是集体的，个人无权单独同意[^lsa2019ethics-e6] |
| 不问意愿，一律匿名或一律署名 | 有的发音人希望被署名[^lsa1992humansubjects-e3]，有的希望不和身份联系[^lsa2019ethics-e4] |
| 以为伦理委员会免审就不用考虑伦理 | LSA 2019 年伦理声明认为，免审项目也应尽力遵守核心原则[^lsa2019ethics-e2] |
| 论文里的例句查不到出处 | 读者没法核对，只能"相信你"[^berezkroeker2018reproducible-e5]；要写明位置[^berezkroeker2018reproducible-e7] |
| 不说明数据来自自己的语感判断 | 内省数据要明确说明[^berezkroeker2018reproducible-e9] |
| 数据只存在自己电脑上 | 珍贵的濒危语言数据可能消失[^berezkroeker2018reproducible-e14]；要存进档案馆[^berezkroeker2018reproducible-e10] |
| 试了很多分析，只报告显著的那个 | Roettger 主张测了多少、分析了多少就报告多少[^roettger2019researcher-e4]；LSA 伦理声明也要求不做 p 值操纵[^lsa2019ethics-e11] |

## 延伸阅读

- **约克大学英语系，Close reading**（免费网页）：细读的定义和做法。第一次写文学论文，从这里开始。
- **北卡罗来纳大学写作中心，Literature (Fiction)**（免费讲义）：分步骤讲怎样从读作品到写出一篇有论点的分析。
- **MLA Style Center**（style.mla.org）：MLA 格式的免费官方页面，含文中引注、引用文献列表和抄袭说明。
- **MLA，Report of the Task Force on Evaluating Scholarship for Tenure and Promotion**（2007）：基于 2005 年对美国 1,339 个系的非代表性调查，讲美国院系在终身教职评审中怎样看专著、期刊和学术版本。
- **LSA Ethics Statement**（2019）：美国语言学会的伦理声明，讲对参与者、社区、学生和同行的责任。做田野调查前必读。
- **Berez-Kroeker 等 2018，Reproducible research in linguistics**（开放获取）和 **Austin Principles**：为什么要引用语言数据，怎样引用。
- **Roettger 2019，Researcher degrees of freedom in phonetic research**（开放获取）：作者对语音研究中"研究者自由度"的分析和建议。做语音或语言实验前可以读。
