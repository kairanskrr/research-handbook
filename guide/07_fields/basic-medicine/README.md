# 基础医学：学科概况

本文讲基础医学的研究实际怎样运转。基础医学包括解剖学、生理学、病理学、药理学、毒理学、免疫学、医学微生物学等。它的很多日常做法和实验室方向的生命科学相同：课题组怎样分工、实验记录本怎么记、生物学重复和技术重复怎么分、动物实验的 3R 原则（替代、减少、优化）和 ARRIVE 动物研究报告规范，这些见[生物科学学科概况](../biological-sciences/README.md)。涉及病人的临床试验、试验登记、国际医学期刊编辑委员会（International Committee of Medical Journal Editors，ICMJE）的署名标准和临床报告规范，见[临床医学学科概况](../clinical-medicine/README.md)。各学科共通的做法见[全程地图](../../00_start-here/research-journey.md)里列出的各章和[贯穿全程](../../08_throughout/README.md)。本文只写基础医学特有的东西：为什么很多临床前发现到了人身上就不灵，以及为此要守的规矩。常用哪些研究套路、各看什么证据，见[常用套路与证据标准](#常用套路与证据标准)；具体怎么做，见[本学科常用的研究方法](#本学科常用的研究方法)。

**读完本文，你应该能：**

- 说清"从实验台到病床"是什么意思，知道临床前发现为什么常常不能转化；
- 按临床前研究的核心要求设计和报告实验：随机分组、盲法、样本量、数据处理；
- 分清探索性实验和验证性实验，知道哪些结果可以做统计、哪些只能当线索；
- 知道抗体为什么要按用途验证，论文里怎样写清试剂；
- 知道用人体组织和生物样本库的样本要过哪些伦理关；
- 知道良好实验室规范是谁定的、管哪类研究。

## 本领域研究怎样运转

### 研究处在"从实验台到病床"的上游

医学研究常被描述成一条链：发现从实验台上的基础研究开始，经过临床前的动物研究，再到人体临床试验中证明疗效[^mak2014lost-e9]。基础医学的很多课题就在这条链的上游。所以你的结果可能被别人拿去当下一步的依据。例如，美国食品药品监督管理局和加拿大卫生部都要求新分子实体用于人体之前先做动物试验[^mak2014lost-e10]。Freedman 等人 2015 年的文章说，有临床应用前景的学术研究，在开始临床研究之前，通常会先在药企内部重做一遍，每次需要 3 到 24 个月、50 万到 200 万美元[^freedman2015economics-e6]。有缺陷的临床前研究，会给等待治疗的病人带来虚假的希望[^freedman2015economics-e8]。

### 很多临床前发现到了人身上不灵

这是本领域最需要新手了解的背景。下面的数字和例子来自 Mak 等人 2014 年的一篇短综述。据本手册通读全文后的判断，它是叙述性综述，不是系统综述；文中的数字是转引其他研究的，而且只讲癌症和新药，不能直接套到所有方向。

- **转化成功率低。** 这篇综述称，从动物模型成功转化到癌症临床试验的平均比例不到 8%[^mak2014lost-e1]。它还引用：临床前试验成功的新药，早期临床试验有 85% 失败；走到三期的，只有一半获批[^mak2014lost-e2]。
- **有的失败很惨烈。** TGN1412 在首次人体试验中引起灾难性的全身器官衰竭，而给药剂量比动物研究中认为安全的剂量低 500 倍[^mak2014lost-e7]。IPI-926 让晚期脑肿瘤小鼠的生存期提高了五倍，在人体试验中却和安慰剂没有差别[^mak2014lost-e8]。

这篇综述认为，失败的部分原因在两方面[^mak2014lost-e5]：

1. **模型本身不像人。** 动物模型难以模拟人类癌症发生和进展的复杂过程[^mak2014lost-e3]。卒中领域的研究者分析多项失败的临床试验时也承认，没有一种动物模型能完全再现人类卒中[^landis2012call-e3]。
2. **临床前研究方法差、报告不清。** 这一类是你能控制的。在药物 NXY-059 的卒中动物研究里，报告了随机分组、分组隐藏或盲法评估的论文，效应量明显小于没报告这些信息的论文[^landis2012call-e4]。设计差、报告又不清的一系列研究，可能合起来成为大型、昂贵、最终失败的临床试验的依据，让病人白白承担风险[^landis2012call-e5]。

Mak 等人转述的改进建议包括：不只用啮齿类，也用更高等的动物；做随机分组和结局评估者盲法；两种性别、不同年龄的动物都纳入；阳性和阴性数据都发表[^mak2014lost-e6]。他们还写到，因为阴性结果常常不发表，动物研究对"治疗有效"的可能性似乎高估了约 30%[^mak2014lost-e4]；怎样报告阴性结果，见[科研诚信与伦理](../../08_throughout/integrity_and_ethics.md#2-对证据诚实不骗自己报告全部结果)。所以，基础医学里"做得严谨、写得清楚"不只是为了论文好看，而是因为下游的人和病人会依赖你的结果。

### 组织方式、发表和署名

课题组分工、记录本、试剂和动物管理和实验室方向的生命科学一样，见[生物科学学科概况](../biological-sciences/README.md)；发表以期刊为主，预印本见该篇的[发表：期刊和预印本](../biological-sciences/README.md#发表期刊和预印本)。署名标准见临床医学学科概况的[署名：ICMJE 的四条标准](../clinical-medicine/README.md#署名icmje-的四条标准)，目标期刊是否采用以作者须知为准。

## 本领域的规范和报告标准

### 临床前研究至少报告四件事：美国一次研讨会的建议

2012 年 6 月，美国国家神经疾病与卒中研究所召集各方开会，讨论怎样改进基金申请和论文里动物研究方法的报告[^landis2012call-e16]。会议的主要建议是：研究**至少**要报告样本量怎么估计、是否以及怎样随机分组、研究者是否设盲、数据怎样处理[^landis2012call-e1]。这是一次会议的建议，不是法规；你的单位、资助方和期刊可能另有要求。为什么要强调？会议文章引用的一项回顾：2010 年《Cancer Research》（《癌症研究》）的 100 篇论文里，28% 报告了随机分组，2% 报告了观察者设盲，没有一篇说明每组动物数是怎么定的[^landis2012call-e2]。

- **随机分组，分组隐藏。** 研究者不应知道从笼里取出的下一只动物会分到哪组[^landis2012call-e6]。样品分批处理时也要注意安排，否则可能把批次效应当成处理效应[^landis2012call-e7]。
- **事先算样本量。** 动物太少、几乎不可能测出有意义差异的实验，也不合伦理[^landis2012call-e8]。
- **事先定好什么时候停。** 不要"显著就停、不显著就再加数据"；样本量和停止收集数据的规则要事先定好，并写进论文[^landis2012call-e9]。否则假阳性的机会会变大。
- **动物中途退出要交代。** 一种处理如果杀死了最弱的动物而又不报告，看起来反而像是有效[^landis2012call-e10]。
- **事先指定主要终点**、评估时间和分析方法，不要做完再挑[^landis2012call-e11]。
- **报告同一实验做了几次。** 这能抵消"只发表最好那次结果"的倾向[^landis2012call-e15]。

这几条和 ARRIVE 动物研究报告规范的核心项一致，ARRIVE 的内容见[生物科学学科概况](../biological-sciences/README.md#动物研究3r-原则和-arrive-报告规范)。会议文章还观察到：很少有动物研究报告随机、盲法或样本量依据，但大多数都写了遵守动物法规，因为期刊要求写[^landis2012call-e14]。

### 分清探索性实验和验证性实验

早期的探索性实验常常样本小、没有主要结局、不设盲。这没关系，但它们只能当作"提出假设"的实验来解读[^landis2012call-e12]。探索阶段的发现，要用按上面核心要求设计和报告的后续实验来确认[^landis2012call-e17]。

### 一家药理学期刊的具体规定：《英国药理学杂志》

《英国药理学杂志》（British Journal of Pharmacology）2018 年发表了一份给作者和审稿人的设计与分析指南，更新了 2015 年版，也是该刊审稿的评判标准[^curtis2018experimental-e1]。下面只是这一本期刊 2018 年版的规定，不是整个学科的统一要求；投别的期刊，以对方的作者须知为准。指南作者自己也说，部分规定是人为划定的，有些会改[^curtis2018experimental-e12]，投稿前要查该刊最新版。

- **每组 n 至少为 5 才做统计。** n 小于 5 的组不能做统计检验，结果要标为"探索性"或"初步"[^curtis2018experimental-e2]。
- **n 是独立样本数。** 三份样品各测五次，按 n = 15 做统计是常见错误，n 应为 3[^curtis2018experimental-e3]；同一只小鼠的五个细胞是技术重复，n = 1[^curtis2018experimental-e10]。实验单位怎么定，见[生物科学学科概况](../biological-sciences/README.md#先弄清实验单位再算-n)。
- **功效分析算出的样本量再加 50%**。功效分析算出的是最低样本量；该刊鼓励（不是硬性规定）再加 50%，以降低漏掉真实差异的风险[^curtis2018experimental-e9]。
- **归一化之后要换统计方法。** 把每个值除以配对对照后，对照组均值恒为 1、没有标准误。这时不能用方差分析等参数检验，只能用非参数检验；这种情况在蛋白质印迹（Western blot）分析中常见[^curtis2018experimental-e4]。
- **显著性阈值在方法部分写明，结果部分不能换**[^curtis2018experimental-e5]。
- **离群值默认保留**，除非有事先定好、说得通的剔除标准[^curtis2018experimental-e6]。
- **方法部分要有"数据与统计分析"小节**[^curtis2018experimental-e13]。
- **预实验数据可以放，但不给 P 值。** 不适合做统计的预实验数据，放在方法部分的"预实验"小节[^curtis2018experimental-e11]。

这些规定执行得并不好。该刊统计了 2015 年指南发布至少半年后出版的三期论文，发现很多论文没有完全遵守指南[^curtis2018experimental-e7]。因此该刊规定：没有随机和盲法、各组 n 不等、n 小于 5 还做统计，这几项同时出现的论文会在初筛时直接拒稿[^curtis2018experimental-e8]。

### 抗体要按用途验证，试剂要写到能被找到

抗体是基础医学很常用的工具。但抗体用得很广，却缺少一套跨应用的验证框架，用抗体得到的数据质量差别很大[^uhlen2016proposal-e1]。Freedman 等人也把生物试剂和参考材料列为临床前研究不可复现的四类主要原因之一[^freedman2015economics-e7]；他们估算这类问题和研究设计问题占了不可复现研究花费的大部分，所以应优先改进[^freedman2015economics-e9]。

2016 年，Uhlen 等人代表一个国际抗体验证工作组提出了建议[^uhlen2016proposal-e3]：

- **验证要按用途和样品做。** 抗体在蛋白质印迹里表现好，不代表在酶联免疫吸附试验（ELISA）里也好[^uhlen2016proposal-e2]。使用者应在自己的用途和样品里至少做一种验证[^uhlen2016proposal-e6]。
- **五种验证思路，至少用一种**：基因方法、正交方法、两种独立抗体对照、表达带标签的目标蛋白、免疫捕获后做质谱[^uhlen2016proposal-e3]。简单说，基因方法是去掉或减少目标蛋白、看信号是否随之变化；正交方法是用不依赖抗体的方法对照。
- **人体样本有特殊困难。** 基因方法不能用于人体组织样本和血浆、血清等体液[^uhlen2016proposal-e4]，只能用其他思路。
- **结合了目标不等于特异。** 有的补充方法能说明抗体结合了目标，却排除不了它也结合结构相似的其他蛋白（交叉反应）[^uhlen2016proposal-e9]。
- **展示整块胶。** 用蛋白质印迹验证时，要展示整块胶，不只是目标大小附近那一段[^uhlen2016proposal-e5]。
- **论文里写清试剂。** 至少写货号和批号，最好加上研究资源标识符（Research Resource Identifier，RRID，一个免费、各期刊通用的试剂编号）[^uhlen2016proposal-e6][^uhlen2016proposal-e7]。生产方应对每个新批次重复验证[^uhlen2016proposal-e8]，所以换批号后要留意结果是否变化。

读这份建议时要知道它的产业关联：文章的编辑协助由 Phase Five Communications 提供，费用由试剂公司 Thermo Fisher Scientific 支付；第一作者 Uhlen 是 Atlas Antibodies 等抗体相关公司的联合创始人[^uhlen2016proposal-e10]。细胞系鉴定等其他试剂问题，见[生物科学学科概况](../biological-sciences/README.md#试剂抗体和细胞系要验证)。

### 用人体组织和生物样本库：先确认同意和伦理批准

基础医学常用手术切除的组织、血液、病理切片，或生物样本库里的样本。**生物样本库**是生物材料及其相关数据的集合[^wma2016taipei-e2]。用这些样本，即使不接触病人本人，也在伦理规则的管辖内：世界医学会《赫尔辛基宣言》（2024 年修订版）的适用范围就包括使用可识别的人体材料或数据的研究[^wma2024helsinki-e1]。

世界医学会的两份文件——《赫尔辛基宣言》和专讲健康数据库与生物样本库的《台北宣言》（2016 年修订版）——给出了下面的原则：

- **采集和保存都要知情同意。** 采集、处理、保存生物材料和可识别的数据，以及可预见的二次使用，都要取得自愿的知情同意[^wma2024helsinki-e11]。
- **样本库本身要过伦理委员会。** 建立数据库和生物样本库要经研究伦理委员会批准，后续使用也受它监督[^wma2024helsinki-e12]。
- **新课题用旧样本，要查当初的同意够不够。** 伦理委员会要检查采集时的同意是否覆盖你计划的用途[^wma2016taipei-e6]。无法或难以取得同意时，用已保存的样本做二次研究，必须先经研究伦理委员会批准[^wma2024helsinki-e13]。
- **"为将来的研究存起来"的同意，要讲清楚才有效。** 样本存入样本库、用于多种不确定的用途时，只有把相关情况充分告知本人，同意才有效（《台北宣言》第 12 段列了要告知的条目）[^wma2016taipei-e3]。其中一条是：样本一旦去标识，本人可能无法知道它被怎样使用，也无法再撤回同意[^wma2016taipei-e4]。
- **捐献者可以撤回。** 个人可以随时更改同意，或要求撤出自己可识别的数据和样本[^wma2016taipei-e5]。
- **向别的单位要样本或给出样本，按规矩签协议。** 样本库的治理规则要规定获取和共享，必要时使用材料转移协议[^wma2016taipei-e8]。

《台北宣言》主要写给医生，但鼓励所有使用健康数据库和样本库的人遵守[^wma2016taipei-e9]；它也要求同时考虑本国的伦理、法律和监管规定[^wma2016taipei-e7]。具体怎么申请，以本国法规和你所在单位伦理委员会的要求为准。

### 毒理学和安全性研究：良好实验室规范

**谁定的、管什么？** 本文依据的是经济合作与发展组织（Organisation for Economic Co-operation and Development，OECD）的《良好实验室规范原则》（Good Laboratory Practice，GLP）。它是一套面向监管用研究的质量体系，管非临床健康与环境安全研究怎样计划、实施、监督、记录、归档和报告[^oecd1998glp-e1]。它由 OECD 理事会 1981 年通过，是《化学品评估数据互认决定》的附件[^oecd1998glp-e3]，1997 年修订[^oecd1998glp-e14]；基础是美国食品药品监督管理局 1976 年发布的非临床实验室研究法规[^oecd1998glp-e4]。目的之一是让各国互认试验数据，避免重复试验[^oecd1998glp-e5]。

**管哪些研究？** 法规要求的、用于药品、农药、食品和饲料添加剂、化妆品、兽药等注册或许可的非临床安全研究（国家立法另有豁免的除外）[^oecd1998glp-e2]。要把结果交给国家主管部门评估的试验机构，必须遵守[^oecd1998glp-e12]。大学实验室里不打算交给监管部门的探索性研究，一般不在这个范围内；但如果你的毒理学或药理学课题要支持药物申报，要先问清是否必须在符合良好实验室规范的机构完成。具体要求以所在国的法规为准。

即使不在适用范围内，它的几条做法也值得学：

- **一人负总责。** 每项研究有一位研究负责人，对整体实施和最终报告负责[^oecd1998glp-e6]。
- **开始前有书面计划**[^oecd1998glp-e8]；偏离计划的地方及时写明原因和日期[^oecd1998glp-e9]。
- **当场记录、签名、注明日期**[^oecd1998glp-e10]；改原始数据不能盖住原记录，要写理由[^oecd1998glp-e11]。
- **独立的质量检查。** 做质量保证的人不参与他检查的那项研究[^oecd1998glp-e7]。
- **全部归档。** 研究计划、原始数据、受试物样品、标本和最终报告都要保存[^oecd1998glp-e13]。

## 常用套路与证据标准

**研究套路**指一个项目主要靠什么逻辑产生新知识，按核心主张来定，见[核心术语](../../00_start-here/key-concepts.md#研究套路)和[研究套路](../../05_research-strategies/README.md)。下表只列本文资料能支持的三种。表的分组和"在基础医学里的样子"一栏是本项目的归纳；每条标准只代表脚注里的出处（多为临床前动物研究和癌症、卒中方向），其他方向本文资料未涉及。构建改进（例如建立新的疾病模型）等套路的评判标准，本文资料未涉及。

| 套路 | 在基础医学里的样子 | 常用证据和评判标准 | 具体做法 |
|---|---|---|---|
| [解释因果](../../05_research-strategies/explain_causality.md) | 在细胞或疾病动物模型上检验机制和药物效果，结果可能成为临床试验的依据[^landis2012call-e5] | 至少报告样本量怎么估计、怎样随机、是否设盲、数据怎样处理[^landis2012call-e1]；没报告随机、分组隐藏或盲法的研究，效应量明显更大[^landis2012call-e4]；探索性实验只能提出假设，要用后续实验确认[^landis2012call-e17]；要外推到人，临床前指南最常建议在不止一种动物模型中重现效应，并独立重复[^henderson2013threats-e8] | [临床前动物研究](../../06_methods/preclinical_animal_study.md)、[实验台实验](../../06_methods/bench_experiment.md) |
| [测量](../../05_research-strategies/measure.md) | 检查抗体等测量工具本身靠不靠得住。用抗体得到的数据质量差别很大[^uhlen2016proposal-e1] | 按用途和样品验证，在印迹里好不代表在别的用途里也好[^uhlen2016proposal-e2]；使用者在自己的用途里至少做一种验证，论文写明货号、批号[^uhlen2016proposal-e6] | [实验台实验：确认试剂和细胞系](../../06_methods/bench_experiment.md#第-7-步确认试剂和细胞系) |
| [综合](../../05_research-strategies/synthesize.md) | 汇总已发表的临床前研究，例如比较同一药物的多项卒中动物研究[^landis2012call-e4] | 看纳入研究是否报告了随机和盲法，因为这会影响效应量[^landis2012call-e4]；阴性结果常不发表，动物研究可能高估疗效约 30%[^mak2014lost-e4] | [综述研究](../../06_methods/review_study.md)、[元分析](../../06_methods/meta_analysis.md) |

怎么用这张表：先按核心主张找到你的套路，再读对应的套路页和做法页。一个课题常常混合几种套路，例如先验证抗体（测量），再用它检验一个机制（解释因果）；每部分按各自的标准要求。

## 本学科常用的研究方法

**跨学科的研究类型**：[临床前动物研究](../../06_methods/preclinical_animal_study.md)、[实验台实验（湿实验）](../../06_methods/bench_experiment.md)、[随机对照试验](../../06_methods/randomized_controlled_trial.md)、[定量仿真](../../06_methods/simulation_study.md)、[复现研究](../../06_methods/replication.md)、[综述研究](../../06_methods/review_study.md)。基础医学目前没有本学科独有的研究方法页。

本学科的特别要求：细胞和分子实验特别要注意抗体验证；动物模型研究按上面四项核心要求做，结论要说明模型和人的差距；药理学实验按目标期刊的设计与分析规定做；为监管申报做的毒理学和安全性研究要遵守良好实验室规范[^oecd1998glp-e2]；人体样本研究要确认当初的同意覆盖你的用途[^wma2016taipei-e6]。非动物替代方法包括体外研究、计算机建模、流行病学研究等[^mak2014lost-e11]。

## 给新手的建议

1. **先想清结果要走多远。** 你的结果如果要支持后续动物或人体研究，设计时就按验证性实验的标准来做；只是找线索，就老实标为探索性[^landis2012call-e12]。
2. **动手前定好四件事：** 样本量怎么算、怎样随机、谁设盲、数据怎样处理（包括停止规则、剔除标准和主要终点）[^landis2012call-e1][^landis2012call-e9][^landis2012call-e11]。写下来，最好让导师看过。
3. **数清你的 n。** 统计用独立样本数，不用测量次数[^curtis2018experimental-e3][^curtis2018experimental-e10]。
4. **新抗体在你自己的样品和用途里先验证再用**，记下货号、批号和研究资源标识符[^uhlen2016proposal-e6]。
5. **用人体样本前，先看伦理批件和当初的同意书覆盖什么用途**[^wma2016taipei-e6]；拿不准就问单位的伦理委员会。
6. **投稿前读目标期刊的设计与统计规定**，不要等审稿人指出；有的期刊会因此直接拒稿[^curtis2018experimental-e8]。
7. **结论别越过模型的边界。** 小鼠里有效只说明小鼠里有效；写讨论时说清模型和人的差距[^mak2014lost-e3]。

## 常见错误

| 错误 | 为什么是问题 |
|---|---|
| 不随机、不设盲，只在论文里写"遵守动物法规" | 没报告随机和盲法的研究效应量可能偏大[^landis2012call-e4]；《英国药理学杂志》会直接拒稿[^curtis2018experimental-e8] |
| 先做几只看看，显著就停，不显著就加 | 停止规则要事先定好[^landis2012call-e9]；否则假阳性的机会变大 |
| 三份样品各测五次，按 n = 15 算 P 值 | n 应为 3；《英国药理学杂志》不接受这种做法[^curtis2018experimental-e3] |
| 每组只有 3 只动物，照样做统计检验并下结论 | 动物太少的实验难以测出有意义的差异[^landis2012call-e8]；《英国药理学杂志》规定 n 小于 5 不能做统计[^curtis2018experimental-e2] |
| 抗体在印迹里用过，就直接拿来做免疫组化 | 抗体性能取决于用途和样品，要按用途验证[^uhlen2016proposal-e2] |
| 只放目标大小附近的一段印迹条带 | 验证时应展示整块胶[^uhlen2016proposal-e5]；只放一段，看不出别处有没有杂带 |
| 拿病理科的旧样本直接做新课题 | 要伦理委员会确认当初的同意覆盖新用途[^wma2016taipei-e6][^wma2024helsinki-e13] |
| 动物死了几只，论文里不提 | 一种处理杀死最弱的动物而不报告，看起来反而像有效[^landis2012call-e10] |
| 把小鼠实验的结果写成"有望治愈某病" | 动物模型难以模拟人类疾病[^mak2014lost-e3]；在癌症领域，很多动物模型里的发现没能在临床试验中重现[^mak2014lost-e1] |

## 延伸阅读

- **Landis 等人 2012，A call for transparent reporting to optimize the predictive value of preclinical research（Nature，PubMed Central 有作者稿）**：讲清临床前研究为什么要随机、盲法、算样本量、事先定数据处理规则。设计第一个动物实验前读。
- **Curtis 等人 2018，Experimental design and analysis and their reporting II（British Journal of Pharmacology）**：一本药理学期刊对 n、归一化、离群值、显著性阈值的具体规定。做药理学或常用蛋白质印迹的人读；投稿前再查该刊最新版。
- **Uhlen 等人 2016，A proposal for validation of antibodies（Nature Methods）**：五种抗体验证思路。第一次自己选抗体前读；注意上文说的产业关联。
- **Mak、Evaniew 和 Ghert 2014，Lost in translation（American Journal of Translational Research）**：篇幅短的癌症转化失败综述，举了几个具体例子，数字多转引自其他研究。想了解"动物有效、人身上无效"是怎么回事的人读。
- **OECD《良好实验室规范原则》（1998 年发布的 1997 年修订版）**：做毒理学或要支持药物申报的人读；其他人看第一部分的定义和第二部分第 8 节"研究的实施"即可。
- **世界医学会《台北宣言》（2016）和《赫尔辛基宣言》（2024）**：用人体样本和生物样本库前读，再对照本国法规和本单位伦理委员会的要求。
