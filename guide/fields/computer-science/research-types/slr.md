# 系统性文献综述与映射研究（SLR）

> **状态**：草稿，待审阅
> **最后更新**：2026-10-05
> **主要依据**：SIGSOFT Systematic Reviews 标准与 General Standard、Kitchenham & Charters (2007)、Petersen et al. (2008)、Wohlin (2014)、Wohlin et al. (2022)、Ralph & Baltes (2022)、PRISMA 2020。出处简称见第 8 节。

## 1. 定义与适用范围

**定义**：系统性综述是对一手或二手文献进行评估、分析和综合的研究，目的是就一个或多个具体主题或研究问题，给出对现有证据完整、详尽的总结 [SIG-SR]。

**适用范围** [SIG-SR]：
- 适用于系统地查找并分析某一主题已有文献的研究
- 同时适用于二级研究（综述一手研究）和三级研究（综述其他综述）
- 不适用于非系统的文献综述、案例调查（case survey），以及元民族志等高级定性综合方法

### SLR 与映射研究的区别

| 维度 | 映射研究 | 系统性综述 |
|---|---|---|
| 目标 | 对研究领域做分类和主题分析，了解有哪些研究、发表在哪里 | 确定证据的现状，基于实证数据找出最佳实践 |
| 质量评估 | 一般不评估单篇研究的质量 | 需要详细评估研究方法的质量 |
| 广度与深度 | 覆盖面广，检索式限制少，工作量较小 | 聚焦更窄、分析更深，工作量更大 |
| 分类粒度 | 较粗的分类即可 | 需要更细的分类 |

出处：[Petersen08 §4]。另见 [Petersen15]：映射研究用于梳理研究领域的结构，系统性综述侧重收集和综合证据。

- 当证据可能很少或主题范围很广时，适合做映射研究。它能找出证据集中和证据空白的地方，为后续的 SLR 指明重点 [K&C §2.5.1]。
- 映射研究可以作为系统性综述的第一步：先梳理整个领域，再聚焦到具体问题 [Petersen08]。

### 综述类型

研究必须说明自己属于哪一类综述 [SIG-SR 必要]。Ralph & Baltes 把文献综述分为七类 [R&B22 §2]：

| 类型 | 简述 |
|---|---|
| 非系统综述（ad hoc） | 不按系统方法挑选文献进行讨论，适合发展理论，但有抽样偏差，不适合支撑实证结论 |
| 元分析（meta-analysis） | 对相似的定量研究做统计汇总，估计效应量；要求尽量完整地找到相关研究并评估质量 |
| 元综合（meta-synthesis） | 用诠释学方法综合定性研究的发现，以发展理论 |
| 案例调查（case survey） | 把定性案例研究的数据转成定量数据集，用来检验假设 |
| 批判性综述（critical review） | 分析一组研究，以论证某个观点或批评研究实践；不要求完整收录 |
| 范围综述（scoping review） | 对研究分类和计数，了解研究现状；以描述为主，综合较少 |
| 快速综述（rapid review） | 为紧急决策牺牲严谨性换取速度；需要明确说明做了哪些妥协 |

Ralph & Baltes 的建议是：SE 领域需要更多的元分析、案例调查和元综合，而范围综述和快速综述应该少一些；以描述为主的范围综述更适合 workshop 或海报，而不是主要会议 [R&B22 §3.1]。

## 2. 主要阶段与产出物

### 系统性综述

Kitchenham & Charters 把 SLR 分为规划、执行、报告三个阶段 [K&C §4]：

| 阶段 | 主要工作 | 产出物 | 出处 |
|---|---|---|---|
| **规划** | 确认是否需要做这个综述 | 需求说明（为什么做、是否已有类似综述） | [K&C §5.1] |
| | 明确研究问题 | 研究问题 | [K&C §5.3] |
| | 制定研究方案 | **研究方案（protocol）**，内容见下 | [K&C §5.4] |
| | 评审研究方案 | 评审后的研究方案 | [K&C §5.5] |
| **执行** | 检索文献 | 检索式、检索来源、检索结果 | [K&C §6.1] |
| | 筛选一手研究 | 纳入/排除记录 | [K&C §6.2] |
| | 评估研究质量 | 质量评分 | [K&C §6.3] |
| | 提取数据 | 数据提取表 | [K&C §6.4] |
| | 综合数据 | 综合结果 | [K&C §6.5] |
| **报告** | 确定发布方式、撰写报告、评审报告 | 综述论文和补充材料 | [K&C §7] |

**研究方案应包含** [K&C §5.4]：背景与动机、研究问题、检索策略（检索词、数据库等来源）、筛选标准与流程、质量评估清单与流程、数据提取策略、数据综合方法、发布计划、时间安排。

### 映射研究

Petersen 等人给出的映射研究流程有五步，最终产出是"系统映射图" [Petersen08 §3]：

| 步骤 | 产出物 |
|---|---|
| 1. 确定研究问题 | 研究范围 |
| 2. 检索一手研究 | 全部候选论文 |
| 3. 筛选论文 | 相关论文 |
| 4. 对摘要做关键词标注（keywording） | 分类方案 |
| 5. 数据提取与映射 | 系统映射图 |

**分类方案的建立方式**：阅读摘要，找出反映论文贡献的关键词和概念，再把多篇论文的关键词合并，形成对研究性质和贡献的整体理解，据此建立分类。摘要信息不够时，可以看引言或结论 [Petersen08 §3.4]。

### 检索策略的补充：滚雪球检索

以下依据 Wohlin 的原始指南 [Wohlin14]：

- **起始集**：没有标准做法，但起始集应当：覆盖可能产出相关论文的不同研究社区；规模与研究范围相称；在出版方、年份、作者上有多样性；从研究问题的关键词（最好包括同义词）出发来找。建议用 Google Scholar 查找，以避免偏向某一家出版方。
- **向后滚雪球**：先排除不满足基本条件（语言、年份、发表类型）和已经看过的论文；再结合论文标题、发表场所、作者，以及这篇参考文献在原文中被引用的位置和上下文，判断是否值得进一步阅读；然后先读摘要，再按需要阅读其他部分，直到能做出判断。
- **向前滚雪球**：用 Google Scholar 找到引用了已纳入论文的文章，逐级评估：先看检索结果信息，再看摘要，再看它如何引用原论文，必要时读全文。
- **迭代与停止**：每次只做一轮，以保证可追溯；本轮新纳入的论文作为下一轮的输入；当向后和向前滚雪球都找不到新论文时停止。之后可以联系已纳入论文的作者（尤其是高产作者）寻找遗漏的论文，如果有新发现，就重新开始滚雪球。
- **先读全文再用于下一轮**：一篇论文只有在读完全文、确认纳入之后，才能作为下一轮滚雪球的输入。否则一旦它后来被排除，基于它找到的论文都要回滚。

Wohlin 还指出，滚雪球不一定能替代数据库检索，最好组合使用多种检索方式 [Wohlin14]。后续研究发现，数据库检索与滚雪球结合的混合策略，比单独数据库检索多找到约 30% 的一手研究 [Wohlin22]。

## 3. 关键决策点

| 决策点 | 为什么关键 / 常见错误 | 出处 | 是否可能需要人参与 `[本项目分析]` |
|---|---|---|---|
| **综述类型；做 SLR 还是映射研究** | 类型决定了检索要多完整、综合要多深入。例如元分析对完整性的要求，远高于对宽泛主题的映射研究 | [K&C §2.5.1]、[SIG-SR 必要 + 脚注 3]、[R&B22] | 一般不需要。但如果深度和广度的取舍取决于用户的目的，就属于偏好问题，需要询问 |
| **研究问题** | 后续所有步骤都围绕研究问题展开。用替代指标（例如用缺陷数代表质量）可能导致结论不可靠 | [K&C §5.3、§5.3.2] | 题目给定时一般不需要 |
| **检索策略的严格程度** | 检索过程要足够严格，与综述的目标相匹配 | [SIG-SR 加分 + 脚注 3] | 不需要 |
| **检索来源组合** | 单一来源会带来抽样偏差和发表偏差。可以组合手工检索与自动检索、向前/向后滚雪球、检查高产作者、正式数据库与索引、学位论文、预印本等。滚雪球不能完全替代数据库检索 | [SIG-SR 加分]、[Wohlin14]、[Wohlin22] | 如果需要的数据库没有访问权限，属于资源问题，需要上报 |
| **滚雪球的起始集** | 起始集决定了滚雪球能覆盖的范围。起始集缺乏多样性（例如几篇论文有共同作者）会带来偏差 | [Wohlin14] | 不需要 |
| **何时把论文用于下一轮滚雪球** | 没读全文就用于下一轮，一旦后来被排除，基于它找到的论文都要回滚 | [Wohlin14] | 不需要 |
| **纳入/排除标准与筛选** | 筛选应分阶段进行：先宽松地看标题和摘要，再按详细标准筛选。只看标题就排除，容易漏掉相关论文。多人评估时用 Cohen's Kappa 衡量一致性，分歧要讨论解决 | [K&C §6.2.2、§6.2.3]、[Wohlin14] | 见下方"单人研究"说明 |
| **质量评估** | K&C 提供了两份清单：定量研究按设计、执行、分析、结论四个阶段列出约 50 个问题（表 5）；定性研究约 18 个问题，涉及可信度、研究设计、抽样、数据收集、分析、报告和伦理（表 6）。应从中挑选适合本研究的问题，而不是照搬。论文没有报告某件事，不等于没做 | [K&C §6.3、§6.3.4] | 不需要 |
| **映射研究的分类方案** | 分类方案通过关键词标注逐步建立，决定了映射图能回答什么问题 | [Petersen08 §3.4] | 不需要 |
| **数据提取表设计** | 提取表要能回答研究问题和质量标准。条件允许时应由多人独立提取 | [K&C §6.4.1、§6.4.3] | 不需要 |
| **综合方式** | 叙述性综合、定量综合、定性综合各有适用场景；元分析不应使用"计票法"（vote counting） | [K&C §6.5]、[SIG-SR 加分] | 不需要 |
| **修改研究方案** | 研究方案在执行前评审；执行中修改检索式、纳入标准、研究问题，会影响结论的可信度 | [K&C §5.5] | 修改本身不一定需要人批准，但按项目章程的约束，必须记录修改内容和理由 [本项目分析] |

**单人研究的情况** [本项目分析]：
Kitchenham & Charters 建议，单人做综述时，可以对随机样本做"重测"（隔一段时间再评一次），或请导师抽查 [K&C §6.2.3、§6.4.3]。agent 实际上相当于单人研究者，这条建议可以对应为：由另一个独立的模型或独立的会话重复筛选和提取一部分样本，并计算一致性。这只是一个待验证的想法，不是结论。

## 4. 质量标准

以下以 SIGSOFT 标准为主（CC0 许可，下文为中文概括）。

### 必要 [SIG-SR]

- **引言**：说明综述类型
- **方法**：
  - 逐步、系统、可复现地描述检索过程，包括检索词
  - 给出明确的筛选标准
  - 说明从每篇一手研究中提取哪些数据，以及这些数据与研究问题的关系
  - 详细说明数据如何提取、如何综合（定性或定量均可）
  - 描述编码方案及其使用方式
- **结果**：从提取的数据到研究问题的答案，有清晰的证据链
- **讨论**：为实践者或非专业读者给出结论或建议

所有实证研究还要满足 General Standard 的必要项，例如：说明研究目的及其重要性；方法适合研究目的；结果直接回答研究问题；披露所有主要局限；结论与研究问题对应，并有明确证据支持 [SIG-GEN]。

### 加分 [SIG-SR]

- 提供补充材料：研究方案、检索词、检索结果、筛选过程记录、完整数据集、分析脚本、编码方案及示例、判定规则、边界情况说明
- 采取多种措施缓解抽样偏差和发表偏差（见第 3 节"检索来源组合"）
- 证明检索过程对综述目标而言足够严格
- 用事先确定的编码方案评估一手研究的质量，说明评估方法；排除低质量研究（可以），或把研究质量作为调节变量建模（更好）
- 评估覆盖程度，例如漏斗图、trim-and-fill 方法、已知论文的检出比例
- （实证主义取向的综述）由两名以上分析者独立工作，分析评分者间一致性，说明分歧如何解决
- （诠释主义取向的综述）反思研究者的偏见可能如何影响分析
- 用表格、图示整合结果；包含 PRISMA 流程图
- 通过已有或新建的概念框架进行分析（定性综合）
- 使用适合一手研究的元分析方法，不使用计票法
- 把结果整合进已有理论或研究，指出空白、偏差或未来方向
- 把结果呈现为基于证据的实用指南
- 明确区分基于证据的结果与解读、推测

**关于 PRISMA**：PRISMA 2020 是系统性综述的**报告**规范，而不是执行规范。它包含 7 个部分共 27 项检查条目；流程图记录识别、筛选、纳入三个阶段的论文数量，以及每一步排除的数量和理由。与 2009 版相比，它要求给出所有数据库的完整检索式，说明筛选人数、是否独立筛选、是否使用了自动化工具，并新增了数据和代码公开情况的说明 [PRISMA20]。

### 优秀 [SIG-SR]

- 两名以上研究者在确定检索范围和关键词之前，独立进行预检索
- 联系一手研究的作者，确认解读是否正确，或获取论文中没有的细节（如原始数据）
- 采用整合数据分析（integrative data analysis）

## 5. 评估时的注意事项

**可接受的偏离** [SIG-SR]：
- 专门研究某个会议或期刊（如 ICSE）对某主题的覆盖情况时，可以不处理发表偏差
- 一手研究数量过多（数千篇）时，可以对其做概率抽样
- 研究方法论问题的综述，可以不给实践者建议

**不成立的批评** [SIG-SR]：
- 在不同数据库中使用的检索式不完全相同
- 分析策略应该更定性或更定量

[SIG-GEN] 还列出了通用的不成立批评，例如：只说"缺少细节"却不指出缺什么；只说"不新颖"却不给出几乎相同的已发表研究；因为报告了负面结果而拒绝。

> **为什么要写这一节** [本项目分析]：如果用 LLM 做评委，它很可能提出这类不成立的批评，误判 agent 的产出。评估标准中应明确排除这些批评。

## 6. 反面模式

**SLR 特有** [SIG-SR]：
- 罗列式描述（"A 发现了 X，B 发现了 Y……"），而没有综合
- 用发表会议或期刊的档次代替对一手研究质量的直接评估
- 在高质量一手研究太少的领域做综述，导致结论不可靠

**检索相关** [Wohlin14]：
- 起始集缺乏多样性，例如几篇起始论文有共同作者
- 只看标题就做排除决定，容易漏掉相关论文
- 只找到一个相互引用的论文群，而忽略了与之没有引用关系的其他论文群

**综述类型相关**：
- 只聚焦使用某种特定研究方法的论文，在呈现整个研究领域时可能带来偏差 [Petersen08]
- 范围综述只做分类和计数，缺乏真正的综合 [R&B22]

**通用** [SIG-GEN]：
- 没有阅读和遵循该类研究的已发表指南就开展研究
- 结论或推广超出证据范围；淡化或回避局限
- 承认了局限，但写结论时却当局限不存在

**其他警示** [K&C]：
- 当某种方法由业界有影响力的团体推动时，发表偏差尤其严重 [K&C §6.1.2]
- 论文没有报告某件事，不等于没做 [K&C §6.3.4]
- 观察性研究可能不可靠，好的观察性研究需要考虑混杂因素 [K&C §6.3.1]

## 7. 对评估的启示 `[本项目分析]`

**有没有标准答案**：有。可以选择已发表、并附带完整检索和筛选记录的 SLR，让 agent 在同样的研究问题下重做，然后：
- 对比 agent 纳入的论文集合与原综述的集合，计算召回率和准确率
- 对比综合得出的主要结论是否一致

这种做法在文献中有先例：Wohlin 2014 正是用滚雪球方法重做了已发表的 SLR，再与原综述找到的论文集合对比 [Wohlin14]。他也指出了这种做法的一个效度威胁：重做者事先读过原综述，可能影响纳入判断。对 agent 来说，对应的风险是模型在训练中可能见过原综述，评估时需要考虑这一点。

需要注意：原综述有发表时间，复现时要把检索的时间范围限定在原综述的检索日期之前，否则新发表的论文会干扰对比。

**可以做阶段级评估的地方：**
- 给定研究问题，评估研究方案是否完整（对照 [K&C §5.4] 的清单）
- 给定研究方案，评估检索的召回率
- 给定候选论文集合，评估筛选结果与人工筛选的一致性
- 给定已纳入的论文，评估数据提取的准确性

**可以从过程记录中检查的信号：**
- 滚雪球每一轮新纳入的论文数应逐轮减少 [Wohlin14]；如果不减少，可能说明检索没有收敛
- 是否先读全文确认纳入，再用于下一轮滚雪球 [Wohlin14]

**在最终论文里看不出来、需要依赖过程记录的问题：**
- 执行中是否修改过检索式或纳入标准，以及为什么修改
- 筛选时排除了哪些论文、理由是什么
- 质量评估是否在综合之前完成，还是看到结果后才做

**与质量门槛的关系**：按 Ralph & Baltes 的观点，以描述为主的范围综述或映射研究大致对应 workshop 水平，而高质量的综合（元分析、案例调查、元综合）才适合主要会议 [R&B22 §3.1]。这和 P1 以 workshop 水平为门槛是一致的，也说明 SLR 类任务要向更高质量水平提升，关键在于综合，而不是收录更多论文。
