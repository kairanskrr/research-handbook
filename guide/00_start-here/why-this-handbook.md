# 我们为什么做这本手册

我们在做 auto research，也就是让大模型 agent 自己去做研究。想让 agent 做研究，得先回答：研究究竟是怎么做的？可当我们问自己这个问题时，却一时说不出来。

一个博士生从刚入学的新手，一步步成长为能独当一面的研究者，一路上积累了大量经验，其中很多是不知不觉积累下来的。这些东西很少有人系统地写下来，大多数人是在实践里慢慢摸出了自己的一套。所以我们想先把它写下来。

## 这本手册的目标

检验这本手册，只看一个问题：**一个刚开始做研究的人，照着它，能不能上手？**

所以它写给刚开始做科研的人，从头到尾写做研究的方法：怎样选题、设计研究、推进项目，以及各个学科有哪些自己的规矩。每条建议都能追溯到原文出处，并且尽量说人话。

## 说清楚，和自己练

这本手册想把做研究的方法尽量说清楚，包括很多人以为只能靠做才学得会的事，比如判断一个方向值不值得做、卡住了怎么调整。

但说清楚不等于不用练。知道该问哪几个问题，不等于第一次就能答好；判断力是在真实项目里一次次做出来的。手册能做的，是让你练的时候有方向、少走弯路。

每个人所处的环境、舒服和擅长的做事方式也不一样。同一条建议，你可能需要调整才用得顺，而怎么调整最适合你，也要在实践里试出来。

我们还在继续把这些说清楚。你在实践中发现哪里说得不对、不适用，欢迎[告诉我们](../../CONTRIBUTING.md)。

## 只写给人

这本手册纯粹是写给人的，不是写给 agent 的。

我们的顺序是：先把这些材料为人整理清楚；在这之后，再去探索怎样把它变成 agent 能有效使用的知识。那是下一步的事，不在这本手册里。
