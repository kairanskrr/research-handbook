# 我们为什么做这本手册

> 这一页讲本项目的初衷，是我们自己的想法，不是研究建议，所以没有脚注。

## 起点：我们在做 auto research

我们在做 auto research，也就是让大模型 agent 自己去做研究。

大模型越来越好用，我们也越来越依赖它，自己想得反而少了。可用着用着又常发现，很多事它做不好，于是回过头来跟它来回扯皮。

当机械的、只需要简单判断的工作逐渐交给 agent，留给人的，恰恰是更需要想清楚的那部分。这对我们自己的思考提出了更高的要求：很多平时不假思索、照着做的事，现在得停下来想一想，它到底是怎么回事。

科研就是这样一件事。

## 一个答不上来的问题

想让 agent 做研究，得先回答：研究究竟是怎么做的？里面有哪些方法论，有哪些诀窍？

一个博士生从刚入学的新手，一步步成长为能独当一面的研究者：写论文越来越快，知道什么值得做，能给出明确的方向。这一路上，他们积累了大量经验和知识，其中很多是不知不觉积累下来的。

可当我们问自己"研究到底怎么做"时，却一时说不出来。这些东西好像很少有人系统地总结过，大多数人是在实践里慢慢摸出了自己的一套。找 bug 也是这样：很难说清楚，只能去做，做多了才会。

## agent 需要什么

如果希望 agent 能做研究，它需要什么？是先给它一本研究手册，还是让它在实践中慢慢积累？可就算是积累，是不是也得先告诉它该怎么积累？

这些问题我们还没有答案。但我们觉得，第一步是把这些只可意会的东西尽量说清楚、写下来。

## 所以有了这本手册

这本手册试着把做研究的方法从头到尾写下来：怎样选题、设计研究、推进项目、写作投稿，以及各个学科有哪些自己的规矩。

我们给自己定了两条规矩：

- 每条建议都要能追溯到原文出处；属于我们自己判断的，不加脚注，读者一眼就能分开。
- 说人话，让刚开始做研究的人读得懂。

它首先写给人，写给刚开始做科研、还没摸出自己套路的人。它也是我们做 auto research 的基础：把研究讲清楚，人和 agent 都用得上。
