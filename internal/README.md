# 团队内部材料

这里存放团队自己的科研经验，本次尚未放入任何内容。外部标准只能说明"好的研究应该满足什么"，而这些材料能说明"研究实际上在哪里出问题"。

## 计划收集的材料

1. **真实项目的决策记录**
   请研究员回顾一个做过的项目，记下过程中的关键决策点：当时有哪些选项，最后选了什么，为什么这样选，哪些地方去问了别人、问了谁。

   这些记录可以同时用于三个地方：作为 S1 的锚点任务；作为评估参照，对比 agent 在同一决策点的选择；作为判断 agent 是否该上报的参照，因为它记录了人在哪里真正需要问别人。

2. **收到过的审稿意见**（包括被拒稿的）
   这是最真实的质量问题清单，可以补充各类研究的反面模式。

## 注意事项

- 审稿意见和未发表的工作可能涉及保密，**本仓库必须保持私有**。
- 放入之前请确认没有违反会议或期刊的保密要求。
- 涉及他人（审稿人、合作者）的信息，按需要做匿名化处理。
