# OSF Support：Organizing files

- 资料：`osforganizing`，[原文](https://help.osf.io/article/147-organizing-files)
- 版本：开放科学中心（Center for Open Science）OSF 平台官方帮助文档，网页，2026-10-05 读取。位置写小标题。

### E1

- 位置：Organizing files
- 原文："Organizing your files using names and locations that are informative help to document what your files are and how they relate to other files. The more informative your file organization, the more reproducible your research will be."
- 要点：文件名和位置本身就是文档；组织得越清楚，研究越容易复现。

### E2

- 位置：Separate raw data from derived data
- 原文："Within your data/ component, create separate subdirectories for raw data, derived data, and data summaries."
- 要点：在数据目录下，把原始数据、派生数据、数据汇总分到不同子目录。

### E3

- 位置：Make raw data read-only
- 原文："When you are not entering data, make your raw data file read-only to ensure it is not altered or mixed with other data. [...] Don’t attempt calculations, sums, or visualizations within the raw data file."
- 要点：不录入数据时把原始数据设为只读；不要在原始数据文件里做计算、求和或画图。

### E4

- 位置：Make README files
- 原文："Document the files contents and purpose of the directory and each subdirectory. [...] Whenever files are added or the subdirectory is changed, update the README file to document the changes."
- 要点：用 README 说明目录及子目录的内容和用途；文件增减或目录变化时同步更新 README。
