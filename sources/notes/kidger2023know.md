# Kidger 2023：Just know stuff

- 资料：`kidger2023know`，[原文](https://kidger.site/thoughts/just-know-stuff/)
- 版本：作者博客，2023。标题全称为 "Just know stuff. (Or, how to achieve success in a machine learning PhD.)"。文中具体清单针对机器学习，这里只取通用原则。

### E1

- 位置：开头
- 原文："Know your field inside-out. Know as much about adjacent fields (in math, statistics, …) as you can." / "possessing a technical depth of knowledge is how you come up with new ideas and learn to recognise bad ones."
- 要点：把自己的领域吃透，尽量了解相邻领域；有深厚的知识，才能想出新点子，也才能认出坏点子。

### E2

- 位置：结尾
- 原文："Don’t expect to cover all of that in a few months; this is something that should happen over the next few years."
- 要点：知识积累不是几个月的事，而是几年的事。

### E3

- 位置：结尾
- 原文："One never really stops learning."
- 要点：学习没有终点。
