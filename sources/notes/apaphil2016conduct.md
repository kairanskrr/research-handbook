# 美国哲学学会 2016：Code of Conduct

- 资料：`apaphil2016conduct`，[原文](https://www.apaonline.org/page/codeofconduct)
- 版本：美国哲学学会（American Philosophical Association）行为准则，由 Nancy J. Holland 主持的工作组起草，2016 年理事会批准。官网对脚本拦截，原文取自 Internet Archive 快照。位置写小标题。

### E1

- 位置：I. Code of Ethics
- 原文："Respecting the philosophical opinions and traditions of others, without disparaging those who hold positions at odds with one’s own;"
- 要点：哲学家在一切职业交往中的责任之一：尊重他人的哲学观点和传统，不贬低和自己立场相反的人。

### E2

- 位置：I. Code of Ethics
- 原文："Maintaining integrity and trust in all professional commitments and interactions; and"
- 要点：在一切职业承诺和交往中保持诚信。

### E3

- 位置：I. Code of Ethics
- 原文："With the adoption of this Code of Conduct in 2016, the APA reaffirms its commitment to the AAUP statement and to the core value reflected in that statement: academic freedom."
- 要点：美国哲学学会通过这份准则，重申对美国大学教授协会（AAUP）职业伦理声明及其核心价值"学术自由"的承诺。
