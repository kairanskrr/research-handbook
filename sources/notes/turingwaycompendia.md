# The Turing Way：Research Compendia

- 资料：`turingwaycompendia`，[原文](https://book.the-turing-way.org/reproducible-research/compendia)
- 版本：The Turing Way 社区编写的开放手册（CC-BY 4.0），网页，2026-10-05 读取。位置写小标题。

### E1

- 位置：Summary
- 原文："A research compendium is a collection of all digital parts of a research project including data, code, texts (protocols, reports, questionnaires, meta data)."
- 要点：研究汇编（research compendium）是一个研究项目全部数字材料的集合，包括数据、代码和各种文本（方案、报告、问卷、元数据）。

### E2

- 位置：Summary
- 原文："The main purpose is that all elements of a project are published together, so a basic folder structure combining all components can be sufficient."
- 要点：重点是把项目的所有部分放在一起；一个把各部分组织起来的基本文件夹结构就够了，不需要高深的技术。

### E3

- 位置：Structure of a Research Compendium
- 原文："Files should be organized in a conventional folder structure; [...] Data, methods, and output should be clearly separated; [...] The computational environment should be specified."
- 要点：三条原则：用约定俗成的文件夹结构；数据、方法、产出清楚分开；写明计算环境。

### E4

- 位置：Basic Compendium
- 原文："Furthermore, any compendium should have a landing page in the form of a README document."
- 要点：每个研究汇编都应有一个 README 作为入口页。
