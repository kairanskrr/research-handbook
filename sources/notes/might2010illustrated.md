# Might 2010：The illustrated guide to a Ph.D.

- 资料：`might2010illustrated`，[原文](https://matt.might.net/articles/phd-school-in-pictures/)
- 版本：作者主页，2010。用一组图说明博士工作就是把人类知识的边界向外推出一个小凸起。

### E1

- 位置：图解序列
- 原文："You push at the boundary for a few years:" / "Until one day, the boundary gives way:"
- 要点：在知识边界上推好几年，直到某一天边界被推动。

### E2

- 位置：图解序列结尾
- 原文："Of course, the world looks different to you now:" / "So, don't forget the bigger picture:" / "Keep pushing."
- 要点：做出一点突破后，世界在你眼里会不一样；但别忘了更大的图景，继续往前推。
