# Cumming、Fidler 和 Vaux 2007：Error bars in experimental biology

- 资料：`cumming2007error`，[原文（PubMed Central）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2064100/)
- 版本：Journal of Cell Biology 177(1):7–11，2007 年，免费全文。原文文本读取自 Europe PMC 全文接口，2026-10-06。位置写小标题或规则编号。

### E1

- 位置：What do error bars tell you?，Rule 1
- 原文："Rule 1: when showing error bars, always describe in the figure legends what they are."
- 要点：画误差线，一定要在图注里写明它是什么（标准差、标准误还是置信区间）。

### E2

- 位置：Replicates or independent samples—what is n?，Rule 2
- 原文："Rule 2: the value of n (i.e., the sample size, or the number of independently performed experiments) must be stated in the figure legend."
- 要点：图注里必须写明 n，也就是样本量或独立进行的实验次数。

### E3

- 位置：Replicates or independent samples—what is n?
- 原文："If an experiment involves triplicate cultures, and is repeated four independent times, then n = 4, not 3 or 12."
- 要点：每次做三个平行培养，独立重复四次，n = 4，不是 3，也不是 12。

### E4

- 位置：Replicates or independent samples—what is n?，Rule 3
- 原文："Rule 3: error bars and statistics should only be shown for independently repeated experiments, and never for replicates. If a ‘representative’ experiment is shown, it should not have error bars or P values, because in such an experiment, n = 1"
- 要点：误差线和统计只能用于独立重复的实验，不能用于重复测量；展示"代表性实验"时 n = 1，不应画误差线、给 P 值。

### E5

- 位置：What type of error bar should be used?，Rule 4
- 原文："However, if n is very small (for example n = 3), rather than showing error bars and statistics, it is better to simply plot the individual data points."
- 要点：n 很小（如 n = 3）时，与其画误差线、做统计，不如直接把每个数据点画出来。

### E6

- 位置：Statistical significance tests and P values
- 原文："It is a common and serious error to conclude ‘no effect exists’ just because P is greater than 0.05."
- 要点：仅因为 P 大于 0.05 就下结论说"没有效应"，是常见而严重的错误。

### E7

- 位置：Statistical significance tests and P values
- 原文："Of course, even if results are statistically highly significant, it does not mean they are necessarily biologically important."
- 要点：统计上高度显著，不等于生物学上重要。

### E8

- 位置：Replicates or independent samples—what is n?
- 原文："In the example of replicate cultures from the one stock of cells, the population being sampled is the stock cell culture. For n to be greater than 1, the experiment would have to be performed using separate stock cultures, or separate cell clones of the same type."
- 要点：从同一份细胞储备液分出的平行培养，抽样的总体只是这一份储备液；要让 n 大于 1，需要用不同的储备培养物或同类型的不同细胞克隆来做。
