# Black 2022：Novelty in Science: A guide for reviewers

- 资料：`black2022novelty`，[原文](https://perceiving-systems.blog/en/news/novelty-in-science)
- 版本：博客文章，Perceiving Systems Blog。

### E1

- 位置：开头
- 原文："I see reviewers regularly mistake complexity, difficulty, and technicality for novelty."
- 要点：审稿人常把复杂、困难、技术性强误当成新颖。

### E2

- 位置：Novelty as complexity
- 原文："If nobody thought to change that one term, then it is ipso facto novel."
- 要点：只改了一处、但以前没人想到这样改，这本身就是新颖的。

### E3

- 位置：Novelty as surprise
- 原文："The novelty, however, must be evaluated before the idea existed."
- 要点：新颖性要站在想法出现之前来评判；事后看来显而易见，不减损其新颖性。

### E4

- 位置：Novelty as technical novelty
- 原文："A new dataset can be novel if it does something no other dataset has done, even if all the methods used to generate the dataset are well known. A new use of an old method can be novel if nobody ever thought to use it this way."
- 要点：新颖性不只在技术细节：新数据集、旧方法的新用法也可以是新颖的。

### E5

- 位置：Novelty as usefulness or value
- 原文："Lack of utility is indeed an issue but it is very hard to assess with a new idea. Reviewers should be careful here and aware that we all have limited imagination."
- 要点：新想法的用处很难提前判断，审稿人要意识到自己的想象力有限。

### E6

- 位置：Novelty as difficulty
- 原文："A simple idea can be important. But it can also be trivial."
- 要点：简单的想法可能重要，也可能平凡；平凡指的是不重要，而不是简单。
