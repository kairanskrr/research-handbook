# Rosenberg 等人 2020：The Next Frontier: Making Research More Reproducible

- 资料：`rosenberg2020next`，[原文（美国国家科学基金会公共访问库中的作者录用稿）](https://par.nsf.gov/servlets/purl/10188458)
- 版本：Journal of Water Resources Planning and Management 146(6): 01820002 的作者录用稿（accepted version），社论。

### E1

- 位置：正文，Figure 1 之后
- 原文："This policy has subsequently been adopted by nearly all of the 30+ journals published by the American Society of Civil Engineers."
- 要点：2018 年《水资源规划与管理期刊》的数据可得性政策，后来被 ASCE 出版的 30 多种期刊中的几乎全部采用。

### E2

- 位置：正文第 2 段
- 原文："3) Authors cannot share proprietary or sensitive materials or materials containing protected intellectual property; 4) Some workflows use stochastic, high performance computing, big data, or methods with long run times that are too big to share or reproduce bit for bit"
- 要点：复现的障碍包括：专有或敏感材料、含受保护知识产权的材料不能共享；有些流程用到随机方法、高性能计算、大数据或运行很久的方法，太大，无法共享或逐位复现。

### E3

- 位置：Checklist，Make all materials available in the repository
- 原文："Specify which code segments produce each figure, table, or other results in the article." / "Remove (or indicate) code references to local paths that are machine (user) specific."
- 要点：写明哪段代码生成论文中的哪张图、哪个表；去掉（或标出）只在自己电脑上有效的本地路径。

### E4

- 位置：Checklist，Make all materials available in the repository
- 原文："Write directions assuming people who will use the content are technically proficient in the field but not familiar with the data, models, code, software, programming language, methods, or study materials."
- 要点：写使用说明时，假设读者懂本领域技术，但不熟悉你的数据、模型、代码、软件和方法。

### E5

- 位置：Checklist，Make proprietary, private, sensitive, computationally intensive, and stochastic data, models, and code more reproducible
- 原文："Where possible, make available the input and output data from every step of a workflow that uses proprietary software or is data intensive, requires a long run time, or cannot be rerun by other users."
- 要点：流程中用到专有软件、数据量大、运行时间长或别人无法重跑的步骤，尽量公开每一步的输入和输出数据。

### E6

- 位置：正文，好处列表之后
- 原文："Each benefit also provides professionals better access to published research and can help narrow the gap between research and practice."
- 要点：公开材料也让工程从业者更容易用上已发表的研究，有助于缩小研究和实践之间的差距。
