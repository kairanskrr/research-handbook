# Lakens 2022：Sample Size Justification

- 资料：`lakens2022sample`，[原文 PDF（PsyArXiv 预印本）](https://osf.io/preprints/psyarxiv/9d3yf/)
- 版本：PsyArXiv 预印本，正式版发表于 Collabra: Psychology 8(1):33267。位置写小标题。

### E1

- 位置：摘要
- 原文："six approaches are discussed to justify the sample size in a quantitative empirical study: 1) collecting data from (almost) the entire population, 2) choosing a sample size based on resource constraints, 3) performing an a-priori power analysis, 4) planning for a desired accuracy, 5) using heuristics, or 6) explicitly acknowledging the absence of a justification."
- 要点：说明样本量的六种理由：收集（几乎）整个总体、按资源限制定、做事先功效分析、按想要的估计精度定、按经验规则定、明确承认没有理由。

### E2

- 位置：A-priori Power Analysis
- 原文："Given a specified effect size, alpha level, and power, an a-priori power analysis can be used to calculate the number of observations required to achieve the desired error rates, given the effect size."
- 要点：事先功效分析：给定效应量、显著性水平和想要的功效，算出需要多少观测。

### E3

- 位置：A-priori Power Analysis
- 原文："an a-priori power analysis is useful, as long as a researcher can justify the effect sizes they are interested in."
- 要点：功效分析有没有用，取决于你能不能说清楚为什么选这个效应量。

### E4

- 位置：What is the Expected Effect Size?（用已有研究估计效应量）
- 原文："a pilot study does not provide a meaningful effect size estimate for planning subsequent studies due to the imprecision inherent in data from small samples."
- 要点：Lakens 引用 Leon 等人的话：小样本的预实验估出的效应量很不精确，不能拿来给正式研究算样本量。

### E5

- 位置：What is the Expected Effect Size?
- 原文："effect size estimates from studies can differ from the true population effect size due to random variation, and that publication bias inflates effect sizes."
- 要点：从已发表文献里拿效应量要小心：既有随机误差，又因为发表偏差（显著结果更容易发表）而被高估。

### E6

- 位置：A-priori Power Analysis
- 原文："the default recommendation to aim for 80% power lacks a solid justification."
- 要点："功效达到 80%"只是惯例，本身没有坚实的理由；错误率应该根据具体情况说明理由。

### E7

- 位置：Resource Constraints
- 原文："Because resource limitations always play a role, a responsible scientist carefully evaluates resource constraints when designing a study."
- 要点：资源总是有限的。负责任的研究者在设计研究时要认真评估资源限制。
