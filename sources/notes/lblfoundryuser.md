# 美国劳伦斯伯克利国家实验室 Molecular Foundry：User Program Overview

- 资料：`lblfoundryuser`，[原文](https://foundry.lbl.gov/become-a-foundry-user/)
- 版本：美国能源部（DOE）纳米科学用户设施 Molecular Foundry 的用户项目说明页，2026-10-06 读取。

### E1

- 位置：User Program Overview（页首）
- 原文："It is open to any interested researcher (“user”) through a competitive peer-reviewed proposal process administered by our User Program Office."
- 要点：任何有兴趣的研究者都可以通过竞争性的同行评审申请成为用户。

### E2

- 位置：User Program Overview（页首）
- 原文："Access to the Molecular Foundry is free of charge for non-proprietary research; the vast majority of projects fall into this category."
- 要点：非保密研究免费使用，绝大多数项目属于这一类。

### E3

- 位置：User Program Overview（页首）
- 原文："Proprietary projects pay a full cost recovery rate during the period when the project is active."
- 要点：保密（专有）项目要按全成本付费。

### E4

- 位置：2. Apply for Access
- 原文："Becoming a Foundry user generally begins by submitting a proposal to one of our twice-yearly proposal calls."
- 要点：成为用户一般要先在每年两次的征集中提交申请。

### E5

- 位置：3. Prepare to Start Work
- 原文："Once at the Foundry, there will be additional safety training courses that will be required before you can start work."
- 要点：到了设施之后，开始工作前还要上额外的安全培训课程。

### E6

- 位置：5. Project End and Reporting
- 原文："When you publish work that involved the Foundry, you need to include the facility in the acknowledgment using the correct text."
- 要点：发表用到该设施的成果时，要在致谢中按规定的措辞写上设施。
