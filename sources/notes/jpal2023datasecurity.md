# J-PAL 研究资源：Data security procedures for researchers

- 资料：`jpal2023datasecurity`，[原文网页](https://www.povertyactionlab.org/resource/data-security-procedures-researchers)
- 版本：J-PAL 研究资源页，作者 Elisabeth O'Toole、Laura Feeney、Kenya Heard、Rohit Naimpally，2023 年 5 月更新；2026 年 10 月访问。位置写小标题。

### E1

- 位置：Data security overview
- 原文："Even seemingly de-identified data may be re-identified if enough unique characteristics are included."
- 要点：看似去掉身份信息的数据，只要包含足够多的独特特征，也可能被重新识别。

### E2

- 位置：Minimizing data security threats
- 原文："Reduce the data security threat-level a priori by acquiring and handling only the minimum amount of sensitive data strictly needed for the research study."
- 要点：只收集和处理研究严格需要的最少量敏感数据。

### E3

- 位置：De-identifying data
- 原文："Separate Personally Identifiable Information (PII) from all other data as soon as possible"
- 要点：尽快把可识别个人身份的信息和其他数据分开。

### E4

- 位置：Data security overview
- 原文："Researchers should also ensure that their research assistants, students, implementing partners, and data providers have a basic understanding of data security protocols."
- 要点：研究助理、学生、实施伙伴和数据提供方都要了解基本的数据安全规程。
