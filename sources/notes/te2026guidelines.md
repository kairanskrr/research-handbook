# Theoretical Economics：Guidelines for Referees

- 资料：`te2026guidelines`，[原文](https://www.econometricsociety.org/publications/theoretical-economics/policies/guidelines-for-referees)
- 版本：计量经济学会（Econometric Society）旗下理论期刊 Theoretical Economics 的审稿人指南网页，2026 年 10 月查看，网页未写日期。代表这一份期刊的要求。

### E1

- 位置：The opinion
- 原文："This section should explain the strengths and weaknesses of the paper. Length should be used as a criterion in the assessment."
- 要点：审稿意见要讲清论文的长处和短处；篇幅本身是评判标准之一。

### E2

- 位置：Substantive comments
- 原文："You should state if (and how) the paper can be made shorter. Which results should be prioritized, and which should be cut? Can the paper be made more succinct, and the proofs shorter, if the results are less general?"
- 要点：审稿人要指出论文能不能、怎样缩短：哪些结果优先保留、哪些删掉；如果结果不那么一般，论文和证明能不能更简短。

### E3

- 位置：Substantive comments
- 原文："The report should suggest only extensions that are essential for the paper at hand."
- 要点：审稿人只应要求对这篇论文必不可少的扩展。
