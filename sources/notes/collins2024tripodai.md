# Collins 等人 2024：TRIPOD+AI statement: updated guidance for reporting clinical prediction models that use regression or machine learning methods

- 资料：`collins2024tripodai`，[原文（BMJ，开放获取）](https://doi.org/10.1136/bmj-2023-078378)；读取的是 Europe PMC 的全文（PMC11019967）
- 版本：BMJ 2024;385:e078378，按 CC BY 4.0 许可开放获取。位置写小节或表格。

### E1

- 位置：Summary points
- 原文："The TRIPOD+AI statement consists of a 27 item checklist, an expanded checklist that details reporting recommendations for each item, and a TRIPOD+AI for Abstracts checklist containing 13 items"
- 要点：TRIPOD+AI 包括一份 27 项的清单、逐项展开的说明，以及一份 13 项的摘要清单。

### E2

- 位置：Abstract
- 原文："TRIPOD+AI provides harmonised guidance for reporting prediction model studies, irrespective of whether regression modelling or machine learning methods have been used."
- 要点：不管用回归还是机器学习方法，开发或评估预测模型的研究都可以按 TRIPOD+AI 报告。

### E3

- 位置：Table 1 Reporting guidelines for healthcare studies using machine learning
- 原文："Medical imaging studies using artificial intelligence" / "Early stage clinical evaluation (including safety, human factors evaluation) of decision support systems driven by artificial intelligence" / "Clinical trial reports evaluating an intervention with an artificial intelligence component"
- 要点：表 1 列出了用到机器学习的健康研究的报告规范，例如：医学影像人工智能研究用 CLAIM；人工智能决策支持系统的早期临床评估（含安全性和人因评估）用 DECIDE-AI；含人工智能成分的临床试验报告用 CONSORT-AI。

### E4

- 位置：Development of TRIPOD+AI，第 1 段
- 原文："There is no such thing as a validated prediction model. To avoid ambiguity and harmonise terminology, we refer to validation as evaluation in this article"
- 要点：作者认为不存在"已经验证好的预测模型"；为了避免歧义，文中把"验证"（validation）改称"评估"（evaluation）。

### E5

- 位置：Box 1 Glossary，Evaluation or test data
- 原文："Evaluation data should be distinct from the data used to train the model, tune hyperparameters, or do model selection, such that there is no overlap in participants between the training and evaluation data."
- 要点：评估数据要和训练、调参、选模型用的数据分开，两边不能有同一个受试者。

### E6

- 位置：Box 1 Glossary 脚注
- 原文："Validation data often has different meanings. For example, in machine learning studies, validation data can refer to data used for parameter tuning or data used to evaluate model performance"
- 要点："验证数据"一词含义不一：在机器学习研究里，它可能指调参用的数据，也可能指评估模型表现的数据。

### E7

- 位置：Discussion，open science 部分
- 原文："TRIPOD+AI prominently features open science practices."
- 要点：TRIPOD+AI 很突出开放科学做法（清单中有关于研究方案、登记、数据共享和代码共享的条目）。
