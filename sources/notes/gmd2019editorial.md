# GMD Executive Editors 2019：Editorial: The publication of geoscientific model developments v1.2

- 资料：`gmd2019editorial`，[原文](https://doi.org/10.5194/gmd-12-2215-2019)
- 版本：Geoscientific Model Development 12, 2215–2225, 2019，开放获取（CC BY 4.0）。读取的是期刊网站上的 PDF。

### E1

- 位置：摘要
- 原文："Best practice in code and data archiving continues to develop and is far from universal among scientists."
- 要点：GMD 编辑认为，代码和数据存档的良好做法在科学家中还远未普及。

### E2

- 位置：§2
- 原文："Bugs occur in essentially all non-trivial code."
- 要点：几乎所有不简单的代码都有错误（bug）。

### E3

- 位置：§2
- 原文："Even given two codes attempting to implement the same algorithm, there is no guarantee that the results will be the same, and without source code it is impossible to establish the underlying cause of the differences."
- 要点：两个实现同一算法的程序，结果也未必相同；没有源代码，就无法查出差异从哪来。

### E4

- 位置：§3.1 Source code is necessary but not sufficient
- 原文："It is also necessary to have access to all of the input data and to know all of the steps which were taken from raw data to points on graphs or numbers in tables."
- 要点：光有源代码不够，还要有全部输入数据，并知道从原始数据到图上每个点、表中每个数的全部步骤。

### E5

- 位置：§3.2 Manual processing considered harmful
- 原文："This frequently occurs when figures are produced interactively. Unfortunately, this breaks the provenance chain between the model and the paper" / "The only remedy for this is for authors to consistently ensure that there is no manual processing of the data: models are run by a script, and all pre- and post-processing is scripted."
- 要点：交互式手工处理数据、手工画图会切断模型和论文之间的"来源链"；唯一的补救是全部用脚本运行和处理。

### E6

- 位置：§3.3 Source code or data may be unavailable
- 原文："In particular, some of the current Earth system models have restricted licences controlled by large institutions."
- 要点：一些地球系统模式由大机构控制，许可证受限，代码不能自由公开。

### E7

- 位置：§3.4 Embargoes
- 原文："It is the opinion of the GMD editors that if the code is not ready, then neither is the manuscript."
- 要点：GMD 编辑的看法：代码没准备好，论文也就没准备好。

### E8

- 位置：§4 Journals and archives
- 原文："if code has not been curated sufficiently well, it may not be possible to recover the exact version used in a paper"
- 要点：代码没管理好，事后可能找不回论文用的确切版本，"向作者索取"靠不住。

### E9

- 位置：§3.5 Archive on submission
- 原文："at the core of the open review process of European Geosciences Union journals is the idea that the submitted manuscript and the review process are openly and persistently available to scrutiny."
- 要点：欧洲地球科学联合会（EGU）期刊采用公开审稿：投稿和审稿过程都公开、长期可查。

### E10

- 位置：§3.5 Archive on submission
- 原文："the code and data availability section in the manuscript can and should identify the preferred download location for the latest model version, in addition to citing the archived version corresponding to the given publication."
- 要点：既引用论文对应的存档版本，也可以给出最新版的下载地址，两者并存。
