# 3GPP：About 3GPP

- 资料：`3gpp2026about`，[原文](https://www.3gpp.org/about-us)
- 版本：第三代合作伙伴计划（3rd Generation Partnership Project，3GPP）官网"关于我们"页面，2026-10-06 读取。

### E1

- 位置：页首
- 原文："3GPP specifications cover cellular telecommunications technologies, including radio access, core network and service capabilities, which provide a complete system description for mobile telecommunications."
- 要点：3GPP 的规范覆盖蜂窝移动通信的无线接入、核心网和业务能力，构成移动通信的完整系统描述。

### E2

- 位置：历史部分
- 原文："3GPP was created in 1998 to develop 3G mobile standards for WCDMA and TD-SCDMA accesses and their core networks."
- 要点：3GPP 成立于 1998 年，最初为了制定 3G 移动通信标准。

### E3

- 位置：Release 时间线
- 原文："In parallel, we now have the 6G Timeline in place & work has started on 6G studies - due for completion in 2026."
- 要点：3GPP 的工作按版本（Release）推进，6G 研究已经启动。
