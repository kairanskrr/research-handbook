# Leonard 2018：Reflections on (de)colonialism in language documentation

- 资料：`leonard2018decolonialism`，[原文](http://hdl.handle.net/10125/24808)
- 版本：Language Documentation & Conservation Special Publication 15，pp. 55–65，开放获取；作者为美国加州大学河滨分校语言学者，文中以迈阿密族（美国原住民）社区成员的身份写作

### E1

- 位置：§2
- 原文："a documentation corpus may contain carefully annotated texts but lack examples of conversations."
- 要点：记录语料可能有精心标注的文本，却缺少对话。

### E2

- 位置：§2
- 原文："a decolonial approach calls not just for considering community needs, but rather for starting with them in conceiving of language documentation as an idea"
- 要点：不只是考虑社区需求，而是从社区需求出发来构想语言记录。

### E3

- 位置：§3
- 原文："one useful practice when disseminating documentation is to feature larger and well-contextualized language examples, initially represented as the community would most commonly represent them"
- 要点：发布记录时，先用较长、有语境的例子，并按社区最常用的方式呈现。

### E4

- 位置：§3
- 原文："it is important to start an example using unbroken words."
- 要点：行间注释的例句，第一行应先给不切分的完整词。

### E5

- 位置：§1
- 原文："My tribal community shifted away from myaamia almost entirely"
- 要点：作者说自己的部族社区几乎完全不再使用迈阿密语（myaamia），可见他以社区成员身份写作。
