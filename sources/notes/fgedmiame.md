# FGED Society：MIAME（Minimum Information About a Microarray Experiment）

- 资料：`fgedmiame`，[原文](https://www.fged.org/projects/miame/)
- 版本：功能基因组数据学会（Functional Genomics Data Society，FGED）的项目网页，2026-10-08 读取。页面注明该学会已停止运作，网页仍保留。MIAME 最早发表于 Brazma 等人 2001（Nature Genetics）。位置写段落。

### E1

- 位置：页首
- 原文："MIAME describes the Minimum Information About a Microarray Experiment that is needed to enable the interpretation of the results of a microarray experiment unambiguously and potentially to reproduce the experiment. [ Brazma et al. (2001), Nature Genetics"
- 要点：MIAME 规定了一项基因芯片实验最少要提供哪些信息，让别人能无歧义地解读结果，并有可能重复实验；出处是 Brazma 等人 2001 年发表在 Nature Genetics 上的论文。

### E2

- 位置：六个关键要素
- 原文："The six most critical elements contributing towards MIAME are:" / "The raw data for each hybridisation (e.g., CEL or GPR files)" / "The final processed (normalised) data for the set of hybridisations in the experiment (study)" / "The essential sample annotation including experimental factors and their values" / "The experimental design including sample data relationships (e.g., which raw data file relates to which sample, which hybridisations are technical, which are biological replicates)" / "Sufficient annotation of the array" / "The essential laboratory and data processing protocols (e.g., what normalisation method has been used to obtain the final processed data)"
- 要点：六个关键要素：每次杂交的原始数据；最终处理（标准化）后的数据；样品的基本注释，包括实验因素及其取值；实验设计，包括哪个数据文件对应哪个样品、哪些是技术重复、哪些是生物学重复；芯片的足够注释；基本的实验和数据处理流程（例如用了什么标准化方法）。
