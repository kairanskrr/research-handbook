# Wohlin 2014：Guidelines for snowballing in systematic literature studies and a replication in software engineering

- 资料：`wohlin2014guidelines`，[原文 PDF（作者主页）](https://www.wohlin.eu/ease14.pdf)
- 版本：EASE 2014 论文。

### E1

- 位置：§1
- 原文："Using the references and the citations respectively is referred to as backward and forward snowballing."
- 要点：顺着一篇论文的参考文献往前找，叫向后滚雪球；顺着引用了它的论文往后找，叫向前滚雪球。

### E2

- 位置：§3.1 Start Set
- 原文："A good start set may be identified by using, for example, Google Scholar. It is a good alternative to avoid bias in favour of any specific publisher."
- 要点：起始论文集可以用 Google Scholar 来找，避免偏向某一家出版社。

### E3

- 位置：§3.1 Start Set
- 原文："If relevant papers may come from different communities, then it is important to have these covered in the start set. This is particularly crucial if there is a risk that relevant papers may be in independent clusters, i.e. in clusters of papers not referring to each other. [...] The start set should cover several different publishers, years and authors. The important issue here is diversity. The start set ought to be formulated from keywords in the research question, while preferably also taking synonyms into account."
- 要点：起始集要多样：覆盖不同研究社区、出版社、年份和作者；从研究问题的关键词出发，并考虑同义词。否则可能漏掉"互不引用"的另一群论文。

### E4

- 位置：§3.2 Iterations
- 原文："To finally decide to include a paper means that the full paper should be examined before deciding to use it as a paper in the snowballing. If not doing this, a rollback is needed if other papers are included based on a paper that later is excluded."
- 要点：一篇论文要读完全文、确定纳入后，才能拿来做下一轮滚雪球；否则它后来被排除时，从它找到的论文都要退回重来。

### E5

- 位置：§3.2.1 Backward Snowballing
- 原文："The first step is to go through the reference list and exclude papers that do not fulfil the basic criteria such as, for example, language, publication year and type of publication [...]. The next step is to remove papers from the list that have already been examined [...]. If the paper still is a candidate for inclusion after having looked at it in the reference list, then the next step is to examine where and how the paper is referenced."
- 要点：向后滚雪球的做法：先按语言、年份、发表类型等基本条件排除，再去掉已经看过的；还剩下的，看它在原文中被引用的位置和上下文，再决定要不要读。

### E6

- 位置：§3.3 Authors
- 原文："Once no new papers are found in the iterations using both backward and forward snowballing, the loop is ended."
- 要点：向后、向前滚雪球都找不到新论文时停止。
