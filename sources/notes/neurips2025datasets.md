# NeurIPS 2025：Datasets & Benchmarks Track 征稿启事

- 资料：`neurips2025datasets`，[原文](https://neurips.cc/Conferences/2025/CallForDatasetsBenchmarks)
- 版本：NeurIPS 2025 数据集与基准分会征稿页，2026-10-17 读取。
- 说明：2025 年的分会征稿沿用主会征稿启事，另加三点：可单盲、提交时必须提供数据集和代码、专门的收稿范围。审稿因素等其他内容见 `neurips2024datasets`。

### E1

- 位置：DB track specifics，2. Required dataset and benchmark code submission，Access
- 原文："Datasets and code should be available and accessible to all reviewers, ACs and SACs at the time of submission. Data should be found and obtained without a personal request to the PI. Code should be documented and executable. Non-compliance justifies the desk rejection of the paper."
- 要点：投稿时数据和代码就要让审稿人能拿到，不用私下找负责人要；代码要有文档、能运行。做不到可以直接拒稿。

### E2

- 位置：DB track specifics，2. Required dataset and benchmark code submission，Hosting
- 原文："New datasets should be hosted at one of the hosting sites dedicated to ML datasets (Dataverse, Kaggle, Hugging Face, or OpenML) or at a bespoke hosting site if the dataset requires it."
- 要点：新数据集应托管在专门的机器学习数据平台（Dataverse、Kaggle、Hugging Face、OpenML），确有需要时可用专门的网站。

### E3

- 位置：DB track specifics，2. Required dataset and benchmark code submission，Metadata
- 原文："Authors should use the Croissant machine-readable format to document their datasets in a machine-readable way and include the Croissant file with their paper submission in OpenReview."
- 要点：要用 Croissant 格式（一种机器可读的数据集描述格式）记录数据集，并随论文提交。

### E4

- 位置：DB track specifics，3. Specific scope
- 原文："Advanced practices in data collection and curation that are of general interest even if the data itself cannot be shared. Private data sets, however, cannot be listed as contributions, and the methodology should also be validated on reproducible and publicly available data/tools."
- 要点：数据不能公开时，可以把收集和整理数据的做法作为贡献，但私有数据集本身不能算贡献，方法还要在公开可复现的数据或工具上验证。

### E5

- 位置：DB track specifics，2. Required dataset and benchmark code submission
- 原文："All accepted papers should have their code and datasets documented and publicly available by the camera-ready deadline."
- 要点：论文被接收后，到提交最终版时，代码和数据集都要有文档并公开。

### E6

- 位置：DB track specifics，3. Specific scope
- 原文："Frameworks for responsible dataset development, audits of existing datasets, identifying significant problems with existing datasets and their use"
- 要点：收稿范围包括：负责任地开发数据集的框架、审查已有数据集、找出已有数据集及其用法中的重大问题。
