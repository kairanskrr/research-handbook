# PLOS：Data Availability

- 资料：`plosdatapolicy`，[原文](https://journals.plos.org/plosone/s/data-availability)
- 版本：PLOS 系列期刊的数据政策网页，适用于所有 PLOS 期刊，2026-10-06 读取。这是一家出版商的政策，用来举例说明期刊对数据的要求。位置写小标题。

### E1

- 位置：Introduction
- 原文："PLOS journals require authors to make all data necessary to replicate their study’s findings publicly available without restriction at the time of publication."
- 要点：PLOS 要求作者在发表时公开重复研究结果所需的全部数据，不加限制。

### E2

- 位置：Acceptable data sharing methods（数据仓库）
- 原文："If field-specific standards for data deposition exist, PLOS requires authors to comply with these standards. Authors should select repositories appropriate to their field of study (for example, ArrayExpress or GEO for microarray data; GenBank, EMBL, or DDBJ for gene sequences)."
- 要点：领域有专门的数据提交标准时必须遵守；要选本领域合适的仓库，例如芯片数据交 ArrayExpress 或 GEO，基因序列交 GenBank、EMBL 或 DDBJ。

### E3

- 位置：Acceptable data sharing methods（数据仓库）
- 原文："The Data Availability Statement must list the name of the repository or repositories as well as digital object identifiers (DOIs), accession numbers or codes, or other persistent identifiers for all relevant data."
- 要点：数据可用性声明里要写出仓库名称，以及所有相关数据的 DOI、登录号（accession number）或其他永久标识。

### E4

- 位置：Minimal data set
- 原文："PLOS does not permit references to “data not shown.”"
- 要点：PLOS 不允许在论文里写"数据未展示"。

### E5

- 位置：Minimal data set（图像数据）
- 原文："Authors must provide original, uncropped and minimally adjusted images supporting all blot and gel results reported in the article’s figures and Supporting Information files."
- 要点：论文中所有印迹（blot）和凝胶结果，都要提供未裁剪、只做过最低限度调整的原始图像。

### E6

- 位置：Minimal data set
- 原文："The values behind the means, standard deviations and other measures reported; The values used to build graphs"
- 要点：要提交的数据包括：算出平均值、标准差等统计量的原始数值，以及画图用的数值。
