# Thieberger 2019：Recording Audio and keeping track of recordings（PARADISEC 培训讲义）

- 资料：`thieberger2019recording`，PARADISEC 网站上的 PDF 讲义：https://www.paradisec.org.au/blog/wp-content/uploads/2019/08/Honiara-Audio.pdf
- 版本：Nick Thieberger（PARADISEC，墨尔本大学）的幻灯片讲义，2019 年 8 月放在 PARADISEC 网站上（文件名表明用于所罗门群岛霍尼亚拉的一次培训）。这是培训材料，不是档案馆的正式存档规定。位置写幻灯片标题。

### E1

- 位置：幻灯片"Record with NO compression"；"Basics"
- 原文："Do NOT record in mp3 format!" / "Minimally 44.1 kHz, 16bit WAV"
- 要点：不要录成 mp3；最低 44.1 千赫兹、16 位的 WAV。

### E2

- 位置：幻灯片"Set levels"
- 原文："If you can control input levels" / "Do not use automatic limiting" / "Set recording to peak around -12"
- 要点：能调输入电平时，不要用自动限幅，把录音峰值设在 -12 左右。

### E3

- 位置：幻灯片"Machinery"；"Recording"
- 原文："Monitor audio recordings through headphones" / "Avoid background noise if possible" / "Move away from the wind and use a windsock" / "Keep the mic as close to the speaker as possible" / "Use a mic stand"
- 要点：用耳机监听；尽量避开背景噪声；避开风，用防风罩；麦克风尽量靠近说话人；用麦克风支架。

### E4

- 位置：幻灯片"Know your equipment"
- 原文："BEFORE you need to use it!" / "Read the manual" / "Make test recordings"
- 要点：用之前就熟悉设备：读说明书，先试录。
