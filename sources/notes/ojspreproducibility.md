# IEEE Signal Processing Society：Author Instructions for OJSP Reproducibility Review

- 资料：`ojspreproducibility`，[原文](https://signalprocessingsociety.org/publications-resources/ieee-open-journal-signal-processing/author-instructions-ojsp-reproducibility)
- 版本：IEEE 信号处理学会网页，《IEEE 信号处理开放期刊》（IEEE Open Journal of Signal Processing，OJSP）复现性审查的作者说明，2026-10-06 读取。

### E1

- 位置：正文第 1 段
- 原文："Research reproducibility reviewers can access and run the compute capsule on the Code Ocean website to assess the validity of computational results presented in a manuscript, and share their assessment with editorial board members."
- 要点：OJSP 的复现性审稿人会在 Code Ocean 上实际运行作者提交的"计算胶囊"，检查论文里的计算结果，并把评估交给编委。

### E2

- 位置：正文第 1 段
- 原文："OJSP is partnering with Code Ocean for this pilot because of the convenience and flexibility it offers to readers and reviewers"
- 要点：这是 OJSP 的一项试点。

### E3

- 位置：正文，提交时间说明
- 原文："once your article has received an AQR decision indicating that it is accepted for publication subject to passing a reproducibility review."
- 要点：复现性审查发生在论文"有条件录用"之后，条件是通过复现性审查。

### E4

- 位置：FAQ，To what degree is the Code Ocean capsule ... expected to reproduce the results in my paper?
- 原文："The goal of the reproducibility review is to perform a good faith validation of the results. It is not intended to be an adversarial attempt to find unusual conditions under which the code fails."
- 要点：复现性审查是善意地验证结果，不是刻意去找让代码出错的极端条件。

### E5

- 位置：FAQ，Why is OJSP using Code Ocean and not popular code sharing platforms such as GitHub?
- 原文："While source code published on platforms such as GitHub is helpful for researchers, a substantial amount of time and energy is usually required for a researcher to set up such source code to run in one's own computational environment."
- 要点：只把源代码放到 GitHub 上，别人往往要花大量时间配置环境才能跑起来；所以要连同运行环境一起打包。

### E6

- 位置：FAQ，What happens to the Code Ocean module once my OJSP article is published?
- 原文："Upon acceptance and publication of your OJSP article, the Code Ocean module you have submitted for reproducibility review is also made publicly available and assigned a DOI"
- 要点：论文发表后，通过审查的代码胶囊也会公开，并分配 DOI（数字对象标识符，一种永久链接）。
