# Bird & Simons 2002：Seven Dimensions of Portability for Language Documentation and Description

- 资料：`bird2002portability`，[原文](https://arxiv.org/abs/cs/0204020)
- 版本：arXiv 预印本 cs/0204020v1（2002 年 4 月）；修订版 2003 年发表于 Language 79(3)。本摘录依据预印本

### E1

- 位置：§1 Introduction
- 原文："While today's linguists can access documentation that is over 100 years old, much digital language documentation and description is unusable within a decade of its creation."
- 要点：百年前的纸质记录今天还能用，很多数字化的语言记录不到十年就没法用了。

### E2

- 位置：§5.1 Content，ACCOUNTABILITY
- 原文："Provide the full documentation on which language descriptions are based. For example, where a narrative is transcribed, provide the primary recording (without segmenting it into multiple sound clips). Create time-aligned transcriptions to facilitate verification."
- 要点：提供描写所依据的完整记录：转写了一段叙事，就提供完整原始录音（不要切成很多小片段）；做时间对齐的转写，方便核对。

### E3

- 位置：§5.2 Format，OPENNESS
- 原文："Store all language documentation and description in an open format. Prefer formats supported by multiple third-party software tools."
- 要点：所有记录都存成开放格式，优先选多种第三方软件都支持的格式。

### E4

- 位置：§5.2 Format，DOCUMENTATION
- 原文："Encode the characters with Unicode."
- 要点：文字用 Unicode 编码。

### E5

- 位置：§5.2 Format，MACHINE-READABLE
- 原文："Avoid freeform editors for structured information (e.g. prefer Excel or Shoebox over Word for storing lexicons)."
- 要点：结构化信息不要用自由排版的编辑器存，例如词汇表别存在 Word 里。

### E6

- 位置：§5.4 Access，UNIMPEDED
- 原文："Document all access methods and restrictions along with other metadescription."
- 要点：把所有访问方式和限制写进元数据。

### E7

- 位置：§5.7 Rights，DOCUMENTATION
- 原文："Ensure that the intellectual property rights relating to the resource are fully documented."
- 要点：把资料相关的知识产权情况完整记录下来。

### E8

- 位置：§1 Introduction（引用 Himmelmann 1998: 166）
- 原文："The aim of a language documentation is to provide a comprehensive record of the linguistic practices characteristic of a given speech community."
- 要点：Bird 和 Simons 引用 Himmelmann 1998 的定义：语言记录的目标是全面记录一个言语社区特有的语言实践。
