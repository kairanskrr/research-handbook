# Scientific Data：Submission Guidelines（数据描述论文的投稿指南）

- 资料：`scientificdata2026guidelines`，[原文](https://www.nature.com/sdata/submission-guidelines)
- 版本：Scientific Data 期刊投稿指南网页，2026-10-17 读取。
- 说明：Scientific Data 是 Nature 旗下专门发表数据集描述的开放获取期刊，覆盖自然科学、医学、社会科学等多个学科。这里只摘了"数据描述"（Data Descriptor）这种文章类型的要求。

### E1

- 位置：1. Select an article type，Format outline（Data Descriptor）
- 原文："Background & Summary" / "Methods" / "Data Records" / "Data Overview (optional)" / "Technical Validation" / "Usage Notes (optional)" / "Data Availability" / "Code Availability"
- 要点：数据描述论文的主体结构是：背景与概述、方法、数据记录、数据概览（可选）、技术验证、使用说明（可选）、数据可获取性声明、代码可获取性声明。

### E2

- 位置：3. Prepare the manuscript，Background & Summary
- 原文："For Data Descriptors, this section should provide an overview of dataset, including the motivation for creating it, as well as outlining the potential reuse value where applicable." / "Please do not include subjective claims on novelty, impact, or utility."
- 要点：背景部分概述数据集，说明为什么建它、别人可能怎样重用；不要写关于新颖性、影响或用处的主观宣称。

### E3

- 位置：3. Prepare the manuscript，Methods
- 原文："Methods in Data Descriptors should describe the steps or procedures used to create the data, including full descriptions of the experimental design, data acquisition and any computational processing."
- 要点：方法部分要描述产生数据的步骤，包括实验设计、数据采集和所有计算处理的完整说明。

### E4

- 位置：3. Prepare the manuscript，Methods
- 原文："Where continuously updated input data have been used, authors should provide the version number or search terms used to create it at a level of detail that allows others to find the same input and repeat the work."
- 要点：用了持续更新的输入数据时，要给出版本号或检索词，详细到别人能找到同样的输入、重做一遍。

### E5

- 位置：3. Prepare the manuscript，Data Record
- 原文："This section should be used to explain what the dataset contains, including the repository where the dataset is hosted, an overview of the data files and their formats, and any folder structure." / "The section should also define any column headings, variable names, or other fields/metadata if you believe these would not be understood to users"
- 要点：数据记录部分说明数据集包含什么：托管在哪个仓库、有哪些文件和格式、目录结构，并解释用户看不懂的列名和变量名。

### E6

- 位置：3. Prepare the manuscript，Data Overview
- 原文："Data Descriptors should not contain results, discussion, or analyses. This is because the fundamental goal of a Data Descriptor is to describe the technical contents of a dataset to encourage others to use it, without bias."
- 要点：数据描述论文不写结果、讨论和分析，因为它的根本目的是不带偏见地描述数据集的技术内容，鼓励别人使用。

### E7

- 位置：3. Prepare the manuscript，Technical Validation
- 原文："This section should describe the experiments, analyses or checks needed to support the technical quality of the dataset, with any supporting figures and tables, as needed."
- 要点：技术验证部分要描述支持数据集技术质量所需的实验、分析或检查。

### E8

- 位置：2. Deposit the dataset
- 原文："For first round review we require that data are available for download and review by reviewers via any URL that allows anonymous download." / "From the second round of review onwards we require that data are public and available in a formal data repository that meets our policy, in preparation for any final publication."
- 要点：第一轮审稿时数据要能让审稿人匿名下载；从第二轮起，数据必须公开存放在符合期刊政策的正式数据仓库里。

### E9

- 位置：3. Prepare the manuscript，Usage Notes
- 原文："'Usage Notes' is an optional section that can be used to provide information that may assist other researchers who reuse your data. Most commonly these are additional technical notes about how to access or process the data."
- 要点：使用说明是可选部分，给重用数据的人提供帮助，最常见的是怎样获取或处理数据的技术说明。

### E10

- 位置：1. Select an article type，Scope（Data Descriptor）
- 原文："Descriptions of datasets shared in repositories" / "Peer-reviewed?" / "Yes"
- 要点：数据描述论文的范围是：描述存放在数据仓库中的数据集。表中"是否同行评审"一栏写的是"是"。
