# Vasishth & Nicenboim 2016：Statistical methods for linguistic research: Foundational ideas – Part I

- 资料：`vasishth2016statistical`，[原文](https://arxiv.org/abs/1601.01126)
- 版本：Language and Linguistics Compass 10(8)，349–369（2016），DOI 10.1111/lnc3.12201；本文读的是作者放在 arXiv 的预印本 v2（2016-01-07）。是两位作者面向语言学和心理语言学的方法学综述，代表作者的建议，不是学会或期刊规定。

### E1

- 位置：摘要
- 原文："The best way to use frequentist methods is to run appropriately powered studies, check model assumptions, clearly separate exploratory data analysis from confirmatory hypothesis testing, and always attempt to replicate results."
- 要点：用频率学派方法的最好方式：做统计功效足够的研究，检查模型假设，把探索性分析和验证性检验清楚分开，并尽量重复结果。

### E2

- 位置：§3.2 Misconception 2
- 原文："Unless one has sufficient power (see below), the best one can say when we get a p-value larger than 0.05 is that "we failed to find an effect"."
- 要点：除非功效足够，p 值大于 0.05 时最多只能说"没找到效应"，不能说"没有效应"。

### E3

- 位置：§5 Running till significance is reached
- 原文："one should fix one's sample size in advance based on a power analysis, not deploy a stopping rule like the one above"
- 要点：应根据功效分析事先定好样本量，而不是边做边看、显著了就停。

### E4

- 位置：§6
- 原文："there is no harm in doing and reporting exploratory analysis; but these analyses should be clearly marked as such and presented separately from the primary analyses."
- 要点：做探索性分析没问题，但要明确标出，并和主要分析分开呈现。
