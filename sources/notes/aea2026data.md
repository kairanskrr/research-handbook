# AEA：Data and Code Availability Policy

- 资料：`aea2026data`，[原文](https://www.aeaweb.org/journals/data/data-code-policy)；附属政策 [Policy for Papers Conducting Experiments and Collecting Primary Data](https://www.aeaweb.org/journals/data/policy-experimental)
- 版本：2026 年 2 月版（页面注明 "This version (February 2026) supplants all prior data policies"），2026 年 10 月 6 日读取。适用于美国经济学会（AEA）旗下期刊。

### E1

- 位置：开头
- 原文："Prior to acceptance, authors of papers that contain empirical work, simulations, or experimental work must provide the data, code, and other details of the computations sufficient to permit replication. These materials must be made available and retained in an openly accessible trusted data repository, such as the AEA Data and Code Repository."
- 要点：含实证、模拟或实验的论文，在被接收前必须提供足以复现结果的数据、代码和计算细节，并存放在公开可访问的可信数据仓库中。

### E2

- 位置：开头
- 原文："If providing the data publicly is not possible despite the authors' best efforts and due to valid constraints outside the authors' control, authors must (i) commit to preserving data and code for a period of no less than five years following publication of the manuscript, (ii) commit to providing reasonable assistance to requests for clarification and replication, (iii) make the code publicly available, and (iv) publicly document the source of the data, including appropriate contact information."
- 要点：数据确实不能公开时，作者仍须：保存数据和代码至少五年；协助别人的复现请求；公开代码；公开说明数据来源和联系方式。

### E3

- 位置：开头
- 原文："The AEA data editor will assess compliance with this policy, including by conducting reproducibility checks and verifying the accuracy of the information provided, and will assist the authors in achieving compliance."
- 要点：AEA 数据编辑负责检查是否合规，包括做可复现性检查。

### E4

- 位置：Non-Public Data
- 原文："It is generally not acceptable that data be provided "upon request" if the request must be approved by the authors themselves."
- 要点：如果索取数据要经作者本人批准，"可应要求提供"一般不被接受。

### E5

- 位置：Code for Data Transformation and Data Cleaning (DCAS #7)
- 原文："All programs used to generate the analysis data from raw data must be included, even if the raw data cannot be provided."
- 要点：即使原始数据不能提供，从原始数据生成分析数据的全部程序也必须提供。

### E6

- 位置：Computer Code
- 原文："A master script is strongly encouraged."
- 要点：强烈建议提供一个"总脚本"，一键运行全部分析。

### E7

- 位置：Documentation (README) (DCAS #13)
- 原文："Please include a README document in PDF format in the uppermost directory of the replication package." / "Instructions on all the steps needed to run the computer code and reproduce all the results."
- 要点：复现包的顶层要有 PDF 格式的 README，写明运行代码、复现全部结果的所有步骤。

### E8

- 位置：Requirements and Guidelines
- 原文："The American Economic Association endorses DCAS, the Data and Code Availability Standard v1.0 used by multiple journals in economics, and this data and code availability policy is compatible with DCAS."
- 要点：AEA 认可经济学多家期刊使用的数据与代码可得性标准（DCAS）。

### E9

- 位置：Registration of Randomized Controlled Trials (DCAS #12)
- 原文："It is the policy of the AEA that randomized controlled trials must be registered on the RCT Registry."
- 要点：AEA 规定随机对照试验必须在其 RCT 注册平台登记。

### E10

- 位置：附属政策 Policy for Papers Conducting Experiments and Collecting Primary Data，Original Instructions
- 原文："The original instructions for the experiment or survey should be summarized in the submitted manuscript as part of the discussion of the experimental or survey design and should be provided in full as an appendix at the time of submission."
- 要点：做实验或问卷的论文，投稿时就要提交完整的实验说明或问卷原文作为附录。
