# IEEE Author Center：Research Reproducibility

- 资料：`ieeeauthorreproducibility`，[原文](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/research-reproducibility/)
- 版本：IEEE 期刊作者中心网页，2026-10-06 读取。位置写网页小标题。

### E1

- 位置：IEEE Open Research Statement
- 原文："All IEEE authors are encouraged to share their data, code, and other research outputs to facilitate verification and reproducibility of experiments and their conclusions."
- 要点：IEEE 鼓励（不是要求）所有作者共享数据、代码等研究产出，方便别人核实和复现。

### E2

- 位置：Sharing Data
- 原文："Improve the discoverability of your data by hosting it in an easily accessible repository such as figshare, Zenodo, or Dryad."
- 要点：建议把数据放在 figshare、Zenodo、Dryad 等公开数据仓库里。

### E3

- 位置：Uploading Code
- 原文："Help other researchers view and run your code with Code Ocean, a cloud-based computational reproducibility platform that allows code to be stored, shared, and run in the cloud."
- 要点：IEEE 推荐用 Code Ocean（一个云端计算复现平台）存放、共享和在线运行代码。

### E4

- 位置：Uploading Code
- 原文："Authors who have published with IEEE in the past five years can upload their code to Code Ocean and link it to the article published in IEEE Xplore."
- 要点：近五年在 IEEE 发表过论文的作者，可以把代码上传到 Code Ocean，并链接到 IEEE Xplore 上的论文页面。

### E5

- 位置：页脚
- 原文："IEEE is the world's largest technical professional organization dedicated to advancing technology for the benefit of humanity."
- 要点：IEEE 自称是世界上最大的、致力于推动技术造福人类的技术专业组织。
