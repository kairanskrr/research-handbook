# PLOS Computational Biology：Submission Guidelines

- 资料：`ploscompbiolsubmission`，[原文](https://journals.plos.org/ploscompbiol/s/submission-guidelines)
- 版本：《PLOS 计算生物学》（PLOS Computational Biology）期刊官网的投稿指南，2026-10-08 读取。位置写小节标题。

### E1

- 位置：Software Submissions
- 原文："PLOS Computational Biology publishes articles describing an open-source tool of broad utility that represents a significant advance in providing new biological insights either as a part of the software article, or published elsewhere."
- 要点：本刊发表的软件文章，描述的是广泛有用的开源工具，并且它在提供新的生物学认识上带来重大进步。

### E2

- 位置：Software Submissions
- 原文："The software must already be widely adopted, or have the promise of wide adoption by a broad community of users." / "The software must be downloadable anonymously in source code form and licensed under an Open Source Initiative (OSI) compliant license." / "The source code must be accompanied by documentation on building and installing the software from source, as well as for using the software, including instructions on how a user can test the software on supplied test data."
- 要点：软件要已被广泛采用或有望被广泛采用；源代码要能匿名下载，用符合开放源代码促进会定义的许可证；要附上从源码构建、安装和使用的文档，包括怎样用附带的测试数据检验软件。
