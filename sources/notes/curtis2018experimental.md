# Curtis 等人 2018：Experimental design and analysis and their reporting II: updated and simplified guidance for authors and peer reviewers

- 资料：`curtis2018experimental`，[原文（PubMed Central）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5843711/)
- 版本：British Journal of Pharmacology 175(7):987–993，2018 年。《英国药理学杂志》（BJP，英国药理学会主办）资深编辑撰写的期刊作者与审稿指南。位置写小标题。

### E1

- 位置：Abstract
- 原文："This article updates the guidance published in 2015 for authors submitting papers to British Journal of Pharmacology (Curtis et al., 2015) and is intended to provide the rubric for peer review."
- 要点：这是《英国药理学杂志》给投稿作者的指南，更新了 2015 年版，也是审稿时的评判标准。

### E2

- 位置：Key points of the updated guidance
- 原文："BJP has set 5 as the minimum ‘n’ required for datasets subjected to statistical analysis." / "any data set containing groups of n < 5 must not be subjected to statistical analysis, and findings must be labelled as ‘exploratory’ or ‘preliminary’."
- 要点：该刊规定，做统计分析的数据，每组 n 至少为 5；n 小于 5 的组不能做统计检验，结果要标为"探索性"或"初步"。

### E3

- 位置：Key points of the updated guidance
- 原文："We note that it is common for authors to run three samples ‘in quintuplicate’ then analyse the data with statistical analysis as if it were n = 15 rather than n = 3. This is not acceptable for publication in BJP."
- 要点：三份样品各测五次，按 n = 15 做统计，是常见错误；该刊不接受，n 应为 3。

### E4

- 位置：Key points of the updated guidance
- 原文："normalization to matched controls will generate a control mean of 1 and no SEM, meaning that parametric tests (ANOVA, etc.) cannot be used (only non‐parametric analysis is acceptable)." / "Any dataset where one group has no SEM (common in Western blot analysis) must be analysed by non‐parametric statistics."
- 要点：把每个值除以配对对照后，对照组均值恒为 1、没有标准误，这时不能用方差分析等参数检验，只能用非参数检验；这种情况在蛋白质印迹分析中常见。

### E5

- 位置：Key points of the updated guidance
- 原文："a level of probability (P) deemed to constitute the threshold for statistical significance (typically in pharmacology this is P < 0.05) should be defined in Methods and not varied later in Results"
- 要点：显著性阈值要在方法部分事先写明，结果部分不能再换。

### E6

- 位置：Key points of the updated guidance
- 原文："Outliers should therefore be included in data analysis and presentation unless a predefined and defensible set of exclusion criteria can be generated and applied."
- 要点：离群值要保留在分析和展示中，除非有事先定好、说得通的剔除标准。

### E7

- 位置：Areas of particular concern that require renewed vigilance，Table 1 及注释
- 原文："Many papers published in BJP do not adhere to all the journal's guidance" / "The data above summarizes papers in three issues of BJP published at least 6 months after the publication of the journal's original guidance on design and analysis."
- 要点：编辑们审查了 2015 年指南发布至少半年后三期期刊上的全部原创研究论文（表中 26 篇）。各项的符合率：每组 n 都不小于 5 为 73%，各组 n 相等 31%，写了随机化声明 38%，写了盲法声明 35%。这些论文都声称遵守了指南。

### E8

- 位置：Areas of particular concern that require renewed vigilance
- 原文："a lack of randomization and blinding, unequal group sizes, and statistical analysis applied when n is <5. Together, these render a paper fundamentally flawed, and, as Figure 1 indicates, this will now result in triage rejection."
- 要点：没有随机和盲法、各组 n 不等、n 小于 5 还做统计，同时出现时论文有根本缺陷，该刊会在初筛时直接拒稿。

### E9

- 位置：What is a group and what is a group size?
- 原文："To reduce this risk we encourage investigators to acknowledge this and add 50% to the calculated minimum group sizes."
- 要点：功效分析算出的是最小样本量，有假阴性风险；该刊鼓励在此基础上再加 50%。

### E10

- 位置：What is a group and what is a group size?
- 原文："Thus, five cells from one mouse given the same treatment is not n = 5, and these five cells should be regarded as technical replicates, with n = 1 consensus value taken forward into statistical analysis."
- 要点：同一只小鼠的五个细胞不是 n = 5，而是技术重复，进入统计的只是一个值（n = 1）。

### E11

- 位置：Flexibility and pilot data
- 原文："we encourage authors to do so, with the data presented (without P values) in Methods in a sub‐section headed Pilot Study."
- 要点：没随机、没设盲、不适合统计的预实验数据可以放进论文，但要放在方法部分的"预实验"小节，不给 P 值。

### E12

- 位置：Conclusions
- 原文："As we stated previously (Curtis et al. 2015), some of our guidance is arbitrary, and some will change."
- 要点：编辑们自己说，部分规定是人为划定的，有些会改。

### E13

- 位置：Introduction
- 原文："In order to facilitate implementation of the guidelines, journal instructions now require that every paper should contain a data and statistical analysis sub‐section within the Methods and full detail of design within each protocol described."
- 要点：该刊要求每篇论文的方法部分都有"数据与统计分析"小节，每个实验方案都写全设计细节。

### E14

- 位置：Key points of the updated guidance
- 原文："BJP has set 5 as the minimum ‘n’ required for datasets subjected to statistical analysis."
- 要点：该刊规定，做统计分析的数据，每组 n 至少为 5。
