# Geoscientific Model Development：Code and data policy

- 资料：`gmdcodepolicy`，[原文](https://www.geoscientific-model-development.net/policies/code_and_data_policy.html)
- 版本：期刊《地球科学模式开发》（Geoscientific Model Development，GMD，欧洲地球科学联合会旗下的开放获取期刊，由 Copernicus 出版）的代码与数据政策网页，2026-10-06 读取。位置写小标题。

### E1

- 位置：Core principles
- 原文："Every paper must include a section at the end of the paper before the "Acknowledgements" entitled "Code and data availability"."
- 要点：GMD 的每篇论文都要在致谢前设"代码与数据可获取性"一节。

### E2

- 位置：Core principles
- 原文："This section must include citations for the persistent public archives of the precise versions of all of the code and data associated with the paper."
- 要点：这一节要引用论文所用全部代码和数据的**确切版本**，并且存在永久的公开存档里。

### E3

- 位置：Core principles
- 原文："They must also provide confidential access to the code and data for the editor and reviewers in order to enable peer review." / "All manuscripts which do not make code and data available at this level are to be rejected."
- 要点：因不可控原因不能公开的，也必须私下提供给编辑和审稿人；做不到的稿件一律拒稿。

### E4

- 位置：Core principles
- 原文："Code and data access must be provided at the time that the preprint is submitted. Embargoes, whether pending acceptance or for a defined period, are not acceptable."
- 要点：投稿（预印本提交）时就要提供代码和数据；不接受"录用后再公开"或延期公开。

### E5

- 位置：Scope
- 原文："preprocessing, run control and postprocessing scripts covering every data processing action for all the results reported in the paper"
- 要点：要提供的材料包括覆盖每一步数据处理的预处理、运行控制和后处理脚本。

### E6

- 位置：Archive standards
- 原文："Project or institution websites and online revision control sites such as GitHub, GitLab or Bitbucket are made for code development but not suitable for archiving frozen code versions."
- 要点：项目网站和 GitHub 等代码托管平台适合开发，不适合存档冻结的代码版本。

### E7

- 位置：Archive standards
- 原文："Where code and data change during the revision process of the manuscript, the updated versions must also be archived."
- 要点：修改稿期间代码和数据变了，新版本也要存档，并和修改稿的结果对应。

### E8

- 位置：Scope
- 原文："During the review process, the ease of model download, compilation, and running of test cases may be assessed."
- 要点：审稿时可能会检查模型是否容易下载、编译和运行测试算例。

### E9

- 位置：Useful additions from Copernicus Publications' data policy
- 原文："Video supplements, video abstracts, International Geo Sample Numbers, and other digital assets should be linked to the article through DOIs in the assets tab."
- 要点：Copernicus 期刊让作者把样品编号（IGSN）等数字资产通过 DOI 链接到文章的"资产"栏。

### E10

- 位置：Useful additions from Copernicus Publications' data policy
- 原文："With Earth System Science Data (ESSD) Copernicus Publications provides a journal dedicated to the publication of data papers, including peer review of data sets."
- 要点：Copernicus 有专门发表数据论文、并对数据集做同行评审的期刊《地球系统科学数据》（ESSD）。
