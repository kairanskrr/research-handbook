# McLaughlin 等人 2020：The Synthetic Biology Open Language (SBOL) Version 3: Simplified Data Exchange for Bioengineering

- 资料：`mclaughlin2020sbol3`，[原文](https://doi.org/10.3389/fbioe.2020.01009)，PMC7516281
- 版本：Frontiers in Bioengineering and Biotechnology 8:1009，2020 年。开放获取（CC BY 4.0）。作者是标准的开发者。通过 Europe PMC 全文接口读取。位置写章节。

### E1

- 位置：Abstract
- 原文："The Synthetic Biology Open Language (SBOL) is a community-developed data standard that allows knowledge about biological designs to be captured using a machine-tractable, ontology-backed representation that is built using Semantic Web technologies."
- 要点：合成生物学开放语言（SBOL）是社区开发的数据标准，用计算机能处理的方式记录生物设计的信息。

### E2

- 位置：Introduction
- 原文："Since its initial publication in 2011, SBOL has become the recommended format for engineered nucleic acid constructs in ACS Synthetic Biology (Hillson et al., 2016), and is supported by many biological design tools."
- 要点：SBOL 2011 年首次发布后，成为期刊 ACS Synthetic Biology 推荐的工程化核酸构建体描述格式，也被很多生物设计软件支持。
