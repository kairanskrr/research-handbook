# Mineault 2021：The Good Research Code Handbook

- 资料：`mineault2021good`，[Setting up your project](https://goodresearch.dev/setup)、[Document your code](https://goodresearch.dev/docs)
- 版本：作者的在线手册，网页，2026-10-05 读取。位置写页面和小标题。

### E1

- 位置：Setting up your project，Pick a name and create a folder for your project
- 原文："As an academic, a project will tend to naturally map to a paper. Therefore, one project = one paper = one folder = one git repository is a generally a good default structure."
- 要点：在学术研究中，项目通常对应一篇论文；"一个项目 = 一篇论文 = 一个文件夹 = 一个 git 仓库"是好的默认结构。

### E2

- 位置：同上
- 原文："You might want to create extra standalone projects for tools you re-use across different papers."
- 要点：多篇论文共用的工具，可以单独建项目。

### E3

- 位置：Setting up your project，Initialize a git repository and sync to Github
- 原文："Depending on your pace, you should aim to commit your code from a few times a day to a few times per week. Don’t wait until the project is almost finished before you start to commit. [...] The general rule of thumb is that one commit should represent a unit of related work."
- 要点：每天几次到每周几次提交代码，别等项目快结束才开始；一次提交对应一组相关的工作。

### E4

- 位置：Document your code（章首引语，作者引用 Damian Conway）
- 原文："Documentation is a love letter that you write to your future self."
- 要点：文档是写给未来自己的情书。
