# IUPAC FAIR Chemistry Cookbook（化学 FAIR 数据实践手册）

- 资料：`iupacfaircookbook`，[原文](https://iupac.github.io/WFChemCookbook/intro.html)
- 版本：国际纯粹与应用化学联合会（IUPAC）WorldFAIR 化学项目维护的在线手册首页，2026-10-06 读取。默认许可 CC BY-SA 4.0。

### E1

- 位置：Welcome，第 1 段
- 原文："Welcome to the IUPAC FAIR Chemistry Cookbook, a self-serve web-based toolbox of interactive demonstrations of community best practices in machine-readable chemical data management."
- 要点：这是一本自助式的在线工具箱，用可交互的示例演示化学数据怎样以机器可读的方式管理。

### E2

- 位置：Welcome，第 3 段
- 原文："The IUPAC FAIR Chemistry Cookbook is focused on working with chemical data that are findable, accessible, interoperable, and reusable for machine processing"
- 要点：手册关注可查找、可获取、可互操作、可重用（FAIR）、便于机器处理的化学数据。

### E3

- 位置：Welcome，第 3 段
- 原文："Familiarity with techniques for digitally representing chemical structures and other data components will allow researchers to tap into multiple networked resources for searching and analysis, as well as enable their own data to be more discoverable."
- 要点：熟悉用数字方式表示化学结构等数据，既能利用网上资源检索分析，也能让自己的数据更容易被找到。
