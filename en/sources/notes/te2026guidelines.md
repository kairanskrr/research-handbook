# Theoretical Economics: Guidelines for Referees

- Source: `te2026guidelines`, [original](https://www.econometricsociety.org/publications/theoretical-economics/policies/guidelines-for-referees)
- Version: The guidelines for referees web page of Theoretical Economics, a journal of the Econometric Society, viewed October 2026; the page is undated. Represents the requirements of this one journal.

### E1

- Location: The opinion
- Quote: "This section should explain the strengths and weaknesses of the paper. Length should be used as a criterion in the assessment."
- Key point: A referee report should make clear the paper's strengths and weaknesses; length itself is one of the criteria.

### E2

- Location: Substantive comments
- Quote: "You should state if (and how) the paper can be made shorter. Which results should be prioritized, and which should be cut? Can the paper be made more succinct, and the proofs shorter, if the results are less general?"
- Key point: Referees should indicate whether and how the paper can be shortened: which results should be kept as priorities and which dropped, and whether the paper and proofs could be shorter if the results were less general.

### E3

- Location: Substantive comments
- Quote: "The report should suggest only extensions that are essential for the paper at hand."
- Key point: Referees should request only extensions that are essential to the paper.
