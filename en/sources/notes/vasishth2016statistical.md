# Vasishth & Nicenboim 2016: Statistical methods for linguistic research: Foundational ideas – Part I

- Source: `vasishth2016statistical`, [original](https://arxiv.org/abs/1601.01126)
- Version: Language and Linguistics Compass 10(8), 349-369 (2016), DOI 10.1111/lnc3.12201; we read the authors' arXiv preprint v2 (2016-01-07). A methodological review by two authors for linguistics and psycholinguistics; it represents the authors' recommendations, not the rules of a society or journal.

### E1

- Location: Abstract
- Quote: "The best way to use frequentist methods is to run appropriately powered studies, check model assumptions, clearly separate exploratory data analysis from confirmatory hypothesis testing, and always attempt to replicate results."
- Key point: The best way to use frequentist methods: run appropriately powered studies, check model assumptions, clearly separate exploratory data analysis from confirmatory hypothesis testing, and always try to replicate results.

### E2

- Location: §3.2 Misconception 2
- Quote: "Unless one has sufficient power (see below), the best one can say when we get a p-value larger than 0.05 is that "we failed to find an effect"."
- Key point: Unless you have sufficient power, the most you can say when p > 0.05 is "we failed to find an effect," not "there is no effect."

### E3

- Location: §5 Running till significance is reached
- Quote: "one should fix one's sample size in advance based on a power analysis, not deploy a stopping rule like the one above"
- Key point: Fix the sample size in advance based on a power analysis, rather than checking as you go and stopping once the result is significant.

### E4

- Location: §6
- Quote: "there is no harm in doing and reporting exploratory analysis; but these analyses should be clearly marked as such and presented separately from the primary analyses."
- Key point: Doing exploratory analysis is fine, but mark it clearly as such and present it separately from the primary analyses.
