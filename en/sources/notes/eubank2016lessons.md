# Eubank 2016: Lessons from a Decade of Replications at the Quarterly Journal of Political Science

- Source: `eubank2016lessons`, [original PDF (Duke University DukeSpace repository)](https://dukespace.lib.duke.edu/items/319e52d7-0932-4d21-89bb-85df233fbcbd)
- Version: PS: Political Science & Politics 49(2): 273–276, 2016; the repository provides the published PDF. The author was the journal's replication assistant from September 2012 to November 2015. Locations give the subheading.

### E1

- Location: introduction
- Quote: "Since its inception in 2005, the Quarterly Journal of Political Science (QJPS) has sought to encourage this type of transparency by requiring that all submissions be accompanied by a replication package consisting of data and code for generating results."
- Key point: Since its founding in 2005, the Quarterly Journal of Political Science (QJPS) has required all submissions to include the data and code that produce the results.

### E2

- Location: abstract
- Quote: "It finds that of the 24 empirical papers subjected to in-house replication review since September 2012, only four packages did not require any modifications. Most troubling, 14 packages (58%) had results in the paper that differed from those generated by the author's own code."
- Key point: Of the 24 empirical papers given in-house replication review since September 2012, only four replication packages needed no modifications; for 14 (58%), the results in the paper differed from those produced by the authors' own code.

### E3

- Location: In-House Replication
- Quote: "Of the remaining 20 papers, 13 had code that would not execute without errors, eight failed to include code for results that appeared in the paper"
- Key point: Of the remaining 20 papers, 13 had code that would not run without errors, and eight lacked code for some results in the paper.

### E4

- Location: In-House Replication
- Quote: "This process--although it varies by paper--takes approximately six hours of labor and costs roughly $180 per paper"
- Key point: This in-house review takes about six hours and costs roughly $180 per paper.

### E5

- Location: Advice to Authors
- Quote: "Test files on a different computer, preferably with a different operating system."
- Key point: Test replication files on a different computer, preferably with a different operating system.

### E6

- Location: Advice to Authors
- Quote: "The majority of replication problems emerge because authors either modified their code but failed to update their manuscript or made an error while transcribing their results into their paper."
- Key point: Most replication problems arise because authors changed their code without updating the manuscript, or made errors when transcribing results into the paper.

### E7

- Location: Randomizations and Simulations
- Quote: "Set a random-number generator seed in their code so that it consistently generates the exact results in the paper."
- Key point: For analyses that involve randomness, set a random-number seed in the code so it always reproduces the exact results in the paper.
