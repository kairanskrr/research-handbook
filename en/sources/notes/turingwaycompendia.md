# The Turing Way: Research Compendia

- Source: `turingwaycompendia`, [original](https://book.the-turing-way.org/reproducible-research/compendia)
- Version: The Turing Way, an open handbook written by its community (CC-BY 4.0), web page, accessed 2026-10-05. Locations give the subheading.

### E1

- Location: Summary
- Quote: "A research compendium is a collection of all digital parts of a research project including data, code, texts (protocols, reports, questionnaires, meta data)."
- Key point: A research compendium is a collection of all the digital parts of a research project, including data, code, and texts (protocols, reports, questionnaires, metadata).

### E2

- Location: Summary
- Quote: "The main purpose is that all elements of a project are published together, so a basic folder structure combining all components can be sufficient."
- Key point: The main point is to keep all parts of the project together; a basic folder structure that combines the components can be sufficient, with no advanced technology needed.

### E3

- Location: Structure of a Research Compendium
- Quote: "Files should be organized in a conventional folder structure; [...] Data, methods, and output should be clearly separated; [...] The computational environment should be specified."
- Key point: Three principles: use a conventional folder structure; keep data, methods, and output clearly separated; specify the computational environment.

### E4

- Location: Basic Compendium
- Quote: "Furthermore, any compendium should have a landing page in the form of a README document."
- Key point: Every research compendium should have a README as its landing page.
