# Bird & Simons 2002: Seven Dimensions of Portability for Language Documentation and Description

- Source: `bird2002portability`, [original](https://arxiv.org/abs/cs/0204020)
- Version: arXiv preprint cs/0204020v1 (April 2002); a revised version was published in Language 79(3), 2003. This excerpt follows the preprint

### E1

- Location: §1 Introduction
- Quote: "While today's linguists can access documentation that is over 100 years old, much digital language documentation and description is unusable within a decade of its creation."
- Key point: Paper records over 100 years old are still usable today, yet much digital language documentation becomes unusable within a decade.

### E2

- Location: §5.1 Content, ACCOUNTABILITY
- Quote: "Provide the full documentation on which language descriptions are based. For example, where a narrative is transcribed, provide the primary recording (without segmenting it into multiple sound clips). Create time-aligned transcriptions to facilitate verification."
- Key point: Provide the full documentation behind a language description: if you transcribe a narrative, provide the complete primary recording (not split into many sound clips), and make time-aligned transcriptions so others can verify them.

### E3

- Location: §5.2 Format, OPENNESS
- Quote: "Store all language documentation and description in an open format. Prefer formats supported by multiple third-party software tools."
- Key point: Store all documentation in an open format, preferably one supported by several third-party software tools.

### E4

- Location: §5.2 Format, DOCUMENTATION
- Quote: "Encode the characters with Unicode."
- Key point: Encode text in Unicode.

### E5

- Location: §5.2 Format, MACHINE-READABLE
- Quote: "Avoid freeform editors for structured information (e.g. prefer Excel or Shoebox over Word for storing lexicons)."
- Key point: Do not store structured information in freeform editors; for example, do not keep a lexicon in Word.

### E6

- Location: §5.4 Access, UNIMPEDED
- Quote: "Document all access methods and restrictions along with other metadescription."
- Key point: Record all access methods and restrictions in the metadata.

### E7

- Location: §5.7 Rights, DOCUMENTATION
- Quote: "Ensure that the intellectual property rights relating to the resource are fully documented."
- Key point: Fully document the intellectual property rights that apply to the resource.

### E8

- Location: §1 Introduction (quoting Himmelmann 1998: 166)
- Quote: "The aim of a language documentation is to provide a comprehensive record of the linguistic practices characteristic of a given speech community."
- Key point: Bird and Simons quote Himmelmann's 1998 definition: the aim of language documentation is a comprehensive record of the linguistic practices characteristic of a given speech community.
