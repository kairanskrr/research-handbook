# Barba 2018: Terminologies for Reproducible Research

- Source: `barba2018terminologies`, [original](https://arxiv.org/abs/1802.03311)
- Version: arXiv:1802.03311v1, February 2018. Locations give subheadings.

### E1

- Location: Introduction
- Quote: "One big problem keeps coming up among those seeking to tackle the issue: different groups are using terminologies in utter contradiction with each other."
- Key point: In discussions of reproducibility, different groups use terminologies that flatly contradict each other.

### E2

- Location: Introduction
- Quote: "group 1 calls the minimum standard reproduce, while group 2 calls it replicate. This direct swap of the two terms aggravates an already weighty issue."
- Key point: For the minimum standard, "same data and methods give the same results," one group says reproduce and the other says replicate: the two terms are swapped.

### E3

- Location: Terminologies section (explanation of the decision tree); Conclusions, Table 2 (row B1)
- Quote: "B1 corresponds to the Claerbout/Donoho/Peng convention, while B2 agrees with Drummond (2009) and the ACM terminology." / "signal processing scientific computing"
- Key point: Group B1, the Claerbout/Donoho/Peng convention, calls the minimum standard "same data and methods give the same results" reproduce (see E2). Barba's classification table places signal processing in group B1.

### E4

- Location: Conclusions
- Quote: "the recent adoption of an opposing terminology by two large professional groups--ACM and FASEB--make standardization awkward."
- Key point: As of 2018, organizations such as the ACM (Association for Computing Machinery) had adopted the opposite usage, making standardization harder.
