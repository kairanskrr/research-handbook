# PLOS Computational Biology: Submission Guidelines

- Source: `ploscompbiolsubmission`, [original](https://journals.plos.org/ploscompbiol/s/submission-guidelines)
- Version: Submission guidelines on the website of the journal PLOS Computational Biology, read 2026-10-08. Locations give section titles.

### E1

- Location: Software Submissions
- Quote: "PLOS Computational Biology publishes articles describing an open-source tool of broad utility that represents a significant advance in providing new biological insights either as a part of the software article, or published elsewhere."
- Key point: The journal's software articles describe an open-source tool of broad utility that represents a significant advance in providing new biological insights.

### E2

- Location: Software Submissions
- Quote: "The software must already be widely adopted, or have the promise of wide adoption by a broad community of users." / "The software must be downloadable anonymously in source code form and licensed under an Open Source Initiative (OSI) compliant license." / "The source code must be accompanied by documentation on building and installing the software from source, as well as for using the software, including instructions on how a user can test the software on supplied test data."
- Key point: The software must be widely adopted or promise wide adoption; the source code must be downloadable anonymously under a license that meets the Open Source Initiative definition; and there must be documentation for building from source, installing, and using it, including how to test it with the supplied test data.
