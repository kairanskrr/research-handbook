# Wohlin 2014: Guidelines for snowballing in systematic literature studies and a replication in software engineering

- Source: `wohlin2014guidelines`, [original PDF (author's home page)](https://www.wohlin.eu/ease14.pdf)
- Version: EASE 2014 paper.

### E1

- Location: §1
- Quote: "Using the references and the citations respectively is referred to as backward and forward snowballing."
- Key point: Following a paper's reference list back is called backward snowballing; following the papers that cite it forward is called forward snowballing.

### E2

- Location: §3.1 Start Set
- Quote: "A good start set may be identified by using, for example, Google Scholar. It is a good alternative to avoid bias in favour of any specific publisher."
- Key point: The start set can be found with Google Scholar, which avoids bias toward any particular publisher.

### E3

- Location: §3.1 Start Set
- Quote: "If relevant papers may come from different communities, then it is important to have these covered in the start set. This is particularly crucial if there is a risk that relevant papers may be in independent clusters, i.e. in clusters of papers not referring to each other. [...] The start set should cover several different publishers, years and authors. The important issue here is diversity. The start set ought to be formulated from keywords in the research question, while preferably also taking synonyms into account."
- Key point: The start set should be diverse, covering different research communities, publishers, years, and authors; start from the keywords of the research question and consider synonyms. Otherwise you may miss a separate cluster of papers that do not cite each other.

### E4

- Location: §3.2 Iterations
- Quote: "To finally decide to include a paper means that the full paper should be examined before deciding to use it as a paper in the snowballing. If not doing this, a rollback is needed if other papers are included based on a paper that later is excluded."
- Key point: Only after reading a paper in full and deciding to include it should you use it for the next snowballing round; otherwise, if it is later excluded, everything found through it must be rolled back.

### E5

- Location: §3.2.1 Backward Snowballing
- Quote: "The first step is to go through the reference list and exclude papers that do not fulfil the basic criteria such as, for example, language, publication year and type of publication [...]. The next step is to remove papers from the list that have already been examined [...]. If the paper still is a candidate for inclusion after having looked at it in the reference list, then the next step is to examine where and how the paper is referenced."
- Key point: Backward snowballing: first exclude references that fail basic criteria such as language, year, and publication type, then remove ones already examined; for the rest, look at where and in what context they are cited in the paper before deciding whether to read them.

### E6

- Location: §3.3 Authors
- Quote: "Once no new papers are found in the iterations using both backward and forward snowballing, the loop is ended."
- Key point: Stop when neither backward nor forward snowballing finds any new papers.
