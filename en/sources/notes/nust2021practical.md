# Nüst & Pebesma 2021: Practical Reproducibility in Geography and Geosciences

- Source: `nust2021practical`, [author's accepted manuscript (EarthArXiv)](https://eartharxiv.org/repository/object/3216/download/6465/), doi:10.1080/24694452.2020.1806028
- Version: Annals of the American Association of Geographers 111(5), 2021 (published online October 2020). We read the author's accepted manuscript, CC BY 4.0. The authors are at the Institute for Geoinformatics, University of Münster, Germany. Locations give section names.

### E1

- Location: Reproducible workflows > Creating reproducible workflows
- Quote: "A script-based workflow means that a user can execute a full analysis, i.e., starting from raw data up to visualisations for publication, without any manual intervention."
- Key point: A script-based workflow means the full analysis, from raw data to the figures for publication, runs without any manual steps.

### E2

- Location: Reproducible workflows > Creating reproducible workflows
- Quote: "practicing version pinning in the respective configuration files, allow freezing the logical component in a specific state."
- Key point: Pinning package versions in configuration files freezes the software environment in a specific state.

### E3

- Location: Reproducible workflows > Creating reproducible workflows
- Quote: "All parts of an (executable) research compendium must be adequately licensed to allow use and extension (cf. Stodden 2009), and use open formats (Marwick 2015)."
- Key point: Every part of a research compendium should be adequately licensed and use open formats.

### E4

- Location: Examples
- Quote: "They extend earlier collections of cases in geography (Brunsdon 2016), spatial data collection and analysis in ecology (Lewis, Wal, and Fifield 2018), spatial statistics"
- Key point: The authors cite cases from geography, spatial data collection and analysis in ecology, spatial statistics, and the geosciences, showing that these issues cut across fields.

### E5

- Location: Examples
- Quote: "such as setting a seed to avoid problems with non-deterministic results."
- Key point: One practice the authors praise in a reproduced study: setting a random seed to avoid non-deterministic results.

### E6

- Location: Challenges for practical reproducibility in geography and geosciences
- Quote: "They argue that cartography is often considered a design process and an art, but this should not be at the cost of reproducibility, e.g., due to manual tweaking of visual appearances."
- Key point: Cartography is often treated as design and art, but this should not come at the cost of reproducibility, e.g., through manual adjustments to a map's appearance.

### E7

- Location: Challenges for practical reproducibility in geography and geosciences
- Quote: "Online services pose a challenge for reproducibility, because they may change over time or disappear." / "Still, the code to access geoservices, the requests sent as well as the retrieved responses must all be stored"
- Key point: Online geoservices may change or disappear; save the code that accesses them, the requests sent, and the responses received.

### E8

- Location: Challenges for practical reproducibility in geography and geosciences
- Quote: "Prevailing GIS software is GUI based, proprietary, or both. To fix these limitations, either these tools must be updated to provide an executable workflow, i.e., recording a trace of the user interactions (cf. Brunsdon 2016), or researchers need to switch to open tools to achieve a unified toolchain"
- Key point: Mainstream geographic information system (GIS) software is GUI-based, proprietary, or both; either the software must record user actions as an executable workflow, or researchers must switch to open tools.

### E9

- Location: Challenges for practical reproducibility in geography and geosciences
- Quote: "Data collection and creation of visualisations can be reproducible and should be, because maps are commonly used for interaction with study participants during data collection, and for communicating results."
- Key point: Even in qualitative GIS research, data collection and mapping can and should be reproducible, because maps are often used to interact with participants and communicate results.

### E10

- Location: Challenges for practical reproducibility in geography and geosciences
- Quote: "Made-up data prevents de-anonymisation and can be tailored to illustrate the method."
- Key point: Made-up (simulated) data prevent re-identification of individuals while still demonstrating the method.
