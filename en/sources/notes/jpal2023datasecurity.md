# J-PAL research resource: Data security procedures for researchers

- Source: `jpal2023datasecurity`, [original web page](https://www.povertyactionlab.org/resource/data-security-procedures-researchers)
- Version: J-PAL research resource page by Elisabeth O'Toole, Laura Feeney, Kenya Heard, and Rohit Naimpally, updated May 2023; accessed October 2026. Locations give subheadings.

### E1

- Location: Data security overview
- Quote: "Even seemingly de-identified data may be re-identified if enough unique characteristics are included."
- Key point: Even seemingly de-identified data can be re-identified if they contain enough unique characteristics.

### E2

- Location: Minimizing data security threats
- Quote: "Reduce the data security threat-level a priori by acquiring and handling only the minimum amount of sensitive data strictly needed for the research study."
- Key point: Acquire and handle only the minimum sensitive data strictly needed for the study.

### E3

- Location: De-identifying data
- Quote: "Separate Personally Identifiable Information (PII) from all other data as soon as possible"
- Key point: Separate personally identifiable information (PII) from all other data as soon as possible.

### E4

- Location: Data security overview
- Quote: "Researchers should also ensure that their research assistants, students, implementing partners, and data providers have a basic understanding of data security protocols."
- Key point: Research assistants, students, implementing partners, and data providers all need a basic understanding of data security protocols.
