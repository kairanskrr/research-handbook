# AAS Journals: Policy Statement on Software

- Source: `aassoftware`, [original](https://journals.aas.org/policy-statement-on-software/)
- Version: software policy web page of the American Astronomical Society (AAS) journals, accessed 2026-10-06 (the page says it was updated in February 2024).

### E1

- Location: opening
- Quote: "AAS Journals have adopted a policy that reflects the importance of software to the astronomical community, and the need for clear communication about such software which ensures that credit is appropriately given to its authors."
- Key point: The AAS journals' software policy recognizes the importance of software to the astronomical community and aims to ensure that software authors receive proper credit.

### E2

- Location: Guidelines for citation of software
- Quote: "Ideally, both forms of citation should be included. The former extends credit to the authors for their publication and tells the reader where to learn about the software. The latter gives the reader access to the exact version of the software used in the project."
- Key point: Ideally, cite software both ways: cite the paper describing the software (to credit the authors and tell readers where to learn about it), and cite the software's own DOI (so readers can get the exact version you used).

### E3

- Location: Guidelines for software articles
- Quote: "We highly recommend that authors release code described in an article under an appropriate open source license"
- Key point: Authors are highly recommended to release code described in an article under an appropriate open source license and archive it with a DOI.

### E4

- Location: Guidelines for software articles
- Quote: "Such articles need not include research results produced using the software"
- Key point: AAS journals accept articles devoted to describing software, which need not include research results produced with it.

### E5

- Location: Review of Software
- Quote: "The AAS journals do not ask referees to directly review the software described in papers published in our journals."
- Key point: AAS journals do not ask referees to directly review the software described in papers.
