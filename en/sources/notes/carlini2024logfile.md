### E1

- Location: Opening paragraph
- Quote: "I maintain a single file called ideas.txt, where I just append a new entry every time I think of something that might be an interesting topic for a paper."
- Key point: The author keeps a single ideas file and appends an entry whenever he thinks of something that might become a paper.

### E2

- Location: A bit more detail
- Quote: "And when I'm in the middle of working on one project, if I think of something that's really exciting, I can just write it down and get back to the task at hand."
- Key point: When a new idea comes up mid-project, write it down and get back to the task at hand, so the new idea does not pull you off course.

### E3

- Location: A bit more detail
- Quote: "This filtering of ideas is useful because it means I've thought the idea was good at least twice: once when I wrote it down, and once when I read it."
- Key point: Rereading the ideas file later gives a more objective filter: an idea is worth pursuing only if it seemed good both when written down and when reread.
