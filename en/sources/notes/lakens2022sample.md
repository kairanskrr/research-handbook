# Lakens 2022: Sample Size Justification

- Source: `lakens2022sample`, [PDF (PsyArXiv preprint)](https://osf.io/preprints/psyarxiv/9d3yf/)
- Version: PsyArXiv preprint; the published version appeared in Collabra: Psychology 8(1):33267. Locations give the subheading.

### E1

- Location: Abstract
- Quote: "six approaches are discussed to justify the sample size in a quantitative empirical study: 1) collecting data from (almost) the entire population, 2) choosing a sample size based on resource constraints, 3) performing an a-priori power analysis, 4) planning for a desired accuracy, 5) using heuristics, or 6) explicitly acknowledging the absence of a justification."
- Key point: Six ways to justify sample size: collect data from (almost) the entire population, base it on resource constraints, run an a-priori power analysis, plan for a desired accuracy of the estimate, use heuristics, or explicitly acknowledge that there is no justification.

### E2

- Location: A-priori Power Analysis
- Quote: "Given a specified effect size, alpha level, and power, an a-priori power analysis can be used to calculate the number of observations required to achieve the desired error rates, given the effect size."
- Key point: An a-priori power analysis takes a specified effect size, alpha level, and desired power, and calculates the number of observations required.

### E3

- Location: A-priori Power Analysis
- Quote: "an a-priori power analysis is useful, as long as a researcher can justify the effect sizes they are interested in."
- Key point: A power analysis is useful only as long as you can justify the effect size you chose.

### E4

- Location: What is the Expected Effect Size? (estimating effect sizes from existing studies)
- Quote: "a pilot study does not provide a meaningful effect size estimate for planning subsequent studies due to the imprecision inherent in data from small samples."
- Key point: Lakens quotes Leon et al.: a small pilot study does not give an effect size estimate precise enough for planning the sample size of a subsequent study.

### E5

- Location: What is the Expected Effect Size?
- Quote: "effect size estimates from studies can differ from the true population effect size due to random variation, and that publication bias inflates effect sizes."
- Key point: Be careful when taking effect sizes from published studies: they vary randomly, and publication bias (significant results are easier to publish) inflates them.

### E6

- Location: A-priori Power Analysis
- Quote: "the default recommendation to aim for 80% power lacks a solid justification."
- Key point: Aiming for "80% power" is only a convention that lacks a solid justification; error rates should be justified for the specific situation.

### E7

- Location: Resource Constraints
- Quote: "Because resource limitations always play a role, a responsible scientist carefully evaluates resource constraints when designing a study."
- Key point: Resources are always limited; a responsible scientist carefully evaluates resource constraints when designing a study.
