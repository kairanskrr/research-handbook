# IGSN e.V.: Glossary

- Source: `igsnglossary`, [original](https://ev.igsn.org/glossary)
- Version: The "Glossary" page on the website of IGSN e.V. (the nonprofit organization that manages the International Generic Sample Number), read on 2026-10-10. Locations give the entry name.

### E1

- Location: Allocating Agent entry
- Quote: "An IGSN Agent is an institution that registers IGSN IDs."
- Key point: An IGSN Agent is an institution that registers IGSN IDs.

### E2

- Location: Registration Agency entry
- Quote: "IGSN registrations are sent to DataCite as the Registration Agency by the IGSN Agents ." / "Individual users should refer to IGSN Agents for registration of their samples."
- Key point: IGSN Agents send registrations to DataCite, the Registration Agency; individual users register their samples through an IGSN Agent.
