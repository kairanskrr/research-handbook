# Wallach et al. 2023: Proposal and extensive test of a calibration protocol for crop phenology models

- Source: `wallach2023proposal`, [original (publisher, open access)](https://link.springer.com/article/10.1007/s13593-023-00900-0), DOI [10.1007/s13593-023-00900-0](https://doi.org/10.1007/s13593-023-00900-0)
- Version: Agronomy for Sustainable Development 43:46, 2023, open access (CC BY 4.0), read on 2026-10-08 from the PDF in Agritrop, the institutional repository of the French agricultural research center CIRAD. The study was carried out within the Agricultural Model Intercomparison and Improvement Project (AgMIP), with 19 modeling teams, and concerns wheat phenology models (models that predict crop development stages). Locations give the section or the abstract.

### E1

- Location: Abstract
- Quote: "calibration of crop phenology models is difficult and there is no consensus on the best approach."
- Key point: Calibrating crop phenology models is difficult, and there is no consensus on the best approach.

### E2

- Location: §1 Introduction
- Quote: "Calibration normally only concerns a fairly small subset of the parameters in a crop model, but is essentially always necessary because mechanistic models are only approximations, without universally valid parameter values"
- Key point: Calibration usually concerns only a small subset of a crop model's parameters, but it is essentially always necessary, because mechanistic models are only approximations without universally valid parameter values.

### E3

- Location: §2.1 Data sets; §2.3
- Quote: "For both data sets, the calibration and evaluation subsets had neither site nor year in common, so the evaluation is a rigorous test of how well a modeling team can simulate phenology for out-of-sample environments." / "At no time were the evaluation data shown to participants, neither in previous studies nor in the present study."
- Key point: The calibration and evaluation data share neither site nor year, so the evaluation is a rigorous test of how well a model predicts phenology for new environments; the evaluation data were never shown to participants.

### E4

- Location: §1 Introduction
- Quote: "A second major innovation of the protocol is the definition of documentation tables for each step of the calibration procedure, which can be used both for communication within a modeling team and to inform users of the calibrated model."
- Key point: The calibration protocol defines documentation tables for each step, used both for communication within a modeling team and to tell model users how the calibration was done.

### E5

- Location: §1 Introduction
- Quote: "It has been found, for example, that there is a wide diversity of calibration approaches between modeling teams furnished with identical data, even between modeling teams using the same model structure"
- Key point: Earlier studies found that modeling teams given identical data calibrate in very different ways, even when they use the same model structure.

### E6

- Location: §3.3, Table 8 caption; §3.3 main text
- Quote: "showing root mean squared error (RMSE) for the calibrated model and for two benchmark models" / "Almost all modeling teams did better than the two benchmark models for all stages, both for usual calibration and protocol calibration"
- Key point: Evaluation compares the calibrated model's root mean squared error (RMSE) with that of two simple benchmark models; almost all teams beat the benchmark models for all development stages.

### E7

- Location: §1 Introduction
- Quote: "There are therefore two main tracks to improvement of crop phenology model predictions. The first is through improvement of model structure through improved understanding of the underlying processes, and the second is through improvement of model calibration"
- Key point: There are two main tracks for improving crop phenology predictions: improving model structure through better understanding of the underlying processes, and improving model calibration.
