# APS Journals: Guidelines for Data Availability Statements in Physical Review

- Source: `apsdataavailability`, [original](https://journals.aps.org/authors/data-availability-statements)
- Version: APS journals author guidelines page, read 2026-10-06. APS announced the policy in 2024, first applying it to journals such as Physical Review D, then extending it to all Physical Review journals.

### E1

- Location: Overview of Policies
- Quote: "Statement required: All published articles must include a Data Availability Statement (DAS)."
- Key point: All published articles must include a Data Availability Statement.

### E2

- Location: Overview of Policies
- Quote: "Authors are strongly encouraged to share data and software publicly and according to FAIR (Findable, Accessible, Interoperable, Reusable) principles at publication."
- Key point: Authors are strongly encouraged to share data and software publicly at publication, following the FAIR principles (Findable, Accessible, Interoperable, Reusable).

### E3

- Location: Overview of Policies
- Quote: "Publicly shared data and software must be cited in the reference list, and the citation must be included in the data availability statement."
- Key point: Publicly shared data and software must be cited in the reference list, and that citation must appear in the statement.

### E4

- Location: Overview of Policies
- Quote: "If data can’t be made public, authors must agree to share data privately with editors, reviewers, and readers upon reasonable request."
- Key point: If data cannot be made public, authors must agree to share them privately with editors, reviewers, and readers on reasonable request.

### E5

- Location: What Qualifies as Research Data?
- Quote: "Research data and software includes any factual material necessary to verify or replicate study results"
- Key point: Research data and software include any factual material needed to verify or replicate the results, including code the authors wrote themselves.

### E6

- Location: Examples of Data Availability Statements, Software is publicly available
- Quote: "The data that support the findings of this study were generated by numerical simulations. The source code and parameters used to generate the simulations is publicly available"
- Key point: Sample statement for a numerical-simulation paper: the data were generated by simulations, and the source code and parameters used are publicly available.
