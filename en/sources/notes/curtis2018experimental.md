# Curtis et al. 2018: Experimental design and analysis and their reporting II: updated and simplified guidance for authors and peer reviewers

- Source: `curtis2018experimental`, [Original (PubMed Central)](https://pmc.ncbi.nlm.nih.gov/articles/PMC5843711/)
- Version: British Journal of Pharmacology 175(7):987–993, 2018. Guidance for authors and reviewers written by senior editors of the British Journal of Pharmacology (BJP, published by the British Pharmacological Society). Locations give subheadings.

### E1

- Location: Abstract
- Quote: "This article updates the guidance published in 2015 for authors submitting papers to British Journal of Pharmacology (Curtis et al., 2015) and is intended to provide the rubric for peer review."
- Key point: This is BJP's guidance for authors, updating the 2015 version, and it is also the rubric for peer review.

### E2

- Location: Key points of the updated guidance
- Quote: "BJP has set 5 as the minimum ‘n’ required for datasets subjected to statistical analysis." / "any data set containing groups of n < 5 must not be subjected to statistical analysis, and findings must be labelled as ‘exploratory’ or ‘preliminary’."
- Key point: The journal sets n = 5 per group as the minimum for statistical analysis; groups with n < 5 must not be tested statistically, and the findings must be labeled "exploratory" or "preliminary."

### E3

- Location: Key points of the updated guidance
- Quote: "We note that it is common for authors to run three samples ‘in quintuplicate’ then analyse the data with statistical analysis as if it were n = 15 rather than n = 3. This is not acceptable for publication in BJP."
- Key point: Running three samples in quintuplicate and analyzing them as n = 15 is a common error; the journal does not accept this, and n should be 3.

### E4

- Location: Key points of the updated guidance
- Quote: "normalization to matched controls will generate a control mean of 1 and no SEM, meaning that parametric tests (ANOVA, etc.) cannot be used (only non‐parametric analysis is acceptable)." / "Any dataset where one group has no SEM (common in Western blot analysis) must be analysed by non‐parametric statistics."
- Key point: Normalizing each value to a matched control gives a control mean of exactly 1 with no SEM, so parametric tests such as ANOVA cannot be used, only non-parametric ones; this situation is common in Western blot analysis.

### E5

- Location: Key points of the updated guidance
- Quote: "a level of probability (P) deemed to constitute the threshold for statistical significance (typically in pharmacology this is P < 0.05) should be defined in Methods and not varied later in Results"
- Key point: The significance threshold must be defined in advance in the Methods and not changed in the Results.

### E6

- Location: Key points of the updated guidance
- Quote: "Outliers should therefore be included in data analysis and presentation unless a predefined and defensible set of exclusion criteria can be generated and applied."
- Key point: Keep outliers in the analysis and presentation unless a predefined, defensible set of exclusion criteria exists.

### E7

- Location: Areas of particular concern that require renewed vigilance, Table 1 and notes
- Quote: "Many papers published in BJP do not adhere to all the journal's guidance" / "The data above summarizes papers in three issues of BJP published at least 6 months after the publication of the journal's original guidance on design and analysis."
- Key point: The editors checked all original research papers in three issues published at least six months after the 2015 guidance (26 papers in the table). Compliance rates: n ≥ 5 in every group 73%, equal n across groups 31%, a randomization statement 38%, a blinding statement 35%. All these papers claimed to follow the guidance.

### E8

- Location: Areas of particular concern that require renewed vigilance
- Quote: "a lack of randomization and blinding, unequal group sizes, and statistical analysis applied when n is <5. Together, these render a paper fundamentally flawed, and, as Figure 1 indicates, this will now result in triage rejection."
- Key point: When lack of randomization and blinding, unequal group sizes, and statistics on n < 5 occur together, the paper is fundamentally flawed and the journal rejects it at triage.

### E9

- Location: What is a group and what is a group size?
- Quote: "To reduce this risk we encourage investigators to acknowledge this and add 50% to the calculated minimum group sizes."
- Key point: A power analysis gives the minimum sample size and carries a risk of false negatives; the journal encourages adding 50% to it.

### E10

- Location: What is a group and what is a group size?
- Quote: "Thus, five cells from one mouse given the same treatment is not n = 5, and these five cells should be regarded as technical replicates, with n = 1 consensus value taken forward into statistical analysis."
- Key point: Five cells from one mouse are not n = 5 but technical replicates; only one value (n = 1) goes into the statistical analysis.

### E11

- Location: Flexibility and pilot data
- Quote: "we encourage authors to do so, with the data presented (without P values) in Methods in a sub‐section headed Pilot Study."
- Key point: Pilot data without randomization or blinding, unsuitable for statistics, can go in the paper, but in a "Pilot Study" subsection of the Methods and without P values.

### E12

- Location: Conclusions
- Quote: "As we stated previously (Curtis et al. 2015), some of our guidance is arbitrary, and some will change."
- Key point: The editors themselves say that some of the rules are arbitrary and some will change.

### E13

- Location: Introduction
- Quote: "In order to facilitate implementation of the guidelines, journal instructions now require that every paper should contain a data and statistical analysis sub‐section within the Methods and full detail of design within each protocol described."
- Key point: The journal requires every paper to have a data and statistical analysis subsection in the Methods and full design details for every experimental protocol.

### E14

- Location: Key points of the updated guidance
- Quote: "BJP has set 5 as the minimum ‘n’ required for datasets subjected to statistical analysis."
- Key point: The journal sets n = 5 per group as the minimum for statistical analysis.
