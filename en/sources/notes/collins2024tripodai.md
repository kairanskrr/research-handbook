# Collins et al. 2024: TRIPOD+AI statement: updated guidance for reporting clinical prediction models that use regression or machine learning methods

- Source: `collins2024tripodai`, [Original (BMJ, open access)](https://doi.org/10.1136/bmj-2023-078378); we read the full text on Europe PMC (PMC11019967)
- Version: BMJ 2024;385:e078378, open access under CC BY 4.0. Locations give the section or table.

### E1

- Location: Summary points
- Quote: "The TRIPOD+AI statement consists of a 27 item checklist, an expanded checklist that details reporting recommendations for each item, and a TRIPOD+AI for Abstracts checklist containing 13 items"
- Key point: TRIPOD+AI consists of a 27-item checklist, an expanded checklist explaining each item, and a 13-item checklist for abstracts.

### E2

- Location: Abstract
- Quote: "TRIPOD+AI provides harmonised guidance for reporting prediction model studies, irrespective of whether regression modelling or machine learning methods have been used."
- Key point: TRIPOD+AI can be used to report studies that develop or evaluate prediction models, whether they use regression or machine learning methods.

### E3

- Location: Table 1 Reporting guidelines for healthcare studies using machine learning
- Quote: "Medical imaging studies using artificial intelligence" / "Early stage clinical evaluation (including safety, human factors evaluation) of decision support systems driven by artificial intelligence" / "Clinical trial reports evaluating an intervention with an artificial intelligence component"
- Key point: Table 1 lists reporting guidelines for health research that uses machine learning, for example CLAIM for medical imaging studies using artificial intelligence, DECIDE-AI for early-stage clinical evaluation of AI-driven decision support systems (including safety and human factors evaluation), and CONSORT-AI for reporting clinical trials with an AI component.

### E4

- Location: Development of TRIPOD+AI, paragraph 1
- Quote: "There is no such thing as a validated prediction model. To avoid ambiguity and harmonise terminology, we refer to validation as evaluation in this article"
- Key point: The authors hold that there is no such thing as a validated prediction model; to avoid ambiguity, the article calls validation "evaluation."

### E5

- Location: Box 1 Glossary, Evaluation or test data
- Quote: "Evaluation data should be distinct from the data used to train the model, tune hyperparameters, or do model selection, such that there is no overlap in participants between the training and evaluation data."
- Key point: Evaluation data must be distinct from the data used to train the model, tune hyperparameters, or select the model, with no participant appearing in both.

### E6

- Location: Box 1 Glossary, footnote
- Quote: "Validation data often has different meanings. For example, in machine learning studies, validation data can refer to data used for parameter tuning or data used to evaluate model performance"
- Key point: "Validation data" means different things: in machine learning studies it can mean data used for tuning parameters or data used to evaluate model performance.

### E7

- Location: Discussion, open science section
- Quote: "TRIPOD+AI prominently features open science practices."
- Key point: TRIPOD+AI prominently features open science practices (the checklist has items on protocols, registration, data sharing, and code sharing).
