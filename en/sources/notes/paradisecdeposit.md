# PARADISEC: Deposit pages (archiving guide)

- Source: `paradisecdeposit`, [original](https://www.paradisec.org.au/deposit/)
- Version: Several pages under the Deposit section of the website of the Pacific And Regional Archive for Digital Sources in Endangered Cultures (PARADISEC, Australia), read October 2026

### E1

- Location: Deposit page
- Quote: "Depositors can specify conditions on the access and use of their data, and only registered users can access primary records."
- Key point: Depositors can set conditions on access to and use of their data; only registered users can access primary records.

### E2

- Location: Deposit page
- Quote: "Please reduce the number of files to only those that are necessary, for example, not having multiple video or audio files of the same event, or multiple files that contain the same information."
- Key point: Deposit only the files you need: no multiple recordings of the same event and no files that duplicate the same information.

### E3

- Location: Deposit page, Fieldworkers need to make a Will
- Quote: "it is important that you include a section in your Will, that is your last Will and Testament, that expresses your wishes with respect to your field recordings and associated material."
- Key point: Fieldworkers should state in their will how their field recordings and associated material are to be handled.

### E4

- Location: Catalog Structure & File Naming page
- Quote: "Related files can share the same base name. For example, an .eaf transcription file would share the same name as its corresponding audio or video file, and both would sit inside the same item."
- Key point: Related files share the same base name, e.g., a transcription file has the same name as its audio or video file, and both sit in the same item.

### E5

- Location: Catalog Structure & File Naming page
- Quote: "Hyphens are reserved for separating collection, item, and file identifiers, so do not use hyphens or spaces within any individual component of a name."
- Key point: Hyphens are reserved for separating collection, item, and file identifiers; do not use hyphens or spaces within any part of a name.

### E6

- Location: File formats page
- Quote: ".WAV (as close to the archival standard of 24bit, 96kHz as possible)"
- Key point: Deposit audio as WAV, as close as possible to the archival standard of 24-bit, 96 kHz.

### E7

- Location: File formats page
- Quote: "mkv (archival master) & mp4 (access copy)"
- Key point: Deposit video as mkv for the archival master and mp4 for the access copy.

### E8

- Location: File formats page
- Quote: "Fieldworks (FLEx) files need to be exported to xml (one for the lexicon and one for the text)."
- Key point: Files from FLEx (FieldWorks Language Explorer, widely used software for dictionaries and text annotation) must be exported to XML.

### E9

- Location: Metadata page
- Quote: "This metadata includes a subset that conforms to the Open Languages Archives Community and Dublin Core Metadata sets (global standards in metadata terminology)."
- Key point: Part of PARADISEC's metadata conforms to the Open Language Archives Community (OLAC) and Dublin Core metadata sets, two global metadata standards.

### E10

- Location: Metadata page, field list
- Quote: "Access conditions specific to this item"
- Key point: The metadata has a "rights" field for access conditions specific to the item.

### E11

- Location: Metadata page, field list (Role)
- Quote: "annotator / artist / author / compiler / consultant / data_inputter / depositor / developer / editor / illustrator / interviewer / participant / performer / photographer / recorder / researcher / respondent / speaker / signer / singer / sponsor / transcriber / translator"
- Key point: The metadata gives each participant a role, such as annotator, consultant, recorder, speaker, transcriber, or translator.

### E12

- Location: Do you own your records? page
- Quote: "If you work at a university, or have received grants to do research, then you may not be able to archive your records without obtaining a release form from your funders or employers."
- Key point: If you work at a university or have research grants, you may need a release from your funders or employer before you can archive your records (the page describes the Australian situation).

### E13

- Location: Do you own your records? page
- Quote: "As an author you may agree to assign your copyright in cultural recordings to the individuals / communities with which you are working."
- Key point: Authors may agree to assign their copyright in cultural recordings to the individuals or communities they work with.

### E14

- Location: Access Conditions page
- Quote: "To acknowledge in any work, published or unpublished, based in whole or in part on analyses of the data, both the original depositors of the data and PARADISEC (by use of the PARADISEC persistent identifier and citation form)."
- Key point: In any work based on the data, users must acknowledge both the original depositors and PARADISEC, using the persistent identifier and citation format.
