# ACM 2020: Artifact Review and Badging (Version 1.1)

- Source: `acm2020artifact`, [original](https://www.acm.org/publications/policies/artifact-review-and-badging-current)
- Version: v1.1, 2020-08-24. The ACM website refuses scripted access, so the text is taken from the Internet Archive snapshot `https://web.archive.org/web/20260102131040/https://www.acm.org/publications/policies/artifact-review-and-badging-current`.

### E1

- Location: opening
- Quote: "By "artifact" we mean a digital object that was either created by the authors to be used as part of the study or generated by the experiment itself. For example, artifacts can be software systems, scripts used to run experiments, input datasets, raw data collected in the experiment, or scripts used to analyze results."
- Key point: An artifact is a digital object either created by the authors for the study or generated by the experiment, such as a software system, scripts used to run experiments, input data, raw data collected in the experiment, or analysis scripts.

### E2

- Location: Artifacts Evaluated – Functional v1.1
- Quote: "The artifacts associated with the research are found to be documented, consistent, complete, exercisable, and include appropriate evidence of verification and validation."
- Key point: The "Artifacts Evaluated – Functional" level requires artifacts to be documented, consistent with the paper, complete, and exercisable, and to include appropriate evidence of verification.

### E3

- Location: Artifacts Evaluated – Reusable v1.1
- Quote: "they are very carefully documented and well-structured to the extent that reuse and repurposing is facilitated"
- Key point: The "Artifacts Evaluated – Reusable" level goes beyond Functional: the artifacts must be very carefully documented and well-structured so that reuse and repurposing are facilitated.

### E4

- Location: Artifacts Available v1.1
- Quote: "Author-created artifacts relevant to this paper have been placed on a publically accessible archival repository. A DOI or link to this repository along with a unique identifier for the object is provided." / "Personal web pages are not acceptable for this purpose."
- Key point: The "Artifacts Available" level requires placing the artifacts in a publicly accessible archival repository and providing a DOI or a link with a unique identifier; personal web pages do not count.

### E5

- Location: Results Validated
- Quote: "The main results of the paper have been obtained in a subsequent study by a person or team other than the authors, using, in part, artifacts provided by the author." / "The main results of the paper have been independently obtained in a subsequent study by a person or team other than the authors, without the use of author-supplied artifacts."
- Key point: "Results Reproduced" means others obtained the main results using the authors' artifacts; "Results Replicated" means others obtained the main results independently, without the authors' artifacts.

### E6

- Location: Artifacts Evaluated – Functional, Notes (Complete)
- Quote: "Proprietary artifacts need not be included. If they are required to exercise the package then this should be documented, along with instructions on how to obtain them."
- Key point: Proprietary components need not be included, but if they are required to run the package, this must be documented along with instructions on how to obtain them.

### E7

- Location: Artifacts Evaluated
- Quote: "Artifacts need not be made publicly available to be considered for this badge. However, they do need to be made available to reviewers."
- Key point: Artifacts need not be made public to be considered for an "Artifacts Evaluated" badge, but they must be made available to reviewers.

### E8

- Location: opening
- Quote: "well-formed and documented artifacts allow others to build directly upon the previous work through reuse and repurposing."
- Key point: Well-formed, documented artifacts let others build directly on your work.

### E9

- Location: opening
- Quote: "An experimental result is not fully established unless it can be independently reproduced."
- Key point: An experimental result is not fully established unless it can be independently reproduced.

### E10

- Location: opening
- Quote: "such review processes are encouraged, but remain completely optional for ACM journals and conferences, and when they are made available, it is recommended that participation by authors also be made optional."
- Key point: Artifact review is encouraged but entirely optional for conferences, journals, and authors.

### E11

- Location: Badging
- Quote: "We recommend that three separate badges related to artifact review be associated with research articles in ACM publications: Artifacts Evaluated, Artifacts Available and Results Validated."
- Key point: There are three separate badges: Artifacts Evaluated, Artifacts Available, and Results Validated.

### E12

- Location: Artifacts Evaluated – Reusable v1.1
- Quote: "very carefully documented and well-structured to the extent that reuse and repurposing is facilitated."
- Key point: The "Reusable" level: documentation and structure good enough that others can directly reuse and repurpose the artifacts.

### E13

- Location: Artifacts Available v1.1
- Quote: "Author-created artifacts relevant to this paper have been placed on a publically accessible archival repository. [...] Personal web pages are not acceptable for this purpose."
- Key point: "Available": placed in a publicly accessible archival repository with a DOI or link; personal web pages do not count.

### E14

- Location: Results Validated
- Quote: "exact replication or reproduction of results is not required, or even expected. Instead, the results must be in agreement to within a tolerance deemed acceptable for experiments of the given type."
- Key point: "Results Validated" does not require exactly matching numbers, only agreement within the tolerance acceptable for that kind of experiment, without changing the main conclusions.

### E15

- Location: Results Validated
- Quote: "In particular, differences in the results should not change the main claims made in the paper."
- Key point: Differences in the results should not change the main claims made in the paper.

### E16

- Location: Terminology, Repeatability
- Quote: "Repeatability (Same team, same experimental setup)" / "For computational experiments, this means that a researcher can reliably repeat her own computation."
- Key point: Repeatability: same team, same experimental setup; for computational experiments, a researcher can reliably repeat her own computation.

### E17

- Location: Terminology, Reproducibility
- Quote: "Reproducibility (Different team, same experimental setup)" / "For computational experiments, this means that an independent group can obtain the same result using the author’s own artifacts."
- Key point: Reproducibility: different team, same experimental setup; for computational experiments, an independent group can obtain the same result using the original authors' artifacts.

### E18

- Location: Terminology, Replicability
- Quote: "Replicability (Different team, different experimental setup)" / "For computational experiments, this means that an independent group can obtain the same result using artifacts which they develop completely independently."
- Key point: Replicability: different team, different experimental setup; for computational experiments, an independent group can obtain the same result using artifacts they developed completely independently.

### E19

- Location: Terminology, asterisked note
- Quote: "ACM agreed with NISO’s recommendation to swap the terms “reproducibility” and “replication” with the existing definitions used by ACM as part of its artifact review and badging initiative. ACM took action to update all prior badging to ensure consistency."
- Key point: Following a recommendation from the National Information Standards Organization (NISO), ACM swapped the meanings of "reproducibility" and "replication" to align with the broader scientific community, and updated all earlier badges. Older literature may use the pre-swap terms.
