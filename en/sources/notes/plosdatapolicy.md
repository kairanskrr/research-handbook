# PLOS: Data Availability

- Source: `plosdatapolicy`, [original](https://journals.plos.org/plosone/s/data-availability)
- Version: Data policy web page for the PLOS journals, applying to all PLOS journals, read 2026-10-06. This is one publisher's policy, used as an example of journal data requirements. Locations give subheadings.

### E1

- Location: Introduction
- Quote: "PLOS journals require authors to make all data necessary to replicate their study’s findings publicly available without restriction at the time of publication."
- Key point: PLOS requires authors to make all data needed to replicate their findings publicly available, without restriction, at publication.

### E2

- Location: Acceptable data sharing methods (repositories)
- Quote: "If field-specific standards for data deposition exist, PLOS requires authors to comply with these standards. Authors should select repositories appropriate to their field of study (for example, ArrayExpress or GEO for microarray data; GenBank, EMBL, or DDBJ for gene sequences)."
- Key point: Where field-specific data deposition standards exist, you must follow them; choose a repository suited to your field, e.g., ArrayExpress or GEO for microarray data, and GenBank, EMBL, or DDBJ for gene sequences.

### E3

- Location: Acceptable data sharing methods (repositories)
- Quote: "The Data Availability Statement must list the name of the repository or repositories as well as digital object identifiers (DOIs), accession numbers or codes, or other persistent identifiers for all relevant data."
- Key point: The Data Availability Statement must name the repository and give DOIs, accession numbers, or other persistent identifiers for all relevant data.

### E4

- Location: Minimal data set
- Quote: "PLOS does not permit references to “data not shown.”"
- Key point: PLOS does not permit references to "data not shown."

### E5

- Location: Minimal data set (image data)
- Quote: "Authors must provide original, uncropped and minimally adjusted images supporting all blot and gel results reported in the article’s figures and Supporting Information files."
- Key point: For all blot and gel results in the paper, provide the original, uncropped, minimally adjusted images.

### E6

- Location: Minimal data set
- Quote: "The values behind the means, standard deviations and other measures reported; The values used to build graphs"
- Key point: The data to submit include the values behind reported means, standard deviations, and other statistics, and the values used to build graphs.
