# IEEE Signal Processing Society: Author Instructions for OJSP Reproducibility Review

- Source: `ojspreproducibility`, [original](https://signalprocessingsociety.org/publications-resources/ieee-open-journal-signal-processing/author-instructions-ojsp-reproducibility)
- Version: IEEE Signal Processing Society web page: author instructions for reproducibility review at the IEEE Open Journal of Signal Processing (OJSP). Read 2026-10-06.

### E1

- Location: Main text, paragraph 1
- Quote: "Research reproducibility reviewers can access and run the compute capsule on the Code Ocean website to assess the validity of computational results presented in a manuscript, and share their assessment with editorial board members."
- Key point: OJSP reproducibility reviewers actually run the authors' compute capsule on Code Ocean to check the computational results in the manuscript, and share their assessment with the editors.

### E2

- Location: Main text, paragraph 1
- Quote: "OJSP is partnering with Code Ocean for this pilot because of the convenience and flexibility it offers to readers and reviewers"
- Key point: This is a pilot at OJSP.

### E3

- Location: Main text, on submission timing
- Quote: "once your article has received an AQR decision indicating that it is accepted for publication subject to passing a reproducibility review."
- Key point: Reproducibility review happens after the paper is accepted subject to passing a reproducibility review.

### E4

- Location: FAQ, To what degree is the Code Ocean capsule ... expected to reproduce the results in my paper?
- Quote: "The goal of the reproducibility review is to perform a good faith validation of the results. It is not intended to be an adversarial attempt to find unusual conditions under which the code fails."
- Key point: Reproducibility review is a good-faith validation of the results, not an adversarial attempt to find unusual conditions under which the code fails.

### E5

- Location: FAQ, Why is OJSP using Code Ocean and not popular code sharing platforms such as GitHub?
- Quote: "While source code published on platforms such as GitHub is helpful for researchers, a substantial amount of time and energy is usually required for a researcher to set up such source code to run in one's own computational environment."
- Key point: Source code on GitHub alone usually takes others a lot of time to set up and run, so package the code together with its runtime environment.

### E6

- Location: FAQ, What happens to the Code Ocean module once my OJSP article is published?
- Quote: "Upon acceptance and publication of your OJSP article, the Code Ocean module you have submitted for reproducibility review is also made publicly available and assigned a DOI"
- Key point: Once the paper is published, the reviewed code capsule is also made public and assigned a DOI (Digital Object Identifier, a permanent link).
