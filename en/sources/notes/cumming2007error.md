# Cumming, Fidler, and Vaux 2007: Error bars in experimental biology

- Source: `cumming2007error`, [Original (PubMed Central)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2064100/)
- Version: Journal of Cell Biology 177(1):7–11, 2007, free full text. Text read through the Europe PMC full-text API on 2026-10-06. Locations give subheadings or rule numbers.

### E1

- Location: What do error bars tell you?, Rule 1
- Quote: "Rule 1: when showing error bars, always describe in the figure legends what they are."
- Key point: When you show error bars, always say in the figure legend what they are (standard deviation, standard error, or confidence interval).

### E2

- Location: Replicates or independent samples—what is n?, Rule 2
- Quote: "Rule 2: the value of n (i.e., the sample size, or the number of independently performed experiments) must be stated in the figure legend."
- Key point: The figure legend must state n, the sample size or the number of independently performed experiments.

### E3

- Location: Replicates or independent samples—what is n?
- Quote: "If an experiment involves triplicate cultures, and is repeated four independent times, then n = 4, not 3 or 12."
- Key point: If triplicate cultures are run and the experiment is repeated four independent times, n = 4, not 3 or 12.

### E4

- Location: Replicates or independent samples—what is n?, Rule 3
- Quote: "Rule 3: error bars and statistics should only be shown for independently repeated experiments, and never for replicates. If a ‘representative’ experiment is shown, it should not have error bars or P values, because in such an experiment, n = 1"
- Key point: Error bars and statistics belong only to independently repeated experiments, never to replicates; a "representative" experiment has n = 1 and should have no error bars or P values.

### E5

- Location: What type of error bar should be used?, Rule 4
- Quote: "However, if n is very small (for example n = 3), rather than showing error bars and statistics, it is better to simply plot the individual data points."
- Key point: When n is very small (e.g., n = 3), plot the individual data points instead of showing error bars and statistics.

### E6

- Location: Statistical significance tests and P values
- Quote: "It is a common and serious error to conclude ‘no effect exists’ just because P is greater than 0.05."
- Key point: Concluding "no effect exists" just because P is greater than 0.05 is a common and serious error.

### E7

- Location: Statistical significance tests and P values
- Quote: "Of course, even if results are statistically highly significant, it does not mean they are necessarily biologically important."
- Key point: A statistically highly significant result is not necessarily biologically important.

### E8

- Location: Replicates or independent samples—what is n?
- Quote: "In the example of replicate cultures from the one stock of cells, the population being sampled is the stock cell culture. For n to be greater than 1, the experiment would have to be performed using separate stock cultures, or separate cell clones of the same type."
- Key point: Replicate cultures from one stock of cells sample only that stock culture; for n to be greater than 1, the experiment must use separate stock cultures or different cell clones of the same type.
