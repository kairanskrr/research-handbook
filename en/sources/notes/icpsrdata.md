# ICPSR: About ICPSR, Deposit Data, Citing Data, Data Confidentiality (web pages)

- Source: `icpsrdata`, [About](https://www.icpsr.umich.edu/web/pages/about/), [Deposit Data](https://www.icpsr.umich.edu/web/pages/deposit/index.html), [Citing Data](https://www.icpsr.umich.edu/web/pages/datamanagement/citations.html), [Data Confidentiality](https://www.icpsr.umich.edu/web/pages/datamanagement/confidentiality/index.html)
- Version: Four pages from the website of the Inter-university Consortium for Political and Social Research (ICPSR), part of the Institute for Social Research at the University of Michigan. The official site returns a verification page to scripts, so we read Internet Archive snapshots (July-September 2025). Locations give page names.

### E1

- Location: About ICPSR
- Quote: "ICPSR is an international consortium of more than 810 academic institutions and research organizations." / "ICPSR maintains a data archive of more than 350,000 files of research in the social and behavioral sciences."
- Key point: ICPSR is an international consortium of more than 810 academic and research institutions and maintains a data archive of more than 350,000 files of social and behavioral science research.

### E2

- Location: Deposit Data, What Should My Deposit Include?
- Quote: "Deposits should include all data and documentation necessary to independently read and interpret the data collection"
- Key point: A deposit should include all the data and documentation others need to read and interpret the data collection independently.

### E3

- Location: Deposit Data, Documentation File(s)
- Quote: "Documentation files are integral to reuse of a data collection and should thoroughly explain the data collection. Examples of documentation files include codebooks, copies of data collection instruments, user guides, README files, summary statistics, project summaries, and bibliographies of publications using the data."
- Key point: Documentation is key to reuse, for example codebooks, copies of data collection instruments (such as questionnaires), user guides, README files, summary statistics, project summaries, and lists of publications that used the data.

### E4

- Location: Citing Data, How to Cite Data
- Quote: "Each citation must include the basic elements that allow a unique dataset to be identified over time: Author Title Distributor Date Version Persistent identifier (such as the Digital Object Identifier, Uniform Resource Name URN, or Handle System)"
- Key point: A data citation must include the basic elements that identify a dataset uniquely over time: author, title, distributor, date, version, and a persistent identifier (such as a DOI).

### E5

- Location: Citing Data, How can I let ICPSR know about my publication?
- Quote: "Users of ICPSR data are required to send us bibliographic citations for each completed manuscript or thesis abstract."
- Key point: Users of ICPSR data must send ICPSR the bibliographic citation of each completed manuscript or thesis abstract.

### E6

- Location: Data Confidentiality, Identifiers
- Quote: "Indirect identifiers. These are variables that can be problematic as they may be used together or in conjunction with other information to identify individual respondents." / "Detailed geographic information (e.g., state, county, province, or census tract of residence)" / "Detailed occupational titles" / "Exact dates of events (e.g., birth, death, marriage, divorce)"
- Key point: Indirect identifiers do not reveal identity on their own but can identify individual respondents when combined with other information (e.g., detailed geography, organizational membership, detailed occupation, exact event dates, detailed income).

### E7

- Location: Data Confidentiality, Identifiers
- Quote: "If modifications to address identifiers to create a public-use dataset will seriously reduce the analytic utility of the data, ICPSR may release a restricted-use dataset or both public- and restricted-use datasets. Restricted-use datasets retain confidential, identifying information, and are accessible under controlled conditions."
- Key point: If removing identifiers to create a public-use dataset would seriously reduce its analytic value, ICPSR may release a restricted-use version that keeps identifying information and is available only under controlled conditions.

### E8

- Location: Data Confidentiality, Confidentiality, Informed Consent, and Data Sharing
- Quote: "The informed consent must include a statement describing how the confidentiality of subject records will be maintained. However, it is also important that informed consent be written in a way that does not unduly limit an investigator's discretion to share data with the research community."
- Key point: The informed consent form must state how participants' confidentiality will be maintained, but it should be worded so it does not unduly limit later sharing of the data with the research community.

### E9

- Location: Data Confidentiality, Confidentiality and IRBs
- Quote: "Institutional Review Boards (IRBs) take different approaches to secondary analysis of research datasets such as those distributed on ICPSR's website. Some institutions require IRB review of proposals to analyze secondary data. Other institutions provide IRB exemption for projects involving secondary data if the data were acquired from preapproved sources such as ICPSR."
- Key point: Institutional review boards treat secondary analysis differently: some require review, while others exempt data from pre-approved sources such as ICPSR.
