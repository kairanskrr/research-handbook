# Leonard 2018: Reflections on (de)colonialism in language documentation

- Source: `leonard2018decolonialism`, [full text](http://hdl.handle.net/10125/24808)
- Version: Language Documentation & Conservation Special Publication 15, pp. 55–65, open access. The author is a linguist at the University of California, Riverside, writing as a member of the Miami (Native American) community.

### E1

- Location: §2
- Quote: "a documentation corpus may contain carefully annotated texts but lack examples of conversations."
- Key point: A documentation corpus may contain carefully annotated texts yet lack examples of conversations.

### E2

- Location: §2
- Quote: "a decolonial approach calls not just for considering community needs, but rather for starting with them in conceiving of language documentation as an idea"
- Key point: A decolonial approach calls not just for considering community needs, but for starting from them when conceiving of language documentation.

### E3

- Location: §3
- Quote: "one useful practice when disseminating documentation is to feature larger and well-contextualized language examples, initially represented as the community would most commonly represent them"
- Key point: When disseminating documentation, feature longer, well-contextualized examples first, presented the way the community most often uses the language.

### E4

- Location: §3
- Quote: "it is important to start an example using unbroken words."
- Key point: An interlinear glossed example should start with unbroken (unsegmented) words on its first line.

### E5

- Location: §1
- Quote: "My tribal community shifted away from myaamia almost entirely"
- Key point: The author says his tribal community shifted away from the Miami language (myaamia) almost entirely, which shows he writes as a community member.
