# Berez-Kroeker et al. 2018: The Austin Principles of Data Citation in Linguistics

- Source: `berezkroeker2018austin`, [original](https://site.uit.no/linguisticsdatacitation/austinprinciples/)
- Version: Version 1.0 (2018), CC BY 4.0

### E1

- Location: 3. Evidence
- Quote: "Linguists should cite the data upon which scholarly claims are based."
- Key point: Cite the data on which scholarly claims are based.

### E2

- Location: 3. Evidence
- Quote: "Authors should ensure that data collection and processing methods are transparent"
- Key point: Make data collection and processing methods transparent.

### E3

- Location: 5. Access
- Quote: "Linguistic data should be as open as possible, in order to facilitate reproducibility; and as closed as necessary"
- Key point: Linguistic data should be as open as possible and as closed as necessary (for ethical, legal, and speech community constraints).

### E4

- Location: 2. Credit and Attribution
- Quote: "One way to do this is through citations that list individual contributors and their roles."
- Key point: Citations can list individual contributors and their roles.

### E5

- Location: 4. Unique Identification
- Quote: "linguists should look for services that provide the means for identification in the form of a Persistent Identifier (PID). For digital data, examples of these include Digital Object Identifiers (DOI) and Handles."
- Key point: When choosing a repository, look for services that provide persistent identifiers (such as DOIs).

### E6

- Location: 7. Specificity and Verifiability
- Quote: "Citations should specify which version of the data is being referenced."
- Key point: Citations should state which version of the data is referenced.

### E7

- Location: 7. Specificity and Verifiability
- Quote: "Data citations should make it easy for a curious reader to find the specific datum or subset of data within the larger dataset that support a claim."
- Key point: Citations should let readers find the specific datum or subset of data that supports a claim.

### E8

- Location: 6. Persistence
- Quote: "Linguists should confirm that the archives or repositories where they are storing their data have written policies pertaining to persistence of data, metadata, and identifiers."
- Key point: Confirm that the archive or repository holding your data has written policies on long-term persistence.
