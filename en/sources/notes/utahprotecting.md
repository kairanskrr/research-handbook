# University of Utah TLO: Protecting Your Research

- Source: `utahprotecting`, [original](https://technologylicensing.utah.edu/news-events/resources-opportunities/protecting-your-research)
- Version: University of Utah Technology Licensing Office web page, accessed 2026-10-06. Written for US law and the university's own policies.

### E1

- Location: What counts as public disclosure — Journal publications
- Quote: "Journal publications: The clock starts when the article publishes, not when you submit it. The peer review process remains confidential, giving you time to file patent protection."
- Key point: A journal article counts as public disclosure only when it is published, not during submission and confidential peer review, so you can file for a patent in that window.

### E2

- Location: What counts as public disclosure — Online preprint servers
- Quote: "Online preprint servers: Unlike journal submissions, these create immediate public disclosure the moment you upload."
- Key point: Uploading a preprint is immediate public disclosure.

### E3

- Location: What counts as public disclosure — Conference presentations
- Quote: "Conference presentations: Both the presentation itself and any published abstracts count as public disclosures."
- Key point: Both a conference presentation itself and any published abstract count as public disclosure.

### E4

- Location: What counts as public disclosure — Thesis and dissertation defenses
- Quote: "Thesis and dissertation defenses: These are considered public disclosures by law, even if only university personnel attend."
- Key point: In the US, a thesis or dissertation defense counts as public disclosure by law, even if only university personnel attend.

### E5

- Location: Provisional applications
- Quote: "Provisional applications are informal placeholders that can be filed quickly - often within days. The TLO can file your manuscript, poster, or even PowerPoint slides directly with the USPTO to establish your priority date."
- Key point: A US provisional application can be filed within days, even using the manuscript, poster, or slides directly, to secure a priority date.
