# IGSN e.V.: Using IGSN in Publications

- Source: `igsnpublications`, [original](https://www.igsn.org/resources/using-igsn-in-publications)
- Version: IGSN e.V. web page, read on 2026-10-06.

### E1

- Location: Main text of the page
- Quote: "Since May 2017 IGSN IDs can be included in the asset tabs of all Copernicus earth science journals."
- Key point: Since May 2017, all Copernicus earth science journals can list IGSN IDs in an article's asset tab.

### E2

- Location: Main text of the page
- Quote: "The machine readable form of an IGSN ID is a complete https://doi.org/ URL"
- Key point: The machine-readable form of an IGSN ID is a complete https://doi.org/ URL (an IGSN is now a kind of DOI).

### E3

- Location: Main text of the page
- Quote: "If a QR code is applied to a sample or its container, the label should also display the IGSN ID short display form in a human-readable way."
- Key point: If a QR code is put on a sample or its container, the label should also show the human-readable short form of the IGSN ID.
