# FGED Society: MINSEQE (Minimum Information about a high-throughput SEQuencing Experiment)

- Source: `fgedminseqe`, [Original](https://www.fged.org/projects/minseqe/)
- Version: FGED project web page, accessed 2026-10-08. The page lists MINSEQE version 1.0 (June 2012) and states that the society has closed operations. Locations are given as paragraphs.

### E1

- Location: Top of the page
- Quote: "MINSEQE describes the Minimum Information about a high-throughput nucleotide SEQuencing Experiment that is needed to enable the unambiguous interpretation and facilitate reproduction of the results of the experiment."
- Key point: MINSEQE sets out the minimum information about a high-throughput sequencing experiment needed to interpret its results unambiguously and to facilitate reproduction.

### E2

- Location: The five elements
- Quote: "The five elements of experimental description considered essential when making data available supporting published high-throughput sequencing experiments are as follows:" / "The description of the biological system, samples, and the experimental variables being studied" / "The sequence read data for each assay" / "The ‘final’ processed (or summary) data for the set of assays in the study" / "General information about the experiment and sample-data relationships" / "Essential experimental and data processing protocols"
- Key point: The five elements considered essential when making data available to support published sequencing experiments: the biological system, samples, and experimental variables studied; the sequence read data for each assay; the final processed (or summary) data; general information about the experiment and how samples map to data; and the essential experimental and data processing protocols.
