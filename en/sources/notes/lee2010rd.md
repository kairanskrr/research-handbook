# Lee & Lemieux 2010: Regression Discontinuity Designs in Economics

- Source: `lee2010rd`, [NBER working paper PDF](https://www.nber.org/system/files/working_papers/w14723/w14723.pdf); published version in Journal of Economic Literature 48(2), 2010
- Version: NBER Working Paper 14723 (February 2009, revised October 2009). Excerpts follow the working paper version; locations give the section number.

### E1

- Location: §3.1 Valid or Invalid RD?
- Quote: "The key word here is "precise", rather than "manipulate". After all, in both examples above, individuals do exert some control over the test score." / "Precise sorting around the threshold is self-selection."
- Key point: The key word is "precise," not "manipulate": people always have some control over the assignment variable (e.g., a test score); what breaks the design is being able to place yourself precisely on one side of the cutoff, which is self-selection.

### E2

- Location: §2.3 RD design as a Local Randomized Experiment
- Quote: "the conditions for local randomization are testable in the same way global randomization is testable in a randomized experiment by looking at whether baseline covariates are balanced."
- Key point: The condition of local randomization near the cutoff is testable the same way a randomized experiment is: check whether baseline covariates are balanced on both sides.

### E3

- Location: §4.6 A Recommended "Checklist" for Implementation
- Quote: "To assess the possibility of manipulation of the assignment variable, show its distribution."
- Key point: To assess possible manipulation of the assignment variable, show its distribution (a histogram).

### E4

- Location: §4.4.1 Inspection of the Histogram of the Assignment Variable
- Quote: "this test can fail to detect a violation of the RD identification condition if for some individuals there is a "jump" up in the density, offset by jumps "down" for others, making the aggregate density continuous at the threshold."
- Key point: McCrary's density test can miss violations: if some individuals jump up and others jump down, the effects can offset and the overall density still looks continuous.

### E5

- Location: §4.6 A Recommended "Checklist" for Implementation
- Quote: "Present the main RD graph using binned local averages." / "we recommend against simply presenting a continuum of nonparametric estimates (with a single break at the threshold), as this will naturally tend to give the impression of a discontinuity even if there does not exist one in the population."
- Key point: Present the main graph using binned local averages; do not just show a single smooth curve broken at the cutoff, which can look like a jump even when there is none.

### E6

- Location: §4.6 A Recommended "Checklist" for Implementation
- Quote: "Explore the sensitivity of the results to a range of bandwidths, and a range of orders to the polynomial." / "report a "typical" point estimate and a range of point estimates."
- Key point: Explore how sensitive the results are to a range of bandwidths and polynomial orders, and report a "typical" point estimate along with the range of estimates.

### E7

- Location: §4.6 A Recommended "Checklist" for Implementation
- Quote: "Conduct a parallel RD analysis on the baseline covariates."
- Key point: Run a parallel regression discontinuity analysis with the baseline covariates as outcomes.

### E8

- Location: §4.6 A Recommended "Checklist" for Implementation
- Quote: "Nevertheless, we do believe that documenting the sensitivity of the results to these array of tests and alternative specifications — even if they only appear in unpublished, online appendices — is an important component of a thorough RD analysis."
- Key point: Space limits mean not every combination fits in the main text, but documenting the results of these tests and alternative specifications (even only in an online appendix) is an important part of a complete regression discontinuity analysis.

### E9

- Location: §1 Introduction
- Quote: "Our main suggestion in estimation is to not rely on one particular method or specification."
- Key point: The authors' main suggestion for estimation: do not rely on one particular method or specification.

### E10

- Location: §1 Introduction
- Quote: "there is some room for the researcher to construct graphs making it seem as though there are effects when there are none, or hiding effects that truly exist."
- Key point: Graphs leave room for manipulation: a researcher can make it look as though there are effects when there are none, or hide effects that truly exist.

### E11

- Location: §3.4.1 Imperfect Compliance: the "Fuzzy" RD
- Quote: "The difference between the "sharp" and "fuzzy" RD design is exactly parallel to the difference between the randomized experiment with perfect compliance and the case of imperfect compliance, when only the "intent to treat" is randomized."
- Key point: The difference between "sharp" and "fuzzy" regression discontinuity designs exactly parallels the difference between a randomized experiment with perfect compliance and one with imperfect compliance where only the assignment is randomized.
