# Chartered Institute for Archaeologists 2023: Standard and universal guidance for archaeological field evaluation

- Source: `cifa2023evaluation`, [Standard PDF](https://www.archaeologists.net/sites/default/files/2024-11/CIfA-Standard-Field-Evaluation_2023.pdf), [Universal guidance PDF](https://www.archaeologists.net/sites/default/files/2024-11/CIfA-Universal-Guidance-Archaeological-Field-Evaluation_2023.pdf)
- Version: The Standard for archaeological field evaluation and the Universal guidance for archaeological field evaluation, published by the Chartered Institute for Archaeologists (CIfA) in December 2023. Field evaluation is the preliminary work that establishes whether an area holds archaeological remains and what they are like. These are professional requirements for CIfA members; locations give the document name and clause number.

### E1

- Location: Standard, Definition of archaeological field evaluation
- Quote: "Archaeological field evaluation is a programme of non-intrusive and/or intrusive fieldwork which seeks to determine the presence or absence of archaeological features, structures, deposits, artefacts or ecofacts."
- Key point: Field evaluation is a program of non-intrusive and/or intrusive fieldwork that seeks to determine whether archaeological features, structures, deposits, artifacts, or ecofacts are present.

### E2

- Location: Universal guidance, 2.8
- Quote: "Wherever possible, non-intrusive methods should be considered as the first option, with intrusive techniques used only where necessary to achieve the purpose of the archaeological field evaluation."
- Key point: Wherever possible, consider non-intrusive methods first, and use intrusive techniques only where needed to achieve the purpose of the evaluation.

### E3

- Location: Universal guidance, 2.2
- Quote: "The project design should be specific to the project under consideration, advocating practicable methods of investigation that reflect the nature, extent, preservation and significance of the archaeological remains likely to be found. Templates should therefore be used with care."
- Key point: The project design should be specific to the project, with methods suited to the nature, extent, preservation, and significance of the remains likely to be found; use templates with care.

### E4

- Location: Universal guidance, 3.9 (c)
- Quote: "the aims, objectives and methods used, including any departure from the project design"
- Key point: The report must state the aims and methods used, including any departure from the project design.

### E5

- Location: Universal guidance, 3.9 (f)
- Quote: "conclusions, including a confidence rating on techniques used, and any recommendations for further work that might improve that confidence"
- Key point: The conclusions must give a confidence rating for the techniques used and recommend any further work that could raise that confidence.

### E6

- Location: Universal guidance, 3.9 (e)
- Quote: "illustrations, plans and essential technical and supporting detail, with accurate spatial information sufficient to locate the areas of investigation in the future"
- Key point: The report's illustrations and plans need accurate spatial information so that the investigated areas can be located in the future.

### E7

- Location: Universal guidance, 3.10
- Quote: "The report and archive should contain enough detail to allow any further phases of work to be appropriately designed and planned."
- Key point: The report and archive should contain enough detail for any later phases of work to be designed and planned from them.
