# Appelbaum et al. 2018: Journal Article Reporting Standards for Quantitative Research in Psychology

- Source: `appelbaum2018journal`, [original PDF (publicly available on the APA website)](https://www.apa.org/pubs/journals/releases/amp-amp0000191.pdf)
- Version: American Psychologist 73(1):3–25. Report of the APA Publications and Communications Board Working Group, i.e., the Journal Article Reporting Standards for quantitative research (JARS–Quant).

### E1

- Location: abstract, p. 3
- Quote: "Examples of modifications include division of hypotheses, analyses, and conclusions into 3 groupings (primary, secondary, and exploratory)"
- Key point: The revised standards divide hypotheses, analyses, and conclusions into three groups: primary, secondary, and exploratory.

### E2

- Location: Table 1, Method — Sample size, power, and precision
- Quote: "Describe the sample size, power, and precision, including • Intended sample size • Achieved sample size, if different from intended sample size • Determination of sample size, including • Power analysis, or methods used to determine precision of parameter estimates • Explanation of any interim analyses and stopping rules employed"
- Key point: The method section should report the intended sample size, the achieved sample size, how the sample size was determined (power analysis or precision calculation), and any interim analyses and stopping rules.

### E3

- Location: Table 1, Method — Measures
- Quote: "Define all primary and secondary measures and covariates, including measures collected but not included in this report."
- Key point: Define all primary and secondary measures, including measures collected but not reported in the paper.

### E4

- Location: Table 1, Method — Psychometrics
- Quote: "Provide information on validated or ad hoc instruments created for individual studies, for example, psychometric and biometric properties." / "Estimate and report values of reliability coefficients for the scores analyzed (i.e., the researcher's sample), if possible."
- Key point: State whether instruments were validated or created ad hoc for the study, and report their psychometric properties; where possible, report reliability coefficients for the study's own sample.

### E5

- Location: Table 1, Method — Data diagnostics
- Quote: "Criteria for post-data collection exclusion of participants, if any"
- Key point: Report the criteria for excluding participants after data collection.

### E6

- Location: Table 1, Discussion
- Quote: "Provide a statement of support or nonsupport for all hypotheses whether primary or secondary"
- Key point: The discussion should state, for every hypothesis (primary and secondary), whether it was supported.

### E7

- Location: Table 1, Title page and author note
- Quote: "Registration information if the study has been registered"
- Key point: If the study was registered, give the registration information in the author note.

### E8

- Location: end of the main text, paragraph on how the tables are used
- Quote: "the ways in which the tables might be used (e.g., as a formal checklist, as a reference list for editors, authors, and reviewers) are not specified."
- Key point: The standards do not specify how the tables should be used; journals may use them as a formal checklist or just as a reference.

### E9

- Location: abstract, p. 3
- Quote: "Several new modules are included that report standards for observational studies, clinical trials, longitudinal studies, replication studies, and N-of-1 studies."
- Key point: The revised standards add modules for observational studies, clinical trials, longitudinal studies, replication studies, and N-of-1 studies.

### E10

- Location: Changes in Table 1, Psychometrics
- Quote: "the term reliability should refer to test scores in particular samples and not to tests or testing instruments. Likewise, the term validity should refer not to a test but to the proposed interpretations of test scores"
- Key point: Reliability refers to scores in a particular sample, not to the instrument itself; validity refers to a given interpretation of scores, not to the instrument itself.

### E11

- Location: Changes in Table 1, Psychometrics
- Quote: "Best practice is to estimate both reliability and validity, when possible, within the researcher's sample or samples (i.e., the scores analyzed)."
- Key point: Best practice is to estimate reliability and validity in your own sample.

### E12

- Location: Table 1, Method — Psychometrics
- Quote: "Provide information on validated or ad hoc instruments created for individual studies, for example, psychometric and biometric properties." / "Estimate and report values of reliability coefficients for the scores analyzed (i.e., the researcher's sample), if possible. Provide estimates of convergent and discriminant validity where relevant."
- Key point: State whether instruments were validated or created ad hoc for the study; where possible, report reliability coefficients for the study's own sample, and convergent and discriminant validity where relevant.

### E13

- Location: Table 1, Method — Psychometrics
- Quote: "Test–retest coefficients in longitudinal studies in which the retest interval corresponds to the measurement schedule used in the study"
- Key point: Longitudinal studies should report test–retest coefficients with a retest interval that matches the study's measurement schedule.
