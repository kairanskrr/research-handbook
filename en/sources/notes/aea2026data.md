# AEA: Data and Code Availability Policy

- Source: `aea2026data`, [original](https://www.aeaweb.org/journals/data/data-code-policy); companion policy [Policy for Papers Conducting Experiments and Collecting Primary Data](https://www.aeaweb.org/journals/data/policy-experimental)
- Version: February 2026 version (the page states "This version (February 2026) supplants all prior data policies"), accessed October 6, 2026. Applies to the journals of the American Economic Association (AEA).

### E1

- Location: opening
- Quote: "Prior to acceptance, authors of papers that contain empirical work, simulations, or experimental work must provide the data, code, and other details of the computations sufficient to permit replication. These materials must be made available and retained in an openly accessible trusted data repository, such as the AEA Data and Code Repository."
- Key point: Before acceptance, papers with empirical work, simulations, or experiments must provide the data, code, and computational details needed to reproduce the results, deposited in a publicly accessible trusted repository.

### E2

- Location: opening
- Quote: "If providing the data publicly is not possible despite the authors' best efforts and due to valid constraints outside the authors' control, authors must (i) commit to preserving data and code for a period of no less than five years following publication of the manuscript, (ii) commit to providing reasonable assistance to requests for clarification and replication, (iii) make the code publicly available, and (iv) publicly document the source of the data, including appropriate contact information."
- Key point: If data truly cannot be made public, authors must still: keep the data and code for at least five years; assist with others' reproduction requests; make the code public; and publicly describe the data source and how to contact it.

### E3

- Location: opening
- Quote: "The AEA data editor will assess compliance with this policy, including by conducting reproducibility checks and verifying the accuracy of the information provided, and will assist the authors in achieving compliance."
- Key point: The AEA data editor assesses compliance, including by conducting reproducibility checks.

### E4

- Location: Non-Public Data
- Quote: "It is generally not acceptable that data be provided "upon request" if the request must be approved by the authors themselves."
- Key point: Providing data "upon request" is generally not acceptable if the request must be approved by the authors themselves.

### E5

- Location: Code for Data Transformation and Data Cleaning (DCAS #7)
- Quote: "All programs used to generate the analysis data from raw data must be included, even if the raw data cannot be provided."
- Key point: All programs used to generate the analysis data from raw data must be included, even if the raw data cannot be provided.

### E6

- Location: Computer Code
- Quote: "A master script is strongly encouraged."
- Key point: A master script that runs the entire analysis in one go is strongly encouraged.

### E7

- Location: Documentation (README) (DCAS #13)
- Quote: "Please include a README document in PDF format in the uppermost directory of the replication package." / "Instructions on all the steps needed to run the computer code and reproduce all the results."
- Key point: The top level of the replication package must contain a README in PDF format with all the steps needed to run the code and reproduce all results.

### E8

- Location: Requirements and Guidelines
- Quote: "The American Economic Association endorses DCAS, the Data and Code Availability Standard v1.0 used by multiple journals in economics, and this data and code availability policy is compatible with DCAS."
- Key point: The AEA endorses the Data and Code Availability Standard (DCAS) used by multiple economics journals.

### E9

- Location: Registration of Randomized Controlled Trials (DCAS #12)
- Quote: "It is the policy of the AEA that randomized controlled trials must be registered on the RCT Registry."
- Key point: AEA policy requires randomized controlled trials to be registered in its RCT Registry.

### E10

- Location: companion policy Policy for Papers Conducting Experiments and Collecting Primary Data, Original Instructions
- Quote: "The original instructions for the experiment or survey should be summarized in the submitted manuscript as part of the discussion of the experimental or survey design and should be provided in full as an appendix at the time of submission."
- Key point: Papers reporting experiments or surveys must submit the full original experimental instructions or survey text as an appendix at submission.

### E11

- Location: Code for Analysis (DCAS #8)
- Quote: "Programs that produce computational results such as estimation, simulation, model solution, and visualization must be included. Ideally, these programs reproduce all the computational exhibits in the paper and approved online appendices with minimal human intervention."
- Key point: All programs producing computational results (estimation, simulation, model solution, visualization) must be in the replication package; ideally they reproduce every computed figure and table in the paper and appendix with little or no manual intervention.
