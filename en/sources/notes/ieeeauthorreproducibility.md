# IEEE Author Center: Research Reproducibility

- Source: `ieeeauthorreproducibility`, [original](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/research-reproducibility/)
- Version: IEEE Author Center web page for journals, read on 2026-10-06. Locations give page subheadings.

### E1

- Location: IEEE Open Research Statement
- Quote: "All IEEE authors are encouraged to share their data, code, and other research outputs to facilitate verification and reproducibility of experiments and their conclusions."
- Key point: IEEE encourages (but does not require) all authors to share data, code, and other research outputs so others can verify and reproduce their work.

### E2

- Location: Sharing Data
- Quote: "Improve the discoverability of your data by hosting it in an easily accessible repository such as figshare, Zenodo, or Dryad."
- Key point: It recommends hosting data in public repositories such as figshare, Zenodo, or Dryad.

### E3

- Location: Uploading Code
- Quote: "Help other researchers view and run your code with Code Ocean, a cloud-based computational reproducibility platform that allows code to be stored, shared, and run in the cloud."
- Key point: IEEE recommends Code Ocean, a cloud-based computational reproducibility platform, for storing, sharing, and running code online.

### E4

- Location: Uploading Code
- Quote: "Authors who have published with IEEE in the past five years can upload their code to Code Ocean and link it to the article published in IEEE Xplore."
- Key point: Authors who have published with IEEE in the past five years can upload code to Code Ocean and link it to their article page on IEEE Xplore.

### E5

- Location: Page footer
- Quote: "IEEE is the world's largest technical professional organization dedicated to advancing technology for the benefit of humanity."
- Key point: IEEE describes itself as the world's largest technical professional organization dedicated to advancing technology for the benefit of humanity.
