# Fields

Research works differently from field to field: the pace, how work is organized, publishing culture, ethics requirements, and what counts as acceptable evidence all differ `[Our analysis]`. The Fields section **covers only what is specific to each field**. Research methods shared by several fields (controlled experiments, questionnaires, interviews, case studies, reviews, replication and so on) live in [Research types](../06_methods/README.md); the Fields pages link there and only explain how their field does things differently. For how the layers of this handbook divide the work, see [How to use this handbook](../00_start-here/how-to-use.md).

Each field has its own folder containing:

- `README.md`: the field overview, which explains how research in the field actually runs, its conventions, and its common pitfalls;
- `practices/` (some fields only): research practices used only in this field. Each page covers the workflow, key decisions, a checklist, and common mistakes.

## Field classification

The Fields section follows the classification of Fields of Research and Development (FORD) in the *Frascati Manual 2015* of the Organisation for Economic Co-operation and Development (OECD): 6 broad areas and 42 second-level fields `oecd2015frascati`. ## Field-specific practices

A practice used in only one field gets its own page under that field's `practices/` folder, and is listed in [Research types](../06_methods/README.md) alongside the shared methods. Methods used in several fields (controlled experiments, randomized controlled trials, questionnaires, interviews, archival research, replication and so on) belong in `06_methods/` and are not repeated here. Each field overview's section "Research methods common in this field" links to them and explains how the field differs.
